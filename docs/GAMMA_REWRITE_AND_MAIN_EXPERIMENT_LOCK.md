# Gamma-centered paper and experiment lock

## Canonical paper

The canonical manuscript is `paper/aistats/main.tex` on branch `gpt-aistats-gamma-rewrite-20260903`.

The paper has one theoretical question: when is one signed, state-scaled flow sufficient, and when is it worth estimating separate interruption and restoration components?

The main theory is organized by

\[
\Gamma_n=\frac{nG_n}{\sigma_\varepsilon^2}=I_{\tau,n}\kappa_n,
\]

where `I_tau` is information about total turnover and `kappa` is the coactivity cost of suppressing one flow. This is the only boxed equation in the manuscript.

## Main real-data experiment

The already completed confirmatory experiment is primary and must not be replaced by a post-hoc protocol:

- cohort: all eleven events in `configs/panel_manifest_g2-convective-11.json`
- outer split: leave one complete event out
- validation: next chronological event under the frozen split map
- training: remaining nine events
- neural seeds: 0, 1, 2, averaged inside event
- objective: masked 48-hour rollout MSE
- primary endpoints: h+24 and h+48
- proposed class: two nonnegative flow networks
- theorem-matched comparator: parameter-matched signed `net_scaled` network
- practical references: same-information HGB and damped persistence

The result is reported exactly as completed:

- h+24: mean relative RMSE gain +4.55%, median +2.00%, 8/11 positive, event bootstrap [+0.74,+9.25]%, exact paired randomization p=0.041; strict preregistered decision not confirmed because the 9/11 sign gate failed.
- h+48: +3.71%, median +2.44%, 6/11 positive, interval [-0.84,+9.20]%, p=0.246; not confirmed.
- HGB and damped persistence have lower equal-event mean RMSE than the two-flow model at both long horizons.

No new neural fit is authorized by this document. The next empirical work, if any, must follow a separately written prospective protocol and cannot retroactively redefine the completed main result.
