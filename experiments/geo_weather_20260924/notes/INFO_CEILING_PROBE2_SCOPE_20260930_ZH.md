# 信息探针第二轮：显性易损性与县内暴露共位（运行前固定，2026-09-30）

承接第一轮（[结果](INFO_CEILING_PROBE_RESULTS_20260930_ZH.md)）。PI 同意试这两个方向（"你试试"）。学习器、折划分、指标和区间都与第一轮完全相同，只是新增两个信息块及其 null。代码在 `info_ceiling/probe2.py`，第一轮的 `probe.py` 不改。

## 1. 显性易损性 V（灾害条件化的历史停电）
- **灾害记录**：NOAA Storm Events 2014–2017（本地已有）。
  - 县记录直接对应到县；预报区记录经 `zone_county.txt` 映射到县。
  - 按 `CZ_TIMEZONE` 换算成 UTC 日期。
- **灾害类别**：
  - 风：雷暴大风、大风、强风、龙卷；
  - 冬季：冬季风暴、冰暴、大雪、暴风雪、湖效应雪；
  - 热带：热带风暴、飓风、热带低压；
  - 降雨：强降雨、山洪、洪水。
- **县对某类灾害的"响应"**：灾害当天及次日 EAGLE-I 日最大停电比例中的较大者（分母为 2024 模型用户数）。只用该县有 EAGLE-I 记录的年份；有覆盖的年份里没有记录的日子记为 0。
- **每县每类的特征**：灾害日数、响应 ≥1% 和 ≥5% 的比例、平均响应。都做经验贝叶斯收缩，向该类的全局均值收缩，伪样本 5 天。
- **与本次事件类别匹配的特征**：热带 → 热带，冬季 → 冬季，天气尺度大风与对流 → 风，强降雨 → 降雨。
- **恢复速度**：该县最大 3 次停电日里，停电维持在当日峰值一半以上的小时数的中位数（取峰后 72 小时内，15 分钟数据）。
- **Vp**：同一套特征按县整体打乱，与第一轮使用同一个置换。

## 2. 县内暴露共位 X
- **X**：HRRR 节点上"先相乘再按人口加权平均"的 4 个共位量：林冠 × 阵风超标、林冠 × 冰荷载 × 风、林冠 × 湿雪 × 风、排水不良 × 前期湿度 × 风（来自已有的 `eih_v1D_hrrr2`）。
- **Xp（null）**：同样 4 项，改为"县平均林冠或排水 × 县平均灾害量"。它保留县的平均地理和平均灾害强度，只去掉县内的共位关系。
- 这只是信息检验，不是恢复已删除的手工通道。如果 X 显著好于 Xp，才值得去重新提取节点数据，做可学习的县内空间核。

## 3. 变体与比较
- **易损性**：
  - M4V = M4 + V，M4Vp = M4 + Vp；
  - M1HV = B + W + H + V，M1HVp = B + W + H + Vp。
- **暴露**：
  - M1RX = M1R + X，M1RXp = M1R + Xp；
  - M5X = M5 + X，M5Xp = M5 + Xp。
- **关键比较**：M4V vs M4Vp、M4V vs M4、M1HV vs M1HVp、M1RX vs M1RXp、M1RX vs M1R、M5X vs M5Xp。

## 4. 判定规则（与第一轮相同，运行前固定）
某类信息算作带来可迁移增量，需要两条同时满足：
- 相对它的 null（Vp 或 Xp），S RMSE 的改善区间不含 0；
- 相对不加该信息的模型也有改善。

另外：
- 易损性同时报告事件级风险评分（Brier 分数、对数损失、AUC）。易损性在风险上"有信息"的判定：相对 Vp 的 Brier 技巧区间不含 0。
- 必须同时报告严重假峰和非 S 误差。
