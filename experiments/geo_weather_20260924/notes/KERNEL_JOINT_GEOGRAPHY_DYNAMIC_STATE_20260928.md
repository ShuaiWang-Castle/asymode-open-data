# 联合地理条件下的动态冲击核：D05 后的概念澄清

**后续具体化：** 主方案现见 [联合地理控制的动态响应核](KERNEL_CONTROLLED_RELAXATION_DESIGN_20260928.md)。本文保留物理输入边界与此前概念推导；其中任意前态条件头、保留原分支的嵌套路线不再是首版默认。新主方案明确采用受天气控制的仿射前态、全子集地理核基及四个有界松弛模式，与原GCRK非严格嵌套；仍未启动新训练。

PI 问题：能否让多种地理共同决定随天气历史变化的冲击？**最新明确约束：不能人工指定某一两种地理组成方案；架构必须允许全体地理变量的任意组合参与条件响应，组合由数据学习。** 本文的物理例子只帮助理解，不作为特定变量对存在关系、特定机制成立或允许交互清单的假设。

本笔记是概念与检验对象的细化，不是新 arm 的执行登记。未增加拟合、seed、NULL、数据下载或标签重建。核心仍是 **天气过程 → 地理的复杂调制 → 潜在冲击形成、叠加与累积 → 停电**，地理作用留在唯一 damage MLP 内部的 kernel。

## 1. 需要纠正的推断

D05 的“前值匹配使高 stock 支持减少”表明比较集合对已有状态敏感；它不证明任何静态模型必然失败，也不证明动态模型一定改善。D05 的 40 个逐坐标边际斜率没有检验完整的地理联合响应面，不能用边际弱效应排除纯交互、阈值组合或相反机制混合。

原 GCRK 本来就有联合地理和动态历史。`src/asymode/gcrk.py` 对 geo40 逐坐标 tanh、按训练均值中心化并作径向或拟合 RMS 归一，再经线性混合与 tanh 得到四维码，再控制耗散、skew 交互与读出增益；非线性链接可产生地理间交互。它的递归矩阵随当前隐藏天气驱动变化，也携带过去状态，已经能表达顺序与地理条件记忆。I18 只改地理归一化。D04 也含混合多个地理坐标的随机 tanh 特征，不能称为逐地理线性模型。

因此，新研究不是首次引入动态性。需要检验的限制包括四维地理压缩、共同的隐藏偏离幅度门控、事件内固定的地理耗散/交互/增益参数，以及单一 rank-2 skew 结构。是否真由这些限制导致漏峰，尚未验证。

## 2. “地理不变，作用变化”有明确含义

短期内县的坡度和基础土壤属性近似静态，但它们可以共同决定入渗、排水、记忆时间、阈值和状态间传递。此前降雨形成的状态再改变后来同一次风雨输入的响应。不是把静态县向量机械改成一个随时间变的向量，而是让它参数化动态过程。

物理类比要更准确：若“泥沙稀疏”指松散土体，松散程度、坡度、根系支撑、水的进入路径、先前含水状态与瞬时水压力都可能相关。USGS 水槽实验发现，松散与密实初始土体可在失稳后表现出很不同的运动；野外研究显示根系加固受物种、深度、方向和健康等共同影响，不能用森林覆盖率完整替代。[Reid et al., 2008](https://www.usgs.gov/publications/deciphering-landslide-behavior-using-large-scale-flume-experiments)；[Schmidt et al., 2001](https://pubs.usgs.gov/publication/70023764)。

降雨诱发失稳存在不同时间尺度：背景水文状态影响易感性，降雨入渗后的瞬态水压力可参与触发；已有状态和当前强度不能互相替代。[Iverson, 2000，出版方元数据与摘要](https://pubs.usgs.gov/publication/70022499)；[USGS 降雨诱发滑坡研究](https://www.usgs.gov/programs/landslide-hazards/science/overview-rainfall-induced-landslides)。本轮读取的是这些公开页面/摘要，未声称已逐页阅读论文全文。

以上研究提供参数化动机，不是本停电数据已经发生泥石流的证据。没有坡面失稳观测或设施暴露位置时，不能把一个学习到的隐状态命名为“泥石流率”或“真实含水率”。植被在不同冲击路径中的作用也不应预先规定统一正负号。

## 3. 联合地理不等于把县均值相乘

有两个不同层次：

- **属性联合**：任意多个地理坐标都可共同改变响应函数，不预先指定变量对、组内/组间限制、正负号或必须先有显著主效应。
- **空间共址与连接**：陡坡、疏林和易失稳物质是否出现在同一处，水是否沿坡面/沟道到达暴露设施。两个县的坡度均值与森林占比相同，联合空间结构也可不同。

对非线性局地作用，通常有

\[
\mathbb E_q[\psi(W_{q,t},G_q)]\ne
\psi(\mathbb E_q[W_{q,t}],\mathbb E_q[G_q]).
\]

更复杂的县级 MLP 不能凭空恢复被聚合丢掉的联合空间分布。若未来采用县内节点，应先在同位置组合天气与地理、更新局地状态，再按明确暴露权重聚合；县域面积权重不是电网暴露权重。需要传播过程时还要核验连接信息，不能把任意县邻接当作沟道或电网。

现有 geo40 已有部分联合结构，不能包装成新数据：

| 字段 | 已有信息与边界 |
|---|---|
| `forest_on_steep_frac` | 150m 网格中森林且坡度至少 10°，占县内 land 像元比例；森林为 NLCD 41/42/43 |
| `canopy_in_developed` | 开发地像元内的平均树冠百分数；不是线路上方树冠 |
| `forest_wet_coloc` | 80m 土壤采样点中森林与静态较差排水类别的联合比例，分母限有效排水属性 |
| `wet_in_forest` | 森林条件下的静态较差排水比例；不是时变土壤含水率 |
| `hazard_in_forest` | 森林位置的土壤 map-unit 内有评级组分中 moderate/severe windthrow 份额；不是实测倒树 |
| `forest_near_developed` | 森林与开发地的空间邻近代理；不是与线路的距离 |
| `windthrow_susceptibility` | 县森林占比乘县根系限制份额，属于县均值乘积，不是栅格共址 |
| `s50_*` | 原属性的邻县平滑，不是新的独立观测 |

基础森林定义排除 NLCD 90，扩展土壤/森林共址量包含 90，分辨率、分母和有效掩膜也不同，不能直接用 `forest_wet_coloc / forest_frac` 当作 `wet_in_forest`。当前 geo40 不直接包含砂黏砾粒径、松散物源厚度/储量、坡面—沟道汇流拓扑或线路/杆塔位置；不能从其他代理字段宣称已测得这些量。

## 4. 可检验的动态 kernel 形式

令 g_i 为全体地理属性，h_it 为原 damage MLP 的天气隐藏表示。新的默认候选是**全向量、无预设组合限制的联合条件映射**，而非人工选交互项。令 g̃_i 为仅在训练事件拟合预处理后的全体地理输入：

\[
z_i^{old}=\operatorname{GCRKCode}(g_i),\qquad
e_i=[z_i^{old};\widetilde g_i;\Phi_\theta(\widetilde g_i)],\qquad
\Theta_{i,t}=H_\theta(e_i,h_{i,t},s_{i,t-1}),
\]
\[
s_{i,t}=F_\theta(s_{i,t-1},h_{i,t};e_i),\qquad
\widetilde h_{i,t}=h_{i,t}+R_\theta(e_i,s_{i,t},h_{i,t}).
\]

Φ 与 H 采用稠密、可共享参数的非线性映射，完整地理向量经直接通路与学习到的联合表示一并进入条件头；不强制所有信息先压成四维。z_old 只是保留原核的并行支路，预处理与原分支必须按原版本复用，不能对已处理输入重复预处理。H 在原系数头的约束前参数上加入学习到的残差，再施加正耗散、反对称及有界读入/读出约束，得到 kernel 参数 Θ；F 与 R 使用这些参数。残差置零可保留原分支，而完整向量通路提供新增容量。所有地理坐标都能到达所有条件头；不存在“只允许坡度与植被相连”之类的关系掩码。该结构允许二阶、三阶及更高阶依赖，不枚举全部变量子集，也不在二阶人为截止。深度、宽度和正则强度以后只在训练事件内选择，目前未冻结数值。

原损伤网络的剩余层把 h̃ 转成其输出，既有停电动力学仍连接损伤、恢复与 stock。不另建第二个 damage 预测网络，不把实测未来 stock 塞进 kernel。候选 s 是可含多个快慢分量的隐状态。这里的条件网络是 kernel 内部参数生成器，不是另一个直接预测停电的网络。

“覆盖所有可能组合”在这里精确定义为：**不因人工选择变量对、地理分组、主效应筛选或指定交互阶数而禁止组合进入表示空间**。有限大小的网络仍有容量和优化约束，有限数据更不可能验证全部组合；不能宣称固定宽度已精确表达任意40维函数。现有 GCRK 的非线性四维码也已允许某些高阶混合，新设计增加的是更少受固定压缩限制的联合条件容量及天气/前态条件化，不是首次获得交互能力。

语义分组只用于解释图表、来源审计或报告分层，不规定参数共享边界，不要求组内或跨组哪个更重要。既有共址特征作为原有输入保留，也不被选成架构唯一的通道。上一版笔记中的“单属性基 + 低秩跨地理块乘积”降为可选表示对照，不能作为默认组合清单；任何可选低秩投影也必须看到完整地理向量，不能用物理名称限制其支持。

所有组合可进入仍是一种架构选择，不是“没有先验”。共享参数、平滑/收缩、维度与稳定性都是明确的归纳约束；要求取消的是未经数据验证的具体关系假定。已丢失的县内联合空间分布和未测量变量也不会因扩大映射容量自动恢复。

动态联合条件需要进入的不只是输出增益，还包括：

1. 天气哪些方向进入状态，以及何时触发；
2. 状态记忆与衰减的时间尺度；
3. 先前状态如何改变后来天气的冲击强度与状态转换；
4. 最后怎样影响原隐藏层。

优先考虑保留原 GCRK 可退回的隐式有界结构，但让系数由 `(e_i, h_it, s_i,t−1)` 条件化：

\[
(I+\operatorname{diag}\lambda_t-\nu_t S_t)s_t
=s_{t-1}+\nu_t d_t,\qquad
S_t^\top=-S_t,\quad \nu_t=\min_j\lambda_{tj}>0,\quad \|d_t\|_2\le1.
\]

读入矩阵和有界触发阈值可以参与构造 d_t，耗散 λ_t 与 skew 系数由联合地理、可用天气及前态共同决定。所有条件量在该步求解前算出，不使用当前未知 s_t。由于 skew 不贡献二次型，逆矩阵范数至多 `1/(1+ν_t)`，故初态范数不超过 1 时有 `||s_t|| ≤ (||s_t−1||+ν_t)/(1+ν_t) ≤ 1`，即使这些系数依赖前态也保持此有界性。读出仍需范数或幅度控制。

这不自动保证不同轨迹间收缩、梯度稳定或参数可识别；还要限制条件映射的敏感性并检查递归 Jacobian。不能沿用原固定系数的自定义反向传播而不修改梯度。把新增条件连接置零、读入设回单位映射、阈值设回原全局门槛、skew 设回原 rank-2 形式，并保留原地理码与归一化分支，才具备退回原核的结构条件。若要求函数与训练流程精确一致，还须保持原 prefix-reference 偏离、拟合侧 c/θ 校准、λ/a/Ω 参数头及其范围、读出增益、开口与 warmup/drop-path，以及原 W2/b2。原核已具有逐坐标不同耗散时间尺度，不能宣称这次首次加入多时间尺度记忆。

从动态系统角度，真正的有效响应核可以写成 `K(i,t,s)=∂s_it/∂h_is`。它依赖联合地理及沿途状态/天气，即使 g_i 不随小时变化也会变化。这个定义描述模型灵敏度，不把导数称为物理因果作用。

## 5. 怎样验证，而不是只增加表达能力

需要分开记录“表示是否能写出”与“数据是否支持它”。首先用结构表核对真实共址、县均值乘积和缺失物理量，不能把该表中的物理例子变成候选组合的筛选名单。保留所有变量，对已有资料可检验的对象，比较天气强度和背景相近、地理联合条件不同的自然样本；同时检查联合历史、已有状态、事件与重复县支持，不能仅依据单变量边际重叠。

响应层的统计对照应明确写出加性地理修饰、全向量学习的联合地理修饰以及后者对动态状态/记忆的修饰。先比较完整联合条件块，再做有支持的事后解释，不先挑某几个显著变量对才准许建模。可以用整个联合块的跨事件增益、稳定性和容量敏感性衡量证据；不要求穷举40维所有子集才承认联合响应。模型参数的加性条件经 sigmoid 或递归后仍可能产生响应交互，不能把“参数加性对照”称作“响应无交互对照”。若使用函数分解定义联合效应，必须给出训练参考分布及相关地理下的非唯一性边界。

随后在相同天气/地理信息、可比容量和同一评价下考虑四级嵌套：原 GCRK；仅扩展联合地理条件表达；再加天气条件变化；再加前隐状态条件变化。各级新增连接应能置零退回前一级。动态关闭对照仍保留递归，不能把整个递归删除后声称仅隔离了动态地理。重新联合拟合的比较与冻结模型内的开关灵敏度是不同证据；若要归因地理信息而非容量，需另外登记训练过的同架构地理信息对照。是否增加参数、改强度门控或修正时间口径必须分别记录，不能把所有收益合并归因于地理联合。

严格嵌套比较需要披露增加的活跃参数，不能同时宣称各级容量完全相同。另设参数/状态维度/训练预算尽量匹配的横向对照，例如更宽的仅地理条件模型对比动态条件模型；这组横向比较未必严格嵌套。两种证据分开报告，避免将模型容量增长直接解释为地理组合或动态条件的作用。

所有选择限训练事件，保留原事件 folds；未来正式队列前冻结预算、数值收敛/初始化稳定性、尾部触发/幅度/假峰与总体指标。跨事件重复、共同支持内的地理组合效应，以及对来源/容量/已有状态的敏感性共同形成证据；总体 MSE 不作为局部现象的排除门槛。本笔记未启动这些比较，也未批准任意新模型或数据扩展。
