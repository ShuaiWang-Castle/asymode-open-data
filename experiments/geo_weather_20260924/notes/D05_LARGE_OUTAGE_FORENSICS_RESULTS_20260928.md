# D05：大幅停电为何漏掉——数据取证结果

分析登记提交 `665218d`。D05 已完成，只有一个 nice-15、两线程进程，没有训练新模型。分析对象为公开 D 的 8,457 个县—事件、2,410 个县、81 个系统、68 个合并事件组，保留 `used=False`。冻结 D04、I18、宿主与原 GCRK 未改；未读取 sealed C、年度原始停电记录或修改稿件。I18 监控继续暂停。

**当前证据支持：大峰值附近存在可见的天气过程信号，而旧模型的响应幅度极小，单纯平移预测时间不足以解决漏峰。地理关联也有值得继续检验的条件差异，但尚不能把未解释部分归因于已证实的地理机制。** 本轮是已经看过 D 后的探索性取证，不是独立确认试验。

## 1. 大跳升与高存量相交，但不是同一个问题

J 定义为预测窗口内最大有效相邻小时净增量至少 1 个百分点；S 定义为观测停电比例最大值至少 10%。每类每县—事件仅取一个最大值锚点，平峰取最早时刻。

| 类型 | 县—事件数 |
|---|---:|
| J 且 S | 723 |
| J 但非 S | 2,240 |
| S 但非 J | 3 |
| 两者均非 | 5,491 |
| J 合计 | 2,963 |
| S 合计 | 726 |

高存量病例的 99.59% 出现过至少 1pp 跳升，但只有 24.40% 的跳升病例进入 S。S 中 702 个预测窗口全部观测，368 个县—事件达到 20% stock。全体县—事件中，16 个在起始前一小时已达到 10%；S 中 9 个没有在预测窗口观测到从低于 10% 的上穿。

按原设计权重，S 的真实峰值中位数为 15.82%，最大一小时净增量中位数为 11.83pp，达到 10% 的小时数中位数为 3。这里的权重描述抽样设计，不应把条件病例统计称为全国发生率。

J 最大跳升后的形态分成多种，不能都用缓慢累积描述：

| 固定形态条件 | 有完整随访的原始比例 | 设计权比例及点位 95% 区间 |
|---|---:|---:|
| 下一小时净回落至少该次跳升的 80% | 551/2,949 = 18.68% | 22.59% [18.74%, 26.53%] |
| 之后六小时每小时都不低于“跳升前 stock + 半个跳升” | 605/2,874 = 21.05% | 7.69% [4.68%, 11.76%] |

这是每个 J 县—事件所选最大跳升的条件形态，不是全部跳升小时的比例。不满足第二条件不等于完全恢复。最大差分选择、共享端点噪声与回归均值都可能带来后续回落；不能说 22.59% 是报告错误或据此估计物理修复速度。边界最大跳升 25 个、并列最大值 33 个，均保留。

## 2. 幅度严重不足，不能靠挪动峰时补救

下表全部为 S 的“预测值 / 该县—事件真实 stock 最大值”中位数，以百分比表示这个比值。每格为 **未加权 / 原设计权**；不是 MSE 改善百分比。全窗最大值要求预测与真实观测共同支持；全部 144h 的未掩码敏感性另外保留在 JSON。

| 冻结 seed-0 模型 | 真实峰时 | 前后 12h 最大预测 | 全窗共同观测支持最大预测 |
|---|---:|---:|---:|
| 宿主 | 4.823% / 0.539% | 6.914% / 0.805% | 8.032% / 1.598% |
| 原 GCRK | 4.554% / 0.451% | 7.454% / 0.558% | 9.030% / 1.224% |
| GCRK+Cin-georms | 4.627% / 0.454% | 7.560% / 0.613% | 8.936% / 1.225% |

Georms 峰时误差的未加权中位数虽然是 0h，10–90% 区间仍是 −40 到 +32h；设计权中位数 −2h，10–90% 区间约 −65 到 +61h。因此不能说“时点已经准确”。然而即使放宽到全窗，幅度仍极小，时间错位不是充分解释。

J 的现象更明显：Georms 在真实最大跳升时的预测增量比中位数为 0.094% / −0.0042%；全窗最大正预测增量比也只有 5.102% / 1.543%。预测 stock 先按原轨迹相邻差分，非正最大值的峰时不计；这不是物理故障率。所有中位数是描述性分位数，未给中位数置信区间；均值及其条件事件 bootstrap 区间完整保留在结果 JSON。

此前 D04 在大跳升上也有幅度不足，但它预测严格过去天气下的净变化，不能把它与这里使用既有天气输入的神经轨迹当成同一个预测任务比较分数。损失诱导收缩、训练精度、局地暴露遗漏与映射形式均仍是假说，本轮没有分解各自贡献。

## 3. 天气并非完全不可见：近时冲击与此前积累都要保留

主对照是同县同事件内的固定时钟 72,84,…204，排除锚点前后 12h，**没有要求对照时点无停电**。先在每县—事件内平均有效对照，再按原权重汇总。J 病例同县对照中，先计算每个县—事件的有效对照小时中 1pp 跳升所占比例，再按县—事件设计权平均，结果为 0.564%。保留每组全部 3,408 个单变量、同步、对称、反对称、固定延迟、近时刻及既有宿主输入坐标。

## 5. 时间与观测审计：已排除什么，仍缺什么

81 份明确 D 小时面板与 D 特征的县标识、时间轴、y、观测 mask、分母逐项相等，每县—事件恰好覆盖一次。预测窗口缺测 3,592/1,217,808 小时（0.295%），有效相邻差分 1,213,761。五个已有复合输入和 snow_ice_load_sum72 各 1,826,712 个缓存值均与当前源映射精确一致；不存在所检查的 near-freeze/snow-load 两列互换。该检查只确认缓存对应，不验证物理公式。

停电 p[T] 是 T、T+15、T+30、T+45 分钟可用比例的均值。当前 ERA5 降水、降雪和小时阵风值索引 T 对应 (T−1,T]；瞬时变量对应 T。因此 D04 最后的 weather[T−1] 对这些区间量实际覆盖 (T−2,T−1]，而 weather[T+1] 才覆盖停电标签所在小时。+1 在这里仅用于回顾对齐，不能作为较早时刻的预测信息，也不能仅凭索引称为物理上的“停电之后天气”。时间区间定义依据 [ECMWF 官方说明](https://confluence.ecmwf.int/spaces/CKB/pages/85402030/ERA5%2Bterminology%2Banalysis%2Band%2Bforecast%2Btime%2Band%2Bsteps%2Binstantaneous%2Band%2Baccumulated%2Band%2Bmean%2Brates%2Band%2Bmin%2Bmax%2Bparameters)。本轮没有量化调整时间口径会改善多少预测。

小时缓存没有保存每小时有效季度小时数、原始计数或裁剪标记。原处理先将季度小时比例裁剪到 [0,1]，部分零值来自已有推断规则；小时精确等于 1 或突降不能判定原始记录错误。采集时刻定义的文字与源实现仍有一处未量化差别：实现先丢显式零行，并用行数而非独立县数阈值。没有为此读取年度原始行或 C mask，也没有改 mask、删除尖峰或重建标签。

## 6. 对下一版 kernel 的具体约束

核心保持 **天气过程 → 地理的复杂调制 → 冲击形成、叠加与累积 → 停电**。下一版研究对象应是单一 damage MLP 内的动态隐状态转换，而不是给静态地理乘一个全局倍率。D05 提供以下动机，并不规定某个机制已成立：

1. **冲击的触发与幅度需要分别可检查。** 对有天气信号的大跳升，旧轨迹响应过小；应在不改既有总体评价的前提下并列检查触发时点、增量尾部、假峰与 stock 峰值。不能只将输出放大，因为 D04 已有假峰问题。
2. **保留连续地理调制的多时间尺度记忆。** 同时保留短时天气突变、前期降水、降雪累积与土壤湿度与较慢冲击累积；让全部 geo40 连续地改变天气进入隐状态、记忆衰减和状态间作用。县类型仅用于导航，不固化成六种物理专家。
3. **同步与有向顺序应在控制主效应后检验。** 先验证联合/顺序信息是否超出单变量幅度、事件阶段和已有 outage 状态。当前二阶坐标不能充当这个检验；未来的条件顺序对照应保持幅度分布与支持，并采用事件留出，避免通过打乱制造不真实轨迹。
4. **观测过程与潜在冲击分开。** stock 的净差包含故障、恢复、小时平均及报告过程；隐状态只能称为 latent impact，不能称为已观测物理损伤。时间可见性必须在任何新训练前明确，未来天气只可用于回顾解释。

优先证据链是验证“在相近天气强度和背景下，地理是否改变短时触发与后续累积，并且这种改变能跨事件保持”，而不是以总体 MSE 或几个显著坐标替代机制证据。本轮未追加神经 arm、seed、NULL、数值重拟合或数据重建。
