# T01：热带数据候选与同事件县留出探针

用户明确不要求跨事件泛化，要求继续寻找适合的数据集。依据3f8f733；在本轮新评分前固定以下有限范围。

- 仅已有公共D的15个热带系统，保留used=False，既有72h历史/144h未来窗口，不读C或年度原始记录。
- 对全部事件审计县数、观测覆盖、地理可用性、ERA5/HRRR缓存；未来停电分布只作已查看开发集描述，不按提升挑县或改窗。
- 对至少25个县、ERA5齐全且未来至少有一个有效观测的事件，固定seed20261001随机五折县留出。每县整条轨迹在一个折；本轮事件分别建模，不宣称空间外推。
- 目标仅为未来144h有效观测峰值；不是完整轨迹预测。报告部分观测样本数；不把未观测峰值当已知。
- Ridge三臂：B=ERA5基础天气前72h/未来144h各通道均值和最大值，加历史OSI的末值、均值、最大值；G=B+基础及扩展地理；P=B+固定随机县置换地理。排除天气缓存中显式canopy*/drain*地理乘积。人口加权天气本身仍含空间聚合假设，B不等于完全不含空间信息。
- 天气使用已知未来再分析，仅为条件hindcast。历史OSI缺测不使用未来补齐；训练侧填补并标准化所有特征。
- 每外折内部三折选择alpha=[0.1,10,1000]，最小设计加权MSE；训练和评分使用既有设计权w。输出截到[0,1]；内层与外层评分口径一致。
- 各事件报告pooled县峰值RMSE/MAE，G对B/P变化，五折胜出数；单seed、有限线性探针，无显著性或核有效性主张。地理置换用于容量参照，不作因果识别。
- 输出全部事件，不只赢家。数据候选初排仅依县数、原始输入覆盖等可用性；预测表现只作公开开发诊断。独立确认数据尚待另立。
- 交付脚本、全事件汇总CSV、固定split、输入hash及中文报告。逐县预测不提交。
