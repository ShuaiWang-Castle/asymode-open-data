# 剂量—易损性核：设计与单 seed 筛选范围（运行前固定，2026-10-02）

PI 指示：文献核查、数据分析、单 seed 实验三件事都做（PI 离开至少 5 小时）。本文件在任何新结果出现之前，固定了数据分析和实验的设计与判定规则。文献核查由独立助手并行完成，结果另存。

## 1. 数据动机（已有证据）
1. **地理是长期易损性的先验。** 按州留出时，地理对县历史易损性的 R² 为 0.07–0.11，打乱后为负。
2. **县的历史记录能解释同天气邻县谁被打得更重。** 孪生县配对的符号准确率 +4.3% [+1.6, +6.8]；严重风险的 Brier 改善 1.5–4%。
3. **宿主在热带严重事件上少用了约 16% 的信息**，这部分来自累积的湿地大风暴露。
4. **恢复侧是直接原因（2026-10-02 新增诊断，宿主 seed 0 的留出输出）。**
   - 宿主在严重事件峰值处的恢复率几乎是常数：各天气类型的设计加权中位数都在 0.263–0.270/小时。
   - 观测到的热带严重事件峰后 24 小时仍剩 16%（加权中位数），不加权为 29%，对应恢复率约 0.05–0.07/小时，比宿主慢 4–5 倍。冬季约 0.15；对流和强降雨约 0.32。
   - 宿主峰值处损伤率的中位数为 0.0086（热带），稳态水平 u/(u+r) 约 3%，所以积不起大的停电存量。
   - 恢复网络每小时独立计算，没有"已经累积了多少损伤"的记忆。

## 2. 模型：剂量—易损性核（DK）

保留宿主 AsymODE（W+Cin，单个损伤 MLP，人口平衡，速率上限不变）。核读取损伤网络第一隐层 h_{i,t}（216 小时），不引入手工灾害特征。

- **暴露**：e_{i,t} = softplus(W_e h_{i,t} + b_e) ∈ R^K，K = 3。
- **剂量状态**（非负、有界的有序累积）：D_{i,t} = ρ ⊙ D_{i,t−1} + (1−ρ) ⊙ e_{i,t}，D_{i,−1} = 0。
  - ρ_k = exp(−1/τ_k)，τ_k ∈ [3, 168] 小时，可学习，初值 12、48、120。
  - 核为 D_t = Σ_v (1−ρ)ρ^{t−v} e_v，显式、有序。
- **标准化**：z_{i,t} = (D_{i,t} − c)/s。c 和 s 是只由拟合县计算的缓冲量（中位数，以及 99% 与 50% 分位数之差），每 10 步刷新一次，不参与优化。
- **易损性阈值**：a_{i,t} = softplus(z_{i,t} − θ − Γ v_i)，a′_{i,t} = softplus(z_{i,t} − θ′ − Γ′ v_i)。
  - v_i 是标准化后的县易损性向量。
  - θ、θ′ 初值为 2；Γ、Γ′ 初值为 0。
- **损伤侧**（易损性曲线读出，竞争灾害形式）：λ^U_{i,t} = βᵀa_{i,t}，β ≥ 0；u ← c_u − (c_u − u)·exp(−λ^U)。
- **恢复侧**（剂量越大恢复越慢）：λ^R_{i,t} = ηᵀa′_{i,t}，η ≥ 0；r ← r·exp(−λ^R)。
- **配对初始化**：β = η = 0，所以第 0 步与宿主完全相同。β、η 每步之后投影到非负。
- **延迟开启**：核的参数在宿主先训练 100 步之后才开始更新，此前不累积 Adam 状态。原因是最初几十步宿主损伤率初值偏高，任何抬高损伤或减慢恢复的方向都会增大损失，β、η 会被压在 0 上，且 Adam 二阶矩被早期大梯度撑大（冒烟运行中观察到，属训练细节，在任何留出结果之前确定）。
- **性质**：u 仍在 [0, c_u]，r 仍在 [0, c_r]，库存保持合法。剂量只会抬高损伤、减慢恢复。

**易损性向量 v_i**（7 维）：
- 地理先验 3 项：用 geo40 加 6 个县内暴露量预测县的历史易损性（log 每年 ≥10% 停电日数、log ≥5% 停电日数、log 最大 5 天平均）。按州分组交叉拟合，每个县的先验都不使用本州的历史；没有历史的县由全部有历史的县训练的模型给出。
- 历史 3 项：EAGLE-I 2014–2017 的同样三个量，缺失时取先验值。
- 1 个"有无历史"的指示量。

全部来自 2018-07-12 之前的数据，与任何开发事件无关。

## 3. 数据分析：地理先验的事件级检验（LightGBM，与信息探针相同设置）
- μG 为地理先验（3 项），μGp 为用打乱的地理做同样交叉拟合得到的先验，v̂ 为历史向先验收缩的后验：v̂ = (n·h + κ·μ)/(n + κ)，n 为有覆盖的年数，κ = 2。
- **孪生县配对**：
  - [B,W,μG] vs [B,W,μGp]；
  - [B,W,H,μG] vs [B,W,H]；
  - [B,W,v̂] vs [B,W,H]；
  - 另报"至少一县历史不足"（缺失或 ≤2 年）的子集。
- **严重风险（Brier）**：M1+μG vs M1+μGp；M1H+μG vs M1H。
- **轨迹**：M1+μG vs M1+μGp，看 S、全体和风暴内 Spearman。
- **判定**："地理作为先验有事件级证据"需要 μG 相对 μGp 的区间不含 0，孪生配对或风险两者满足其一即可。

## 4. 单 seed 筛选（seed 0，event 五折，900 步，与宿主配对）

| arm | 内容 | 对照的问题 |
|---|---|---|
| DKV | 剂量核 + 易损性（先验 + 历史） | 主候选 |
| DK | 剂量核，不带易损性（Γ = Γ′ = 0，不输入 v） | 易损性是否必要 |
| DKVp | 剂量核 + 按县打乱的易损性 | 易损性的 null |
| DKr（时间允许时） | 只开恢复侧（β 固定为 0） | 收益来自恢复侧还是损伤侧 |

- **参照**：宿主 seed 0（及 5 seed 平均）、GCRK seed 0、信息探针 M1 和 M5（上限参照）。
- **运行**：最多 3 个训练进程，nice 10，每进程 2 线程。顺序为 DKV → DK → DKVp → DKr。
- **指标**（完整 144 小时，设计加权；区间为类别内 family cluster bootstrap，2,000 次）：
  - S、全体、非 S 的 RMSE；
  - 严重假峰数；
  - 分天气类型的 S；
  - S 的预测峰/真峰中位数；
  - 风暴内 Spearman；
  - 孪生县配对的符号准确率。

**判定规则（先单 seed）**：
- DKV 成为候选，需要相对宿主的 S 改善区间不含 0，且严重假峰不超过 20 个，且全体 RMSE 不恶化（点估计 ≥ 0）。
- "易损性有贡献"需要 DKV 相对 DKVp 在 S 上或风暴内排序上改善，区间不含 0。
- 候选才追加 seed 1–2，并登记进一步的 null；否则如实报告。
