# D05: large-outage data forensics

PI request: explain missed large outages using preceding/following weather and continuous county structure. The durable chain is **weather -> complex geographic modulation -> latent impact formation/overlap/accumulation -> outage**. This is exploratory analysis on already examined public D, not confirmatory preregistration, causal identification, a new neural arm, or model selection. Overall MSE is not an exclusion gate.

Only the existing D features, explicitly enumerated D hourly panels, D02 county lookup and frozen D04/I18/host/GCRK exports are allowed. No annual raw outage rows, C masks, sealed C, competition material, new data downloads, or manuscript edits. Frozen sources, targets, masks and folds remain unchanged. One nice-15 process, at most two numerical threads; preserve any partial directory. The old monitor remains paused.

## Fixed definitions before the new run

- All 8,457 county-events, including `used=False`, remain background. Forecast hours 72..215; stocks require authoritative observation masks; changes require adjacent observed hours.
- J: maximum one-hour positive net-stock increment >=0.01 (one percentage point). S: observed stock maximum >=0.10 (ten percent), matching the earlier 726-case cohort. Stock >=0.20 is a fixed severity sensitivity. Stock and net increments are different outcomes, neither measures gross physical damage.
- Earliest ties define maximum-jump and maximum-stock anchors. First >=1pp jump and first upward 10% crossing are secondary anchors; already-high origin stock is reported separately. Boundary, missing, plateau and persistent/reversing shapes are retained. Immediate reversal means next change <=-0.8 times the anchor jump; six-hour sustained means each of the next six observed stocks exceeds pre-jump stock plus 0.5 jump. Coverage is mandatory and explicit. Neither flag diagnoses reporting error.
- Frozen seed-0 host, GCRK and georms exports: verify exactly-once five-fold identity, metadata, finite stock range. Compare maximum prediction, prediction at true maximum, local +/-3/6/12h maximum and timing, using common observed support. Original all-144 predicted maximum is a separate sensitivity. Optional rate exports are unchanged model outputs, not physical flows. No simulation or rate replay.
- Weather: all 12 original channels; raw and log1p(CAPE/precip/snow)-then-standardized views. Geography: all 40 continuous coordinates, reference equal unique counties. Weather reference equal all D county-event-hours, used only descriptively. Context six coordinates remains separate. Six D02 types are navigation, not mechanisms.
- Curves at offsets -48..+24; fixed bands [-48,-25],[-24,-7],[-6,-1],[0],[1,6],[7,24]. Mean/min/max, precip/snow sums, all 78 synchronous pairs, 15 band pairs with 78 symmetric and 66 antisymmetric coordinates, and 1/6/24h delayed products of all 144 ordered channel pairs. Incomplete summaries remain missing, never padded. The 28 existing host extras are retained under their stored labels with source semantics audited; no assumption that the old model only used average weather.
- Outage p[T] is the available quarter-hour mean at T,T+.25,T+.5,T+.75. Precip/snow/gust[T] cover (T-1,T], other weather is instantaneous at T. Report -1,0,+1 separately: +1 aggregates retrospectively cover the observation hour and are not forecasting information. Later weather does not establish causation.
- Same county-event contrasts: case anchor versus mean of fixed clock controls 72,84,...204 more than 12h away. No filtering controls by outage outcome. Average eligible controls within unit before weighting. For every feature report complete support, all-regime and five-regime weighted contrast with 999 merged-event bootstrap draws. All coordinates retained, no significance-based selection. Fixed t=120 for all units provides an outcome-independent curve reference. First-onset and all complete +/-24h window views are secondary.
- Same system/time cross-county contrasts: fixed-clock full-risk rows plus J/S outcome-selected anchors; same absolute time, different county. Distance averages the squared RMS of 108 strictly-past weather summaries and six standardized context coordinates. Three nearest eligible neighbors; require three different counties. No outcome-based quiet controls. Parallel no-state and prior-stock-caliper 0.02 versions. Fixed weather RMS calipers 0.5/1/2 and context RMS <=1; main 1, other values support only. Compare focal minus neighbor net change against each of 40 standardized geography differences separately; all five regimes, conditional fixed-match merged-event bootstrap. These are marginal correlated-geography associations, not independent effects. Unmatched support, distances, event concentration and neighbor reuse are mandatory.
- Case weights are original design weights once per county-event. Full-risk rows divide that mass over actually valid fixed hours. Raw-weight sensitivity accompanies basic phenotype/model summaries. Bootstrap holds the observed feature reference and matches fixed and does not cover selection, representation or fitting uncertainty. Pointwise intervals are exploratory, not multiplicity-adjusted discoveries.

Outputs: auditable phenotype/model/weather/matching summaries, static plots and a Chinese evidence note separating observed facts, observation limitations and next kernel hypotheses.
