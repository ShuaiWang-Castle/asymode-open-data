# D06：GPT 外部审查的实证复核范围

登记日期：2026-09-29；基于已公开 D05、I20 和交接提交 `14153f9`。PI 要求分析 GPT 的工作并继续推进。本轮是已看过 D 的探索性诊断，不是新的确认试验。

## 问题与固定范围

先查清观测—宿主—目标—隐层的响应链，再决定是否改核。外部报告中的数学命题与真实数据上的解释力分别验证，不把合成测试当作真实数据实验。

1. 验证外部 ZIP 的逐文件哈希，在独立目录复现其 15 项合成探针；保留原始证据，不运行会覆盖原证据的主入口。
2. 只读取冻结公共 D 特征及原五折宿主/CRK 导出。核对数据哈希、导出元数据与恰好一次 heldout 覆盖。全 D/S/J 按总体、天气类、折、合并事件组报告合法宿主包络违反情况。主容差 1e-7，同时给出超过 1 个百分点的违反，避免把近零小波动当作严重失配。
3. 宿主逐小时合法包络为 `0.5*p_previous <= p <= 0.515 + 0.485*p_previous`。缺测不能填零后计入违反。分清 D05 的“跳升后回落 80%”与总 stock 回落超过 50%，报告交集。
4. 对所有固定 S 县—事件（726 个）做完整 144h 的凸二次 oracle 投影，初值固定为真实 y0，缺测小时仍受动力学约束但不计入目标。主设定 recovery cap=0.5；唯一敏感性为 cap=1，保持 damage cap=0.515。任意逐行逐时合法速率放宽了网络共享和门控约束，最优误差是宿主函数类误差的下界，不能解释成可实现的预测改善或因果贡献。每例保留可行原始解与对偶下界；未闭合的最优性间隙必须公开，不能把原始目标误称严格下界。最多 300 次 SLSQP 迭代、失败可按固定 1000 次对偶优化补证，不改样本或重训。
5. 复核 non-S 的严重假峰四格交集（两者均报、仅宿主、仅 CRK、均不报）。复核每折 FIT 的类别零风险归一化常数、S/J/non-S 权重与零预测误差份额；不得把 OOF 损失说成 FIT 损失。
6. 固定 fold1，使用已冻结 checkpoint 和标准化/标定 buffer，不重新标定。回放全部 OUTER 检查与原预测一致；对 FIT/OUTER 全部县检查实际地理基函数范数、谱、原地理/基函数线性项的量级。对 fold1 全 FIT/OUTER 的全时序做无梯度诊断：注入、时间常数、状态/读出、damage logit、gate、u、r、forget；峰时和固定时钟并列。只将这些量级视为定位线索，不凭量级替代梯度归因或干预试验。

## 判断边界

- 不从有限 oracle 下界单独判定宿主已经解释漏峰；同时比较真实峰幅、oracle 峰幅和原预测峰幅。
- 若包络的最低误差只占现有严重病例误差的小部分，则否定“恢复 cap 是主要充分解释”，保留观测接口问题本身。
- 检查全部 40 维组合仍是目标；小基函数值不等于信息为零，原始地理旁路也必须一起报告。
- 外部 scattering 算子的能量恒等式不等于时点幅度有界，也不自动解决 stock 包络、观测平均或目标失配。本轮不集成、不训练该候选，不增加 seed/NULL/新 arm。
- 不读取年度原始停电记录，不重建标签，不访问 sealed C 或稿件，不删尖峰。缺失原始季度小时支持使观测机制诊断保持有限。
