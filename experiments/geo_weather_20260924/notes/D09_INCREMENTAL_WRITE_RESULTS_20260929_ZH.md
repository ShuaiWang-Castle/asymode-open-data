# D09：新地理写入核的实际重训、失败证据与下一设计约束

日期：2026-09-29，22:40 ET。源与设计在计算前登记于
`eb91994fd124bc7178e7edc0b175c84113406b68`。六个fresh训练任务已全部完成900步，
训练与调度进程均退出；不是设计提案或旧模型缓存冒充的新训练。

**结论：这一候选没有通过固定推进门。** 新核比原CRK好，但严重病例相对无核的RMSE
只下降0.185%，95%合并事件组区间为[-1.583%, +0.656%]；全留出RMSE恶化8.719%，
non-S严重假峰从无核0个增加到78个。不能推进全D训练或宣称达到原10%目标。
更重要的设计证据是：改写入确实能改变训练内的峰恢复分布，却尚未显示稳定的留出受益。

## 1. 用户要求与这次真正实现的结构

核心仍是**天气→联合复杂地理调制→潜在冲击形成、累积与相互作用→停电轨迹**。
不能把地理缩成静态倍率、指定坡度×植被等少数组合，或只看overall均值。
保留完整geo40、任意组合空间、天气历史、事件分组和不利病例；模型不能用未来S标签或真峰路由。
最终要求仍是在完整公共D的原五折上，对预测窗峰值≥10%的S县事件，实现约10%或以上的
144h设计加权RMSE改善，同时检验普通县和假峰。数学约束与创新深度要服务于这些结果。

D07/D08指出旧写入`tanh(raw)-tanh(anchor)`的饱和地理锚点会限制一侧可用幅度，
但核已有大幅作用，损失并非忽略S，现有两条预测的真值二选一也不足以达到10%。
因此D09实际实现了一个可否证的**联合地理条件天气增量写入**，单独替换deposit：

```
v = u / sqrt(1 + ||u||²/64)
a(e) = 1 + 0.5*tanh(anchor(e)/L_g)
r = {a(e)*Bv + C[tanh(f(e)+Fv)-tanh(f(e))]}/(2sqrt8)
d_m = r_m / sqrt(1 + ||r_m||²)
```

B/C/F按精确谱范数控制，f及anchor由完整联合地理特征生成。地理调制天气通路，
不独立凭地理偏置生成deposit；零**标定隐藏输入**严格为零，不等于原始天气零必然无冲击。
直接天气通路绕过fusion的坐标饱和，非线性增量允许地理组合改变天气作用。
原四时标递推、旋转、读出、单damage MLP、目标与开口保持，新增可学习参数为0。

这是实际结构变化，不是等函数重参数化。deposit对64维标定输入和72维地理特征分别有
0.44194和0.88388的Lipschitz上界；这些不是原始天气/geo40到停电的全链上界。
拼接deposit容量上界约1.741，原共同上界2，幅度容量也发生变化。
rho/Q/出口和宿主敏感度没有随之获得新约束；低秩、方向抵消和训练覆盖问题仍可能存在。
完整公式、证明限制和FiLM、谱归一化等原始文献入口见
[设计登记](D09_INCREMENTAL_WRITE_DESIGN_20260929_ZH.md)及
[独立数学审查](D09_WRITE_CONTROL_MATH_REVIEW_20260929_ZH.md)。不能把这个组件修复包装为已成立的重大新理论。

## 4. 漏峰与错误大响应仍然并存

S的设计权峰幅比中位数，W/旧CRK/新分别为**1.575% / 1.664% / 1.442%**。
这里1.442%是“预测峰/真实峰”的百分比，不是预测停电比例1.442个百分点。
新vsW有146/300个S轨迹受益，但仅覆盖26.704%设计权；30个单位占76.049%正收益。
较多普通计数受益不等于高设计权病例得到普遍峰恢复。

按严重小时总数分层，新vsW在1小时和2–6小时分别恶化3.688%和6.031%，≥7小时仅改善0.569%。
最长连续段的对应变化为+3.839%、+5.328%、−0.581%；严重小时总数不能当作连续物理过程。
完整区间、支持数量、缺测与辅助面板结果全部保留于评分JSON。

non-S预测峰≥10%的严重假峰：**W 0 / 原CRK 127 / 新78**；设计权率为
0 / 1.49639% / 0.53377%。相对旧核消失84、新增35、保留43，净少49。
不是所有旧假峰统一缩小，也不能把“比旧核少”说成无核风险已解决。
观测全零的125单位中，>0.001微小报警W117/旧84/新97，这是不同口径，不能抵消严重假峰。

配对误差分解`2rΔ−Δ²`进一步表明：新vsW的S对齐收益230.565，修正幅度代价208.651，
净收益仅21.914；non-S对齐项−99.832、幅度代价1062.178，净损害1162.009。
新vs旧全体净收益中92.169%来自non-S；主要在修正旧错误响应，S新增有效响应仍不足。
同一新模型关闭出口后，S反而比开口略好（开口RMSE恶化0.077%），non-S也明显较好。
独立模型比较含联合训练的全部参数变化；closed是同模型条件干预，二者都不识别地理因果贡献。

## 6. 下一设计该处理什么

本轮淘汰的是这一具体deposit修复，未否定复杂天气×地理信息存在，也未证明所有核都无效。
下一设计必须同时满足“生成原先缺失的有效响应”和“不同事件下稳定分配”，不能只减小范数。

**首要候选问题是整个条件控制规则的协调与支持范围。** D09只约束deposit，
写入、保留时间、旋转和出口仍可通过原控制路径产生不同边界；原CRK本已共享fusion/head，
简单再加一个共享MLP不构成新的解决。应研究在完整联合地理×因果天气历史空间中，
这些控制如何作为同一个受控响应算子的不同参数共同变化，并检验其支持区域内的函数敏感度。
这是下一版的结构方向，不是本轮已验证的归因或已经实现的新arm。

具体可否证要求是：输入只包含当时可用的天气/地理/历史状态；不按S标签路由；
同时保留短时起涨与长期累积的有效变化。对同一固定FIT病例，应看响应覆盖、峰幅和残差对齐，
再比较其在不同事件训练组成下是否保持，而不能只看两个池的边际RMSE。
全事件普通县继续承担假峰检验，不能只在被抽中的小县集上证明选择性。

另一个需要分开的假说是**高维条件映射的优化条件**：全geo40及任意组合可用不等于
这些方向得到有效、稳定的更新。FIT-only、初始函数保持的特征重参数化可检验优化条件，
但不能与控制结构放大同轮混做，不能用OUTER定尺度，也不保持Adam训练轨迹。
现有结果不支持优先加大核/出口、改恢复cap，或只靠增加S损失权重解释失败。

下一比较应只改变一个已明确的结构因素，沿用固定名单、原事件留出、同预算和W/原CRK参照，
并登记有效峰恢复、训练组成稳定性和全县假峰这三项共同验收。
本轮固定候选预算已结束；没有自动加seed、NULL、新arm或全D。原10%全D目标没有放宽。

### 比单独改写入更深的候选结构，尚未实现或登记训练

更值得系统设计的是**联合地理×因果天气路径上的向量值控制核**。
令H_t为同一个damage MLP产生的截至t的小时路径，z_t=(g,H_t)，考虑

```
K(z,z') = normalized_K_allsubsets(g,g') * K_prefix_path(H,H') * B
F(z) = sum_l K(z,z_l) c_l
```

B是正半定输出耦合矩阵；F的各坐标共同生成deposit、log时间尺度、旋转参数及读出调制，
再映射到既有合法范围。地理支路保留40维及任意子集，不指定物理变量配方。
路径支路的候选是signature kernel：迭代积分可表示有序增量，Goursat PDE提供不显式展开
所有signature坐标的计算方式。必须加入时间并保留初始天气幅度，否则不能把路径几何
自动解释成对持续时间和天气水平的辨识；只用截至t的prefix，不能偷看以后天气。
这些性质来自[Salvi等的原论文](https://arxiv.org/html/2006.14794v9)，不是本数据已证明顺序是漏峰原因。

该式是可分离向量值核，提供共同输入几何及候选输出结构，参见
[Alvarez、Rosasco、Lawrence的核综述](https://arxiv.org/html/1106.6251v2)。
若B满秩、c_l自由，B可以被吸收进系数；仅写这个乘积没有自动增加控制协调约束。
协调机制仍需具体的联合系数/RKHS范数约束、低秩或输入相关输出结构，并与独立头对照；
低秩同样可能牺牲有效方向。因此不能仅凭这条公式宣称比原shared fusion更有创新或泛化能力。
这仍不足以保证正确响应：有限FIT地标、系数范数、kernel导数、路径归一化及谱尺度都需
明确设计与验证，才能给出数据支持区域内的控制敏感度界；低秩B也可能损失有效方向。
不能声称一个核乘积本身就是新理论、RKHS自动解决泛化，或县级geo40含有未观测的设施暴露。

这条研究方向的具体检验是：改变事件训练组成后，**同一批有支持的病例**仍保留有效对齐，
短时起涨与长时累积同时改善，且普通县的错误对齐和严重假峰下降。
先用一个只约束全控制场的有限对照区分“未受控边界”与“缺少路径几何”，再决定是否值得
实现路径核；两项不在一次训练中叠加，也不由本轮失败自动启动。
