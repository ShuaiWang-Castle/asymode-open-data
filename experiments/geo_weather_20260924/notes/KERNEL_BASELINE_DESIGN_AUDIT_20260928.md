# 下一版 kernel：现有结构、证据与实现验收审计

2026-09-28。只读审查 `src/asymode/gcrk.py`、宿主/训练/评分代码及已有 D03–D05/I18
紧凑结果说明；没有加载面板、大数组、checkpoint 或原始天气，没有拟合、重评分或新增实验。
本文是设计审计，不是新 arm 的执行登记；以下测试是实施时的待办，没有在本轮执行。

**现 GCRK 已有联合地理、多个坐标记忆和顺序敏感性。新结构应明确改变哪些受限通路，
不能把“首次加入联合/动态”作为贡献。必须继续位于唯一 damage MLP 内，允许全部 geo40
参与任意联合条件，不读未来 observed p，沿用同一 D 数据与既有评价。**

## 1. 当前实现及可保留部分

| 层次 | 已实现的精确结构/界限 | 保留价值与待验证限制 |
|---|---|---|
| 宿主接口 | damage 为 `Linear–ReLU–Linear–ReLU–Linear`，两隐藏层均 32；kernel 包装 `damage[2]`，复用原 W2/b2。Cin 是独立六维背景到第一隐藏层的无偏置线性项，共 192 参数；recovery 宽度 16 | 保留唯一损伤读出、恢复与库存联系及配对初始化。kernel 内参数生成器不等于第二个 damage 预测网络 |
| 地理预处理 | 拟合县事件行上的逐列 mean/std，NaN 标准化后置 0，clip ±5；再 `x=tanh(g/3)−center`。原核用逐县 `sqrt(.01+||x||²)`，I18 用一次冻结的拟合 RMS 标量 | 所有统计只来自拟合集；重复县未去重、无设计加权。I18 只改径向缩放，没有增加学习参数；不能混用 D03 去重县块平衡预处理 |
| 地理条件 | `z=tanh(U x_normalized)`，U 为 4×40；λ/a/Ω 三个头各有 32×4 条件权重。λ 经 sigmoid，a 经向量范数限制，Ω 经 exp/tanh | 全40维已能共同进入每个码，不是逐变量独立模型；但所有地理依赖均通过4个 ridge/tanh坐标。不能将这等同于4个PC，也不能称为任意40维响应函数或已识别4种机制 |
| 历史参考 | `b0=h0`；t=1…72 用严格过去隐藏均值；从72起固定为 h0…h71 均值。`v=h−b` | 因果的窗口参考；不是无记忆模型。参考固定后不随长事件阶段更新，这是否妨碍预测仍是假说 |
| 当前输入 | `q=v/sqrt(c²+||v||²)`；`d=sigmoid(4(||v||/c−θ))q`，`||d||<1`。c 是拟合隐藏偏离范数中位数，floor=1e−4；θ=q80/c | 一个全局幅度门和标量 c 同时作用于32维。geo40不直接进入 d 的方向/阈值；它通过后续条件参数影响状态。Cin 背景已进入 h，不能说 h 完全没有县信息 |
| 耗散与记忆 | `λ_j=expm1(1/96)+(expm1(1/2)−expm1(1/96))*sigmoid(l0_j+Vl_j z)`，初值 `expm1(1/16)` | 无输入时每坐标因子为 `1/(1+λ_j)=exp(−1/τ_j)`；τ∈(2,96)h，初值16h。已经是多坐标时间尺度；当前县参数在事件内固定 |
| 递推与交互 | `f_t=ν d_t, ν=min_j λ_j`；`[I+diag(λ)−(a f_tᵀ−f_t aᵀ)]e_t=e_(t−1)+f_t`，e初值0，`||a||<.5` | skew 每步 rank≤2，依赖当前输入；不同小时的变换通常不交换，因此已有顺序敏感性。结构固定为一个 a 与当前 f 张成的平面，并非通用多状态相互作用 |
| 有界性 | 对称部分 `I+diag(λ)` 正定，逆的2范数≤`1/(1+ν)`，故 `||e_t||≤1`。二阶求解行列式 `1+(aᵀH⁻¹a)(fᵀH⁻¹f)−(aᵀH⁻¹f)²≥1` | 保留稳定求解和有界状态；状态有界不自动保证参数可识别、状态依赖新结构的梯度稳定或不同轨迹收缩 |
| 读出 | `effect=ramp*tanh(alpha)*c*Ω⊙e`；Ω逐坐标∈(.5,2)，ramp=min(1,step/200)；`W2(h+effect)+b2`。原核有 `||effect||<2c` | 不是固定的 stock 振幅上限：c 和后续 W2/输出权重影响实际振幅。signed beta 允许增减隐藏响应；不能简单称为只能增加损伤 |
| 训练门控 | alpha=0；Vl/Va/Vg=0；独立私有初始化/随机流。整个 effect 每次训练 forward 以0.2概率丢弃，无逆概率放大；eval不丢弃。c/θ每10步及评价前从当前拟合隐藏序列刷新 | 第0步 ramp=0，opening与新核参数梯度为0；以后alpha先打开，条件头继而可学习，U还依赖非零条件头。不能误称200步内所有核梯度都为0。读出关闭诊断保持共同训练后的宿主权重，并非重新训练宿主 |
| 计算量 | r=4,G=40,d=32：新增 `rG+3dr+2d+2=610` 参数；I18仅增加buffer。递推前向/反向 O(BTd)，地理头 O(B(Gr+dr))；保存 f/e 级别 O(BTd) | 手写精确adjoint避免每小时一般autograd图；这不等于整个训练仅O(BTd)内存或成本，宿主MLP与数据驻留另计。ST另加3参数和O(BTkd)邻居混合；它不是本次默认时间核 |

代码来源：[GCRK](../../../src/asymode/gcrk.py)、[宿主](../../../src/asymode/asym_host.py)、
[训练](../../../src/asymode/gcrk_train.py)、[screen](../screen.py)。
相对路径按本文件所在 notes 目录解析。

一个可直接推导、但尚未进行归因实验的限制：若关闭 skew，并保持 d 恒定，
`e*_j=(ν/λ_j)d_j`。只要一个坐标采用长记忆、小λ，所有坐标的输入步长ν都随之变小；
较快耗散坐标的稳态幅度因此较小。这是稳定性构造带来的输入/耗散耦合，
不是本项目已经证明的漏峰原因。新设计若把各尺度输入与耗散解耦，须重新证明界限，
不能沿用原证明的结论而忽略ν关系。

## 2. 实际训练和评价口径

I18 不是训练模块通用 docstring 所说的 inner early stopping：其登记为 public D、
seed0、五个原 event folds、每折900步固定预算、每进程两线程。Adam 的宿主/核学习率为
3e−3，recovery 为3e−4。损失仍为观测小时 masked stock MSE；screen 按拟合集计算
`Z_r=Σ_i w_i Σ_t m_it y_it²`，每行权重取 `w_i/Z_r`，再整体缩放使拟合观测格平均权重为1。
Z_r=0 的类别在该拟合损失中权重为0。此设计标准化与 D04 各类原始 MSE 等权目标不同。

原 rollout 只以 observed p71 起步，之后按
`p_t=clip(p_(t−1)+u_t(1−p_(t−1))−r_t p_(t−1),0,1)` 自由运行。
u∈[0,.515]，r∈[0,.5]；损伤端含 logit smoother、occurrence gate 和 background，
因此损伤隐藏变化还需经过多个下游映射。observed p72…p215只在损失/评价出现。
现有外生天气是 ERA5 再分析输入；“不读未来 observed p”不等于已经完成业务天气预报验证。

I18/既有 stock 评价的 balanced gain 是各天气类相对 MSE 变化的等权平均，
完整144h为72…215；既有 pooled +1 口径使用73…215。D04 则先等权平均各类原始净变化
MSE再作比。下一核不得互换这两种 balanced 定义，不得把 D04 一步观测状态诊断当作
与神经自由运行轨迹相同的比较。

I18 最终主指标相对宿主 −2.3581% [−5.0810,+1.2176]，五类 −0.3655%
[−4.2081,+5.5440]，pooled +1 RMSE −0.4840% [−1.5296,+0.6394]。
synoptic_wind +2.0745% 超过其登记 +2% guardrail，最终明确为
`screen_failed_no_seed_expansion`；本设计讨论不重开它。
来源：[I18结果](I18_GEO_RMS_RESULTS_20260928.md)、[verdict](../results/v1/screen_i18_s0_verdict.json)。

## 3. 哪些限制已有证据，哪些仍是假说

| 问题 | 本项目已有证据 | 允许的设计动机；不能越界的结论 |
|---|---|---|
| 地理表示压缩 | D03纯geo40前6PC=79.0567%，90%描述方差需11方向；原核冻结诊断的z熵维2.73–3.28，没有普遍tanh饱和 | 应审计保留完整地理通路与联合响应；这些数字不证明4维码不足，也不决定新码秩 |
| 天气过程形状 | D03 mean-only保留68.9554%/73.1174%路径变异；固定8系数为97.6614%/98.2550%（设计/事件等权） | 保留天气路径是合理动机；不是停电预测增益、非线性流形维数或必须使用DCT的证据 |
| 状态单位界/门关死 | 原GCRK冻结状态中位/.9/最大=.108/.339/.794；deposit gate中位.264，小于.01的小时为零 | 已有结果反对“多数状态撞界”或“沉积门全关”的简单解释；不能据此排除尾部特定条件限制 |

| 地理与联合项 | D04 C/A五类净变化MSE+0.935%，D/B+3.065%；全部116次拟合未达登记梯度阈值。D05高stock匹配前值后仅28.89%设计权覆盖 | 不把D04曲面符号硬编码；不因边际地理弱便禁止高阶联合。当前结果也不证实动态地理一定优于静态地理 |

## 4. 候选设计的可执行验收清单（实施后执行，本轮未执行）
