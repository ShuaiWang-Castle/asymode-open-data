# 记忆、顺序与选择性更新：四篇原文核对及 damage 核的具体接口

主方案已收敛为 [联合地理控制的动态响应核](KERNEL_CONTROLLED_RELAXATION_DESIGN_20260928.md)。本篇第3节的前态条件隐式构造仅保留作比较，不是首版同时加入的模块；首版有界/收缩保证按主方案自己的方程核验。

日期：2026-09-28。范围：方法文献与设计审查；没有训练、读取大面板或改变现有模型。本笔记不是新 arm 的执行登记。所有 geo40 坐标均可进入所有条件头，不按物理名称指定天气—地理配对。

**结论：适合借鉴的是可检查的记忆更新机制，不是直接移植一个名为 Mamba 的完整模型。** 多尺度保留、内容依赖的写入/遗忘/读出以及路径依赖，可以放在唯一 damage MLP 的隐藏核里；这些论文没有验证县级停电，也不能证明 D05 漏峰由记忆不足导致。原 GCRK 已有递归、不同坐标耗散与天气驱动的 skew，不能把这些能力写成本轮首次引入。

## 2. 四种机制分别解决什么

**历史压缩的目标。** HiPPO 的投影对象是历史函数，而不是一个预设“累积灾害量”。因此可让潜变量保存若干不同时间分辨率的信息，但不能把每个潜坐标直接命名为含水率、倒树量或真实故障率。有限状态必然丢信息，所需记忆也不能由原文保证恰好落在本项目的事件窗内。

**固定时间响应。** S4 的递归形式为

\[
s_t=\bar A s_{t-1}+\bar B x_t,\qquad
y_t=C s_t+D x_t,
\qquad K_\ell=C\bar A^\ell\bar B.
\]

它已经能区分相同输入出现在不同 lag。这里借用的是明确的状态/读出接口；不是说已有核缺少顺序，也不是把固定卷积等同于无记忆。

**内容依赖的保留与更新。** Mamba 的机制可概括为 \(\Delta_t,B_t,C_t\) 随输入变化；在其标量特例中

\[
s_t=(1-\gamma_t)s_{t-1}+\gamma_t x_t.
\]

较大的更新门同时加快遗忘和摄入，不能把同一个门既解释为“冲击强度”又解释为“独立记忆时长”。县级核应分开记录衰减、写入幅度、读出增益，即使稳定性约束使其中一些量仍有耦合。本文建议是建模选择，不是该论文的停电结论。

**路径驱动。** Neural CDE 的核心是 \(ds=f(s)\,dX\)，并把时间放入 \(X\)。仅输入天气差分、又没有时间或水平信息，会使持续不变的高强度阶段难以继续驱动状态；当前水平、持续时间和变化方向必须区分。下面选择逐小时离散更新，因而不需要额外引入连续求解器或全窗样条。

## 3. 一个可展开到矩阵的核内参考构造

下面是本笔记的设计推导，不是四篇论文中的现成架构，也不是已批准的配置。它给出“联合条件映射”可以怎样落实，便于与主设计逐项比较。保留原 damage 第一层的 \(h_{it}\in\mathbb R^d\)、第二层 \(W_2,b_2\) 与最后读出；现有实现 \(d=32\)。

令 \(\widetilde g_i\in\mathbb R^{40}\) 只用训练折确定预处理。一个具体联合表示为

\[
e_i=[\widetilde g_i;\ \operatorname{SiLU}(E_2\operatorname{SiLU}(E_1\widetilde g_i+b_1)+b_2^g)],
\]
\[
q_{it}=\operatorname{SiLU}\!\left(Q_2\operatorname{SiLU}
  \left(Q_1[e_i;h_{it};s_{i,t-1}]+a_1\right)+a_2\right).
\]

例如地理隐藏宽度与 \(q\) 宽度均取 64，则 \(e\) 为 104 维，\(Q_1\) 的输入为 168 维。这些数字只说明规模，不是根据结果选择的默认值。所有矩阵稠密；geo40 有直接通路，避免所有信息先通过四维瓶颈。天气与地理在共同非线性映射内混合，前态也参与生成本步系数；没有人工指定灾害通道。社会/供电 context6 保留原 host 接口，不混称物理地理。

将每个 head 明确写成线性投影再施加约束：

\[
\tau_{it,j}=\tau_{\min}
 +(\tau_{\max}-\tau_{\min})\sigma(L_jq_{it}+b^\tau_j),
\qquad
\lambda_{it,j}=\operatorname{expm1}(\Delta t/\tau_{it,j}),
\quad \nu_{it}=\min_j\lambda_{it,j},
\]
\[
w_{it}=\sigma(W_wq_{it}+b_w),\quad
v_{it}=W_vq_{it}+b_v,\quad
d_{it}=w_{it}\frac{v_{it}}{\sqrt{1+\|v_{it}\|_2^2}}.
\]

\(w\) 为标量写入门，\(\tau_j\) 为各潜坐标的时间尺度。初始 \(\tau_j\) 可按对数分布覆盖预先规定的快慢范围，但范围必须由可用历史与训练内选择确定，不能把某个潜坐标指定为某一种物理过程。\(\Delta t\) 使用实际小时长度；在无 skew、系数固定时，\((1+\lambda_j)^{-1}=\exp(-\Delta t/\tau_j)\)。因此这里的 \(\tau\) 是 e-folding 时间，而不是半衰时间；后者为 \(\tau\log2\)。

用多个全向量潜在方向生成 skew，例取 \(U_{it},V_{it}\in\mathbb R^{d\times R}\)：

\[
U_{it}=\operatorname{reshape}(W_Uq_{it}+b_U),\quad
V_{it}=\operatorname{reshape}(W_Vq_{it}+b_V),
\]
\[
\widehat S_{it}=U_{it}V_{it}^{\top}-V_{it}U_{it}^{\top},\qquad
S_{it}=\omega_{\max}\frac{\widehat S_{it}}
 {\sqrt{1+\|\widehat S_{it}\|_F^2}}.
\]

例如 \(R=4\) 的 skew 秩至多 8；这扩大原单一 rank-2 结构，但仍是有限容量约束，不能称任意状态转移。每个 \(U,V\) 头都看到完整联合表示，低秩不对应手工物理分组。

状态与原隐藏层连接为

\[
\boxed{\big[I+\operatorname{diag}(\lambda_{it})-\nu_{it}S_{it}\big]s_{it}
       =s_{i,t-1}+\nu_{it}d_{it}},
\]
\[
r_{it}=r_{\max}\tanh(W_rq_{it}+b_r),\qquad
a^{(2)}_{it}=W_2h_{it}+b_2+eta\,O(r_{it}\odot s_{it}),\quad |\beta|\le1.
\]

\(O\) 也须限制算子范数或报告其有效增益。保留 \(W_2h\) 的即时通路，让迅速变化不必全部通过平滑状态。输出仍由原 damage MLP 剩余层及 host 的既有 stock 递推产生；潜状态只是预测表征。新增内部 heads 生成核系数，不各自输出一条停电预测。

\(w\) 与 \(\tau\) 有不同 head，并不意味着统计可识别；forcing 上界仍通过 \(\nu\) 与遗忘约束耦合。若改变写入上界、原 prefix-reference、阈值、原 geocode 或 host 的 rate-inertia，必须分别记为设计变化。此参考式将 \(\beta=0\) 可退回 host；**它没有自动精确退回原 GCRK**。原核的精确嵌套需保留原分支和全部校准/归一化细节，不能仅凭“残差初始化为零”声称成立。

## 4. 可证明的稳定性，以及不能顺带声称的性质

本节是对上述式子的直接代数检查。设初始 \(\|s_0\|_2\le1\)，\(\lambda_j>0\)，\(S^\top=-S\)。令 \(M=I+\operatorname{diag}\lambda-\nu S\)，则

\[
x^\top Mx\ge(1+\nu)\|x\|_2^2,
\qquad \|M^{-1}\|_2\le(1+\nu)^{-1}.
\]

由于 \(\|d_t\|_2\le1\)，

\[
\|s_t\|_2\le\frac{\|s_{t-1}\|_2+\nu_t}{1+\nu_t}\le1.
\]

这在系数依赖已知前态时仍成立；没有要求冻结天气或地理。然而，完整 Jacobian 还包含 \(\partial\lambda/\partial s_{t-1}\)、\(\partial S/\partial s_{t-1}\)、\(\partial d/\partial s_{t-1}\)，所以它**不是不同轨迹之间收缩或梯度稳定的证明**。必须检查条件头敏感性、长链 Jacobian、解方程残差，以及自动微分；不能复用只对固定系数推导的反向公式。稳定的隐藏核也不能解除 host 的发生门、幅度上界与额外平滑所造成的瓶颈。

同样，负对角连续状态矩阵与正离散步长可保证单步线性保留因子小于 1，但不自动控制任意输入依赖的写入/读出，或神经条件头的整体梯度。不能用“采用 SSM”代替明确的条件。

## 5. 强度和顺序如何区别，如何检查

先看条件量不依赖前态的局部仿射步 \(F_x(s)=A_xs+b_x\)。两次输入交换后的差为

\[
F_b(F_a(s))-F_a(F_b(s))
=(A_bA_a-A_aA_b)s+(A_b-I)b_a-(A_a-I)b_b.
\]

这是本笔记的代数展开。即使两个 \(A\) 对角且互相交换，写入项也可使路径不同；因此“必须有非交换矩阵才有顺序能力”不成立。反过来，出现不同预测不证明非线性 compound effect：固定 LTI 也会因为 lag 权重不同而给不同结果。前态条件化可使先前天气改变后来输入的有效响应，但这只是可表达性。

有区分力的检查应分别考察：

1. 固定顺序、改变幅度/持续时间，观察即时通路、写入、遗忘与读出的变化；不把四者合并为一个模糊“强度门”。
2. 保留所有通道联合的小时向量，比较具有相似幅度分布/总量但顺序不同的**有支持自然样本**；合成反序仅作模型敏感性检查，不能当真实天气反事实。保持所有通道同步可避免逐列乱序制造不存在的组合。
3. 在同一模型与信息集下，比较固定时间响应、仅地理条件、天气条件、再加前态条件；既记录拟合后的比较，也分清冻结模型内开关的含义。全向量地理进入所有层级，不先筛显著变量对。
4. 用含瞬时峰、长平台、重复输入、反序输入、间隔拉长和事件重置的合成序列，检查有限输出、因果性与预期退化关系；不用峰值观测反向决定隐藏初始化。

时间索引必须按预测任务说明。当前数据有区间累计天气与小时 stock 聚合的错位；这些文献不会修正观测口径。若目标要求严格过去天气，应在进入核前固定 shift；禁止通过整窗样条或 held-out 标准化偷看之后的信息。过去 warmup 只可消化获准的天气/上下文，县—事件之间必须重置状态。

## 6. 计算与证据边界

长度 \(T\)、状态宽度 \(d\) 下，每步直接 dense 求解为 \(O(d^3)\)，不是 Mamba 那种对角 selective scan 的成本。采用上述 rank-\(2R\) skew，可用对角加低秩求解降至约 \(O(dR^2+R^3)\)，另加条件 heads 的矩阵运算。前态进入 heads 后通常不能使用输入预先确定的仿射并行 scan；CPU 逐步耗时与反向内存需实测，不能照搬论文 GPU 吞吐。在线只需单条轨迹的 \(O(d)\) 状态；训练若保留全部中间量，内存仍随 \(T\) 增长。

D05 的漏幅、错时和快速反转是开展这些比较的理由，不能区分“记忆不够”“同一天气不同地理的转换错误”“host 输出压缩”“损失权重”或观测问题。县平均、有限事件与未测设施暴露也限制对潜在机制的解释。上述四篇提供表示与计算工具；未来证据仍须来自同信息集、事件留出、数值收敛、尾部幅度/假峰/时点及连续地理支持的共同检验。总体 MSE 不能单独否定局部现象，局部模型灵敏度也不能独自证明物理机制。
