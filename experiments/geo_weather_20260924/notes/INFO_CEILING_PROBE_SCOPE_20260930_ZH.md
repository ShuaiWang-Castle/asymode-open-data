# 信息上限探针：范围与判定规则（运行前固定，2026-09-30）

PI 要求由 Claude Code 亲自执行。目的只有一个：在与各个核相同的按事件留出五折上，用灵活的非神经模型逐层加入公开信息源，测量严重县-事件 S 的误差最多能降多少，以及每一类信息是否带来可迁移的增量。**不训练任何神经网络，不改动任何已有源码、检查点或结果文件，只用公共 D，不读 sealed C，不碰 `paper_v1/`。**

## 1. 数据与留出
- 公共 D：`data/interim/panel_v1/features_v1D.npz`，8,457 个县-事件，预测窗为第 72–215 小时。
- 留出：冻结的 `splits_v1D.json` 中 `event` 五折。第 k 折用其余四折的 dev 单位训练，预测第 k 折的 outer 单位。
- S：预测窗观测峰值 ≥ 10%。指标权重使用设计权重 w（已截断），并使用观测掩码 m。

## 2. 信息源（逐层嵌套）
| 代号 | 内容 |
|---|---|
| B | 起报状态：y0、四个前缀摘要、log 用户数、天气类别、起报月份 |
| W | ERA5 天气：42 个损伤特征（14 个原始通道和因果摘要）、8 个邻县天气摘要，以及窗口内的累计量 |
| G | geo40 县级地理，加上 6 个按人口加权的县内暴露量（林冠、高林冠人口比例、排水不良、高程及其离散度） |
| Gp | 与 G 相同，但按县整体打乱（固定置换，seed 20260930），是地理的 null |
| C | 县情 5 项：城乡代码、人口密度、合作社比例、公用事业数、SAIDI |
| H | 县的历史易损性，来自 EAGLE-I 2014–2017（早于总框起点 2018-07-12，与任何开发事件都不重叠） |
| Hp | 与 H 相同，但按县整体打乱，是历史易损性的 null |
| R | HRRR 天气：30 个只含天气的节点级量（阵风及其超过当地极值的程度、降水相态、冰和湿雪荷载、切变、螺旋度、雷达回波、闪电、暖层），不含林冠/排水乘积 |

## 3. 模型变体
- M0 = B
- M1 = B+W
- M2 = B+W+G；M2p = B+W+Gp
- M3 = M2+C
- M4 = M3+H；M4p = M3+Hp
- M5 = M4+R
- M1H = B+W+H；M1R = B+W+R

## 4. 学习器（超参数固定，不在留出折上调参，不早停）
- LightGBM 4.7，L2 目标，设计权重 w。
- 超参数：学习率 0.05，31 叶，特征抽样 0.8，行抽样 0.8，L2 正则 1，seed 20260930，3 线程。
- **轨迹探针**：每个县-小时一行，目标为 y_t。400 棵树，每叶至少 200 个样本；训练只取偶数时效小时，预测全部小时，裁剪到 [0,1]。
- **事件探针**：每个县-事件一行。300 棵树，每叶至少 40 个样本。
  - 回归目标为 log(峰值 + 0.001)；
  - 另设一个判断是否属于 S 的二分类器。

## 5. 指标与比较
- **主指标**：S 上完整 144 小时的设计加权 RMSE，与宿主 AsymODE（W+Cin，5 个 seed 平均；另报 seed 0）比较。区间用天气类别内的 family cluster bootstrap，2,000 次，seed 20260924。
- **同时报告**：全体和非 S 的 RMSE、严重假峰数（非 S 但预测峰值 ≥ 10%）、S 的预测峰/真实峰中位数。
- **事件探针**：
  - 判断是否属于 S 的设计加权 AUC 和 AP；
  - S 上的峰值 RMSE；
  - 与宿主预测峰的对比。

## 6. 判定规则（运行前固定）
1. **上限**：如果最强的轨迹探针相对宿主在 S 上的 RMSE 改善点估计 < 3%，或区间跨 0，则认定"这批公开输入不支持约 10% 的 S 改善"（仅就这一类灵活模型而言）。
2. **某类信息带来可迁移增量**的条件是两条同时满足：
   - 加入该信息后，S RMSE 的改善区间不含 0；
   - 对 G 和 H，真实版本还要好于各自的打乱版本，区间同样不含 0。
3. 严重假峰和非 S 误差必须一起报告，不能只看 S。

## 7. 计算
单进程，nice 10，3 线程。事件探针在前，轨迹探针在后。输出：
- `results/v1/info_ceiling/*.json`；
- 本地预测保存在 `runs/geo_weather_20260924/info_ceiling_20260930/`；
- 报告写在 `notes/INFO_CEILING_PROBE_RESULTS_20260930_ZH.md`。
