# 下一轮 kernel 方案与单 seed 筛选草案（2026-09-28）

**状态：proposed，尚未获 PI 批准；本文件不授权实现或训练。** 本轮只提出三个有不同目的的方案。
依据为本仓库公开数据设计、现有代码和 [核文献笔记](LITERATURE_KERNELS_20260928.md)。不改论文，不触及封存确认批次。

建议优先次序：**I15（A）恢复历史核 → I16（B）恢复核内的服务区联系**；I17（C）县内暴露节点核留作幅度与输入聚合问题的备选。A、B 用同一天气来源与损伤 MLP，先分清恢复结构是否有价值。B 的公共图输入审计可以先做，但开跑仍须 PI 同意。

## 1. 架构必须先承认的限制

**恢复不是已识别的瓶颈。** 对任意一个小时，观测给出的是

\[
\Delta p_t=u_t(1-p_{t-1})-r_t p_{t-1}.
\]

这是一个方程、两个率。大量不同的 \((u_t,r_t)\) 可以生成相同的 stock 路径；在 \(p_{t-1}=0\) 时恢复率更完全不影响当前值。没有设备级失效/恢复记录时，率只是预测模型中的有效率，不能声称已经恢复出真实抢修效率。

固定损伤率后，即使把恢复完全关闭，也只有

\[
p_t^{r=0}=1-(1-p_{71})\prod_{v=72}^t(1-u_v)
\]

这一条最大累积路径。因此先用已有预测做零恢复上界诊断：若它仍达不到实际量级，单改恢复不可能弥补相同损伤输入的幅度缺口；若能达到，也不证明原恢复率是原因。训练时 u 会共同调整，所以该上界是冻结模型的诊断，不能当新模型能力上限。

**本次公开 D 诊断已支持这个限制。** [轨迹诊断](TRAJECTORY_DIAGNOSTICS_20260928.md) 中，726 个实际峰值至少 10% 的县事件，宿主/时间核/时空核预测峰值比中位数为 0.080/0.090/0.093；冻结 u 并令 r=0 后仍有 66.5%/63.8%/63.1% 达不到实际峰值。实际峰后占宿主 SSE 的 61.8%，却不能据此说恢复太快：在实际与预测各自半衰时间都可观测的完整大停电子集中，预测减实际的中位数为 +4 h/+3 h/+3 h，反而偏长；这些是有条件的描述，并非对完整总体恢复率的识别。幅度 oracle 消除的 SSE 远大于仅作 ±24 h 平移（宿主 41.67% 对 2.27%；二者联合 54.10%），但它使用未来结果，只说明形状错配，不是可实现增益。

**现有空间图只是抽样县图。** 当前 150 km、最多 8 邻居的图来自每场已抽中的县。漏邻居与边界随样本变动，不等于配电网、服务区或外援路径；行归一化也不等于抢修人数/客户数守恒。相似天气的邻县，仅交换状态不会凭空产生缺失的县间差异。

已有 40 维地理中包含 50 km 平滑的 relief、canopy、windthrow susceptibility 和 poorly drained share，也包含若干共位量。因此“加平滑地理”本身不构成新方案；I17 必须保留局部天气与地理的对应，并在县级汇总前形成非线性响应，不能仅重做县均值。

**稳定至少有两种含义。** 状态永不越界与两条相近输入路径始终接近不是同一性质。所有方案承诺前者；若读预测 stock，后者须满足下文小增益条件，不能只引用 GCRK 的单位界。

## 2. 共同接口：一个损伤 MLP，核只进入隐藏层

保留当前宿主的损伤网络、发生门、背景率、logit 平滑及人口 stock 更新。原恢复网络写为

\[
h^R_t=\mathrm{ReLU}(W^R_1x^R_t+b^R_1),\qquad
\ell^R_t=w^R_3{}^T\mathrm{ReLU}(W^R_2h^R_t+b^R_2)+b^R_3.
\]

恢复核仅替换中间隐层输入：

\[
\tilde h^R_t=h^R_t+\eta_s\tanh(\alpha_R)c_R\Omega_i e^R_{i,t},\qquad
r_t=\tfrac12\sigma\!\left(w^R_3{}^T\mathrm{ReLU}(W^R_2\tilde h^R_t+b^R_2)+b^R_3\right).
\]

\(c_R\) 只从训练折的隐藏状态标定；\(\Omega_i\) 的对角元在 \((1/2,2)\)。地理和新增服务区属性只决定核的耗散、方向、增益或核内联系，不追加手工灾害率，不增加第二个损伤 MLP，不加入县 ID embedding。

**精确配对且可启动的初始化。** 先按同一 seed 构建完整宿主并复制相同参数，再用独立随机数流初始化核。令 \(\alpha_R=0\)，但沉积投影、状态路径和原恢复 \(W_2^R\) 非零；可令 \(\eta_s=\min(1,(s+1)/200)\)，从很小的正值开始，而不是同时把 warmup 与开口都置 0。这样第 0 步的预测逐元素等于宿主，且通常

\[
\left.\frac{\partial \tilde h^R_t}{\partial\alpha_R}\right|_{0}=\eta_0c_R\Omega_i e^R_{i,t}\ne0.
\]

其他核参数在第 0 步因零开口而没有预测梯度，开口更新后开始学习；这是透明的分阶段启动，不应声称所有新增参数初始都有梯度。不能把开口、沉积投影和读出同时设为 0。用非退化合成输入检查新分支总梯度，不能要求每个样本、每个参数都非零。地理映射可用小的非零私有初始化，因为零开口已经保证宿主等价。

所有统计标准化、地理中心、尺度、聚类只用训练折拟合；前缀观测最多读到小时 71。预测小时只用给定天气、静态公共属性与模型自己的历史，不能 teacher-force 真实停电。

## 3. I15（方案 A）：恢复隐藏层的冲击历史核（首选）

### 机理与公式

当前恢复 MLP 每小时重算，缺少一个专门记录“此前经历了多少种、怎样排序的冲击”的隐藏状态。用原损伤网络的隐藏状态 \(h^U_t\)、其因果前缀偏离 \(v^U_t\)、原损伤率 \(u_t\) 驱动一个 16 维恢复状态：

\[
d^R_{i,t}=\operatorname{bnd}\!\left(B_v v^U_{i,t}/c_U+B_u u_{i,t}/s_u
                 +B_p p_{i,t-1}/s_p\right),\quad
\operatorname{bnd}(x)=x/\sqrt{1+\|x\|_2^2},
\]

\[
[I+D^R_{i,t}-\nu_{i,t}S(a_i,d^R_{i,t})]e^R_{i,t}
=e^R_{i,t-1}+\nu_{i,t}d^R_{i,t},\quad
\nu_{i,t}=\min_jD^R_{i,t,jj}>0,
\quad S(a,d)=ad^T-da^T.
\]

首个最小版本取 **\(B_p=0\) 固定、\(D^R_{i,t}=D^R_i\)**，只问冲击历史是否改善恢复；这保留率网络的外生可计算性。初始化记忆为 16 h，允许范围先沿用 2–96 h，避免同时搜索时标。输入幅度 \(u/s_u\) 保留为独立坐标，不能只留单位方向；\(s_u\) 从训练折预测率的稳健尺度给定并记录饱和分布。

若 PI 希望第一轮直接检验“积压存量”，可改为 \(B_p\ne0\) 的闭环版本，但它是明确另一个设计选择，须注册并通过下文反馈约束。不能在 A 无增益后悄悄添加 stock，再称同一次筛选。核在前缀只用已知信息热启动：最小版用前缀隐藏天气沉积，前缀尚无现成 \(u_t\) 时该通道置零；stock 版可用已观测 \(p_{t-1}\) 并带遮罩，缺失值只作因果填补。

地理条件为训练折中心化的 \(z_i=\tanh(U\tilde g_i)\)，\(g_i\) 包含已有地理以及已公开的 utility/城乡属性；它只决定 \(D^R_i,a_i,\Omega_i\)。不要把 SAIDI 换成事件年份值；沿用 2017 年公开值与缺失标记规则。\(a_i\) 继续限制 \(\|a_i\|<1/2\)。

### 文献对应、数据、成本

对应 Reinhart 的历史影响与背景分离、Chen–Amos–Nickel 的隐藏历史状态、AntisymmetricRNN 的方向/耗散分离与 Lipschitz RNN 的反馈分析；这是这些结构在 stock 预测上的新假设，非点过程模型复现。需要已有 ERA5、EAGLE-I 前缀、公开静态地理与 EIA/ERS/Census 属性，无新增数据下载要求。恢复沉积投影每小时 \(O(d_Rd_U)\)，核解算 \(O(d_R)\)，总 \(O(NT(d_Rd_U+d_R))\)，\(d_R=16,d_U=32\)；朴素反传存储 \(O(NTd_R)\)，闭环版还需顺序更新 stock，不能继续把全窗恢复率先行向量化。

### 能推翻它的结果

即便核状态活跃，若 A 在同天气、同损伤 MLP 下不胜宿主，或仅通过极慢恢复把已有小损伤长期堆积且增加小停电误报，则没有足够理由继续加恢复自由度。无训练的恢复曲线错配诊断只是排序依据，不能用按真实峰值挑选的子样本决定 keep。

## 4. I16（方案 B）：恢复核内的服务区负担与延迟联系

### 机理与公式

在 A 的同一个恢复状态中加入公共服务联系，不另建输出头：

\[
e^R_{i,t}=M^{-1}_{i,t}\left[(1-\kappa_i)e^R_{i,t-1}
 +\kappa_i\sum_jA^R_{ij}e^R_{j,t-1}+\nu_{i,t}d^R_{i,t}\right],
\quad 0\le\kappa_i\le1,
\]

\[
A^R_{ij}\propto \mathbf{1}_{j\in\mathcal N_i}
 \underbrace{\sum_u b_{iu}b_{ju}}_{\text{公共 utility 服务重叠}}
 \exp[-d_{ij}/\ell-\gamma\|z_i-z_j\|^2],\qquad \sum_jA^R_{ij}=1.
\]

\(b_{iu}\) 是公开 EIA-861 服务县关系的归一化覆盖权重，**不是已知的县内客户分配比例**；资料不支持比例时就明确使用二元服务关系。关系年份先固定为前研究期 2017 并核对到 2020 县域，不能用后来更新的网络冒充事件前已知网络。无联系时自环。\(\mathcal N_i\) 必须从固定公共县域/服务区列表建立，不能由当前抽中的目标县决定。外部上下文县只有天气与静态属性；先以天气驱动的恢复潜在状态作上下文，不借它们的预测窗实际停电，也不对其加监督损失。没有前缀时不能把 0 当已观测存量；用缺失标记和天气状态。

**图边界也属于待批准设计。** 开跑前必须固定扩展域与边界递推规则：若上下文状态继续参与同样的空间递推，要构建所需图闭包并估算全部节点天气成本；若只采用一跳上下文，则边界县使用预先规定的本地天气核/自环，不得临时丢边后重归一化。该选择同时冻结在信息 NULL 中，不能随目标县抽样或结果改变；当前复杂度中的 N、E 指最终扩展域。

一次小时混合已经产生因果多跳时滞。只有后续需要时再注册固定延迟槽 \(A^{(\tau)}e_{t-\tau}\)，满足总权重不超过 1；当前不额外搜索延迟、风向、多个图。\(\gamma\) 从小正值开始、\(\kappa\) 可从小正值开始，因为整个恢复开口为零已保证第 0 步等于宿主；避免空间开口与相似度同时零初始化的链式梯度抑制。

地理/utility 只参与核的条件和核内联系。该结构编码的是“共享服务背景下的历史负担联系”假设；**没有人员派遣数据时不能称为已识别的抢修容量/队伍流**，也不强行把任意相似度图解释为电网。正 Markov 混合仍会平滑，所以 A 的本地状态与本地驱动必须保留；如果两县所有输入相同，本方案仍不能让它们自动分化。

### 文献对应、数据、成本

DCRNN 支持在递推里使用有向/双向图联系，GRAND 支持检查 Markov 混合的最大范数界，非平稳点过程核支持由属性决定联系而不止地理距离。EIA 服务县只提供代理关系；需先审计覆盖、孤立县、跨州公用事业和资料年份，并在采集上下文天气时严格沿用封存掩码，不扩读任何禁止窗口。固定每县最多 8 个公共上下文邻居时，核成本 \(O(T(N+E)d_R)\)，还要计入上下文县天气投影成本；图扩展的实际倍数先以只读清单估算，不能照搬当前 ST 运行时间。

### 配对与幸存者检验

从共同的零恢复开口初始化，仍第 0 步等于宿主；若另作 B 对 A 的精确初始等价，固定相同 A 参数并令新 \(\kappa=0\)、\(\gamma>0\)，共同的 \(\alpha_R=0\) 会令第 0 步空间份额的预测梯度也为零，必须在恢复开口更新为非零之后，再核验 \(\partial L/\partial\kappa\) 的可用梯度；不能声称两级零开口下空间参数马上学习。B 先与宿主、普通 GCRK 比；若幸存，训练一个保留距离分布、度数、上下文数和服务区规模分层、但交换服务联系的匹配 null。若只胜宿主而不胜该 null，结论只能是多县历史处理有用，不能说真实服务联系提供信息。

## 5. I17（方案 C）：县内人口暴露节点核（幅度问题的备选）

### 机理与公式

用公开人口节点分为预先固定的少量地理类型（例如 \(K=4\)，只用训练折静态地理拟合类型），每类一个状态。用**同一套**损伤第一层参数在节点/类型天气上得到 \(h^U_{i,k,t}\)，各类地理仅条件化其核，最终仍只进入原县级损伤 MLP 的隐藏层：

\[
e_{i,k,t}=M_{i,k,t}^{-1}(e_{i,k,t-1}+\nu_{i,k,t}d_{i,k,t}),
\quad
\tilde h^U_{i,t}=h^U_{i,t}+
 \eta_s\tanh(\alpha_U)c_U\sum_{k=1}^{K}\pi_{ik}\Omega_{ik}e_{i,k,t},
\quad\pi_{ik}\ge0,\ \sum_k\pi_{ik}=1.
\]

这里有多个核状态，只有一套共享损伤 MLP 参数和一个损伤输出；不使用多个预测头取平均。节点的原始天气和同规格因果天气摘要经过共享权重，不使用“林冠 × 冰荷载”手工灾害率。地理影响先在局部核里发生，再按人口权重汇总；人口是客户暴露的代理，不宣称等于电力客户分布。类型内平均仍有聚合损失，须明确这是有限节点近似。

首轮保持 ERA5 来源，避免把 HRRR 来源增益与核结构增益混合；若数据表明同县 ERA5 节点天气几乎相同，本方案的信息增量主要来自地理暴露，应先报告这一事实。HRRR 可作为后续单独注册的来源变体，结构配对 null 必须用相同来源和节点。

### 文献对应、数据、成本、初始化

对应 Okawa 的上下文核混合、Dong 的少数非平稳模式；PDE-GCN 对平滑丢失局部差异的提醒支持保留局部状态，但不直接证明该人口加权方案。需要已有公开 WorldPop 节点、USGS/NLCD/NRCS 地理及同源节点天气；零 \(\alpha_U\) 保证精确宿主初始化，非零节点沉积保证可启动开口梯度。单位状态的凸权重汇总范数不超过 1（含 \(\Omega\) 时不超过 2）；核心核成本 \(O(NKTd_U)\)，共享第一层计算另为 \(O(NKTd_Ud_x)\)，状态存储 \(O(NKTd_U)\)，约为单核 K 倍，初期只跑一个训练进程做资源评估。

若幸存，匹配 null 保留天气节点、人口权重、参数数与训练流程，只打乱县内地理到节点的对应，并明确它检验的是 **共位信息**；另训地理均值/匹配地理置换 null 才能问“地理本身是否有信息”。不要用换成县平均天气的不同输入模型代替同结构 null。

## 6. 共同的有界性与 stock 反馈条件

### 6.1 状态与人口比例的前向界（A/B/C）

以 \(\|e\|_{\infty,2}=\max_i\|e_i\|_2\) 衡量多县状态。设 \(D_{i,t}\succeq\nu_{i,t}I\)、\(\nu_{i,t}>0\)、\(S^T=-S\)、\(\|d_{i,t}\|_2\le1\)。则

\[
\|M^{-1}_{i,t}\|_2\le(1+\nu_{i,t})^{-1},\qquad
\|e_{i,t}\|_2\le\frac{\|Pe_{t-1}\|_{\infty,2}+\nu_{i,t}}{1+\nu_{i,t}}.
\]

局部 A/C 的 \(P=I\)，B 的 \(P\) 非负、行和为 1，所以若初态范数不超过 1，则所有时刻不超过 1；有限延迟凸组合也保持该界。该结论允许天气依赖 \(D_t\)，但实现时其梯度须重推，不能复用只接受固定 \(D\) 的伴随。

宿主 stock 可写成

\[
p_t=(1-p_{t-1})u_t+p_{t-1}(1-r_t)\in[0,1],
\]

因为 \(0\le u_t\le0.515\)、\(0\le r_t\le0.5\)。这是两个落在 \([0,1]\) 内值的凸组合；不需要错误地要求当前实现的 \(u+r\le1\)。上述证明也覆盖 stock 驱动沉积，但**只覆盖值域界**。

### 6.2 若启用 stock 驱动：闭环扰动的充分条件

以下是本方案的直接推导，不是文献中的停电结论。固定同一外生天气和地理，令 \(D,a,P\) 不依赖 stock，\(u\) 也不依赖 stock；沉积的 stock 通道满足
\(\|d(p)-d(p')\|\le L_p\|p-p'\|_\infty\)。由 resolvent 恒等式及 \(\|S(a,\Delta d)\|\le2\|a\|\|\Delta d\|\)，可取

\[
q=\max_{i,t}(1+\nu_{i,t})^{-1}<1,\qquad
b=\max_{i,t}\frac{\nu_{i,t}(1+2\|a_i\|)}{1+\nu_{i,t}}L_p,
\]

使 \(\delta e_t\le q\delta e_{t-1}+b\delta p_{t-1}\)。令恢复映射对核状态的 Lipschitz 上界为

\[
L_r\le \frac{0.5}{4}\|w_3^R\|_2\|W_2^R\|_2
       |\eta_s\tanh\alpha_R|c_R\|\Omega\|_2,
\quad a_* =\sup_{i,t,p}|1-u_{i,t}-r_{i,t}(p)|\le1.
\]

于是有限时域的两条路径满足分量不等式

\[
\begin{pmatrix}\delta p_t\\\delta e_t\end{pmatrix}
\le
\begin{pmatrix}a_*+L_rb&L_rq\\b&q\end{pmatrix}
\begin{pmatrix}\delta p_{t-1}\\\delta e_{t-1}\end{pmatrix}.
\]

统一收缩的一个充分条件为

\[
a_*<1,\qquad L_rb<(1-a_*)(1-q).
\]

当前宿主没有显式正率下界，所以不能无条件声称 \(a_*\) 远离 1。最小 A 固定 \(B_p=0\) 因而 \(b=0\)，没有新增 stock 反馈环；若采用闭环版，必须用受限 \(B_p\)/读出增益给出可验证的界，或只声称前向有界并报告实际有限窗敏感度，不能把后者包装成统一收缩。也不能把真实的 stock 梯度 detach 后再声称优化了完整闭环目标。

对于上述 bnd 投影，\(L_p\le\|B_p\|_2/s_p\)，所以限制 stock 通道幅度有直接可核验的意义。如果以后让图权重或耗散也依赖预测 stock，须把 \(\partial P/\partial p\)、\(\partial D/\partial p\) 的项加入 b；上面这条界不能原样引用。B 使用固定属性图、外生天气状态，所以避免这个额外回路。

## 7. PI 同意后才执行的筛选方案

**先纠正旧结果的指标名称。** 按注册的 tropical+winter 头条估计量重算，现有时空核相对宿主为 −1.28% [95% −3.27,+1.72]，相对普通 GCRK 为 −2.38% [−4.84,−0.294]；五类均衡相对宿主仍为 +0.30%，heavy rain 为 +2.60%。所以不能再写“注册主估计量无改善”：正确表述是主估计量点估计改善、相对宿主区间跨 0，并且整体五类检查不通过。此前不追加 seed 的决定按 PI 指示保留；以下把注册 keep 与拟议的更严格整体筛选门槛明确区分。

| 项目 | 草案 |
|---|---|
| 数据 | 只用现有 D 的 81 系统、8,457 县事件；按既定 family 留出的 event 五折，216 h 窗口、72 h 前缀、144 h 开环；C 不构建、不读取、不评估。 |
| 顺序 | PI 先选 A 的无 stock / stock 版本及是否同意 B/C；首个获批方案 seed 0 五折，每折 900 步，与现有 `v1_host_s0`、`v1_gcrk_s0` 配对。只改被批准的结构，保留同源天气和一个损伤 MLP。 |

**A 的 null 必须先冻结主次。** 建议主 null 为从头训练的匹配地理置换：保留完整描述向量、核参数数、开口/标定/损失/训练流程，把地理向量与正确县的对应破坏，按事先固定的宏观区域、密度与服务背景匹配，且同一县在所有事件中使用同一 donor；它问“正确的地理对应是否胜过同容量、近似同分布的异质条件”。匹配变量、置换种子与空间尺度保留诊断要在看新结果前写清，不能事后挑最弱 null。一个辅助的共享地理常量模型则让所有县使用训练折的同一原始地理向量，仍从头训练同一个核；它问“允许县间地理差异是否胜过共享响应”，不保持异质信息容量，不能和置换 null 混称。

现有 `g=0`、`z=0` 与训练折平均 `z` 不是同一个反事实，非线性与中心化使它们可能给出不同方向。共享常量必须明确定义在原始特征空间、按相同训练折标准化/编码走完流程；不把某个评估时反事实的结果当训练 null。A 的 primary null 通过不意味着 B 的真实服务图或 C 的局部共位已通过；每项结构主张仍需自己的匹配 null。

**比较脚本的接口需先适配。** 当前 `compare_kernels_v1.py` 的 `--st` 虽能换 label，但完整报告与 `fold_report` 都硬读 `damage.2.kappa_s/kappa_a/geo_sim`；恢复-only 或节点核会触发 KeyError。实施前应做通用模型 label 和可选元数据适配，保留原评分、时效、权重与 bootstrap 不变，再用现有三模型回放验证数值完全不变；当前尚未修改这个脚本。未适配之前，不把表中的 `--st` 命令当作新架构可直接执行的命令。

筛选前需要的正确性检查：精确第 0 步宿主等价、非退化开口梯度、单步及全轨迹 gradcheck（闭环版包括 p→d→r）、状态/比例边界、前缀因果性、图归一化与空邻居、训练/留出隔离、stock 闭环伴随对朴素自动微分等价。已有 `tests/test_gcrk_space.py` 与 `tests/test_gcrk_equivalence.py` 仍需通过。以上是后续实施要求，本轮没有修改核代码或开始训练。

## 8. PI 要决定的具体事项

建议批准 **A 的最小无 stock 版本先做 seed 0 五折**：它只增加恢复历史这一种机制，闭环和资源解释的歧义最少；并批准 B 的固定公共服务联系输入审计。若诊断显示冻结损伤的零恢复上界仍远低于实际峰值，则把 C 的同源节点核放到下一项讨论，而不是指望不断降低恢复率修补损伤幅度。
