# GPT 审查的真实数据复核：宿主存在失配，但漏峰的主要解释还在响应学习与泛化

日期：2026-09-29。范围登记提交：`5fa930e`。这是已观察过公共 D 和 I20 结果后的探索性诊断，不是独立确认试验。

**独立复核后的摘要补充（同日）：** 第一折 FIT S 的 RMSE 下降 44.03%，但峰幅比设计权中位数从 1.231% 降至 0.800%，90% 分位数则从 16.13% 升至 90.61%。因此不能把训练拟合提升概括为“训练严重病例峰值已普遍学会”；下一问题同时包括训练内部的响应分配与跨事件稳定性。OUTER non-S RMSE 的 +25.31% 也须突出。原始结果未变，详见[独立复核回应](D06_INDEPENDENT_REVIEW_RESPONSE_20260929_ZH.md)。

**结论：GPT 把注意力从“继续加大地理核”转向完整响应链，这个方向有价值。但真实数据不支持把恢复上限、核输出整体过小或尾部完全没有损失权重当作当前失败的充分解释。更突出的实证问题是：CRK 能明显拟合训练事件，却没有把这种响应迁移到留出事件；组合地理基函数的实际作用很弱，而写入非线性已大面积饱和。**

核心科学问题保持：天气过程 → 地理复杂调制 → 潜在冲击的形成、叠加与累积 → 停电。以下分析定位模型与数据接口，不能证明某种地理机制，也不能把负结果概括为“GCRK 不适用于公共数据”。

## 1. 外部工作实际完成了什么

附件自己的状态文件明确写明：没有真实 D、没有真实模型训练、没有 checkpoint 回放。它给出的 cap、锚定写入、核基函数缩小和 scattering 恒等式，是数学/实现层面的证据；其对 I20 失败的解释仍需实证。D06 因此补了三部分：全 D 与五折 OOF 导出审计、全部 726 个 S 的完整轨迹 oracle、固定第一折冻结模型的 FIT/OUTER 回放。

| 外部观点 | D06 判断 |

| 小时平均观测不能直接当作连续 stock 的端点 | 接口问题成立；本轮未读取原始季度小时记录，未量化改标签/观测算子的收益 |

| 类别归一化损失与 pooled S 目标不同 | 确认；但 S 仍占大部分平方损失，不能简化成“目标不关注严重病例” |
| 换成 scattering 可保存输入—状态—输出能量 | 合成代数通过；尚无真实训练、宿主集成或预测收益证据，不能直接替换 |

## 2. 宿主确有不可达轨迹，但量级不足以解释严重漏峰

原宿主的合法速率满足 `0 <= u <= 0.515`、`0 <= r <= 0.5`，因而

\[
0.5p_{t-1}\le p_t\le 0.515+0.485p_{t-1}.
\]

在合法速率范围内，外层裁剪不会扩大这个包络。若能逐时自由选择速率，包络中的每个值也都可实现。实际共享网络、gate 和 smoother 还会施加更多限制，所以“包络可达”不等于“网络能预测”。

仅检查相邻两小时均有观测的对；第一小时使用观测 y0，不把缺测当成零。主违反容差为 1e-7；另报告超出包络至少 1pp 的实质违反。

| 集合 | 有效相邻小时对 | 下界违反对数 | 设计权违反率 | 下界超出 1pp 的对数 / 设计权比例 |
|---|---:|---:|---:|---:|
| 全 D | 1,213,761 | 110,744 | 8.820% | 1,367 / 0.0812% |
| S：预测窗观测峰值≥10% | 104,006 | 7,207 | 8.080% | 598 / 0.9402% |
| J：最大有效小时净增≥1pp | 424,834 | 40,943 | 9.850% | 1,361 / 0.3651% |

全 D 下界违反率的合并事件组 95% 区间为 [8.030%, 9.629%]；S 为 [6.889%, 9.161%]。上界违反远少：全 D 47 对、27 个县—事件。这里的“违反”是当前观测量与当前宿主离散包络不兼容，不等于观测错误或物理恢复不可能。

D05 的 2,949 个可随访 J 最大跳升中，551 个下一小时回落至少该次跳升的 80%；其中 527 个也违反总 stock 的 50% 回落界，设计权交集占快速回落病例的 97.90%。两种定义在这批数据中高度重叠，但并非数学上同义：跳升前的基础 stock 不能省略。

### 全部 S 的完整轨迹 oracle

对每个 S 县—事件，直接用已知真实轨迹求解：

\[
\min_{p_{1:144}}\sum_t m_t(p_t-y_t)^2,
\qquad p_0=y_0,
\quad (1-r_{\max})p_{t-1}\le p_t\le0.515+0.485p_{t-1}.
\]

缺测小时仍连接动力学，但不计入误差；未按结果剔除任何 S。自由逐时速率是原网络的放宽，所以最优值是原模型类误差的下界。它使用未来真实 y，仅用于诊断，**不是预测器，也不是可承诺的改进空间**。

| S、完整 144h、设计加权 | RMSE（停电比例） | 与现有宿主 S 平方误差之比 |
|---|---:|---:|
| 冻结宿主 | 0.0624332 | 100% |
| 冻结 CRK | 0.0622052 | 约 99.27% |
| 原 cap=0.5 的最优 oracle | **[0.0056501, 0.0056859]** | **[0.8190%, 0.8294%]** |
| 仅放宽 recovery cap 到 1 | 0.0014670 | 0.05521% |

主 oracle 的方括号是**数值优化证书上下界**，不是置信区间。相对于宿主 SSE 的下界比值，其事件组 bootstrap 95% 区间为 [0.4236%, 1.5239%]；上界比值区间为 [0.4305%, 1.5401%]。这不分解因果贡献，也不是新模型效果区间。

数值限制完整保留：cap=0.5 的 726 个 SLSQP 求解中，7 个未返回成功，25 个最终原始—对偶间隙超过 1e-8；没有把这些样本删掉，也没有把近似原始目标冒称下界。使用非负对偶乘子与显式盒约束最小化计算下界，并用前向投影得到可行上界。cap=1 全部成功，最大间隙小于 3.5e-15。所有上界轨迹的约束和加权误差另外逐项复算。

原 cap oracle 的全窗峰幅比设计权中位数约为 100%，10% 分位数为 83.12%；当前宿主/CRK 的同口径中位数只有约 1.590% / 1.087%。这里使用累积权重线性插值分位数，与 D05 阶梯分位数可能有微小差异。

**解释：只靠当前速率上限，原本就能表示绝大部分 S 的幅度和轨迹。修改恢复接口仍有建模理由，但不能把它当作目前百倍量级漏峰的主要充分解释。** 余下误差可能来自共享函数类、信息不足、优化、目标折衷和泛化；oracle 无法把它们分开。

## 3. 训练目标确实不同，但严重病例并没有被平方损失忽略

原 FIT 目标按类别用零预测平方风险 `Z_r=sum(w*m*y^2)` 归一化，行权重与 `w/Z_r` 成正比，统一缩放不改变相对份额。它与 pooled S RMSE 不相同。

逐折原 FIT 的 S 占归一化观测小时权重仅 2.56%–3.12%，但占**零预测归一化平方损失的 89.10%–93.42%**。第一折冻结模型回放后，S 仍占宿主/CRK 的该平方损失 **90.67% / 82.66%**。FIT 回放关闭随机 drop-path，不能当成训练时逐步损失日志。

因此可以说类别目标与 PI 的 S 目标存在折衷，不能说模型只因“严重病例数量少、损失几乎不看它们”就漏峰。损失份额不等于共享参数梯度份额，也不证明换损失有用；梯度抵消、sigmoid 工作点和事件分布仍待测。

## 4. 第一折：拟合能力已经增加，跨事件收益没有跟上

固定第一折全部 6,350 FIT / 2,107 OUTER，使用原 checkpoint、原标准化和原标定 buffer，不重新拟合或标定。两模型 OUTER 回放与原导出的最大绝对差均为 **1.49e-8**；回放前后全部 tensor state 逐值不变。

|---|---:|---:|---:|
| FIT 全部 | 0.0114012 | 0.0066233 | **−41.91%** |
| FIT S（559 个） | 0.0636838 | 0.0356420 | **−44.03%** |

这是相同各自样本上的两模型比较；FIT/OUTER 本身分布不同，不能把两集合 RMSE 的绝对差称为纯泛化误差。也不能把单折工作点推广成五折都如此。但它足以反驳“CRK 在训练数据上也完全学不动，只需再增加容量”的单一解释。

五折既有 OOF 的 non-S 严重假峰交集已重新计算：

| 观测峰值<10%，预测峰值≥10% | 县—事件数 |
|---|---:|
| 宿主与 CRK 都报 | 3 |
| 仅宿主报 | 1 |

所以旧结果“4 → 133”准确的增删关系是新增 130、消失 1、净增加 129，不是新增 133。第一折 OUTER 上，宿主无此类假峰，CRK 有 49 个。CRK 的训练适配与留出误报需要同时解释。

以下基函数统计对相应集合的县—事件行等权；峰时统计使用设计权。二者不是同一种聚合口径。

### 5.1 全组合核的有效工作点

| 第一折量级（均值） | FIT | OUTER |
|---|---:|---:|
| 原 40 维地理向量范数 | 0.9599 | 0.9683 |
| 32 维核基函数范数（已含 `/sqrt(32)`） | 0.03114 | 0.02934 |
| fusion 中基函数线性项 / 原地理线性项的平均范数比 | 1.472% | 1.343% |
| head 中基函数线性项 / 原地理线性项的平均范数比 | 0.545% | 0.522% |

这些是实际训练后参数下的量级，不再是“40 个坐标都恰好有同一个相似度”的合成假设。全组合支路相对弱是值得修的条件问题；然而谱仍有多维变化，且原地理旁路经过非线性 fusion，不能说地理没有进入，也不能说高阶地理信息已被证实无用。小幅度不等于小预测作用，仍需局部导数或受控对照。

## 6. 对 scattering 建议的具体取舍

附件的每模式变换为

\[
x_t=\rho Q_tx_{t-1}+\sqrt{1-\rho^2}d_t,\qquad
z_t=\sqrt{1-\rho^2}Q_tx_{t-1}-\rho d_t.
\]

固定同一控制路径、正交 Q 下，`||x_t||²+||z_t||²=||x_{t-1}||²+||d_t||²` 成立。它提供显式即时输出，并把输入能量分配给状态与输出，作为快慢响应的候选有价值。

但它改变了原 CRK 的稳定性口径：单位球状态界不再成立。例如 Q=I、恒定 d 时，稳态 `x=sqrt((1+rho)/(1-rho))*d`；长记忆状态可以明显大于 d。能量恒等式也不保证每小时输出幅度有界，不保证不同天气导致不同控制路径时的增量收缩，更不修复小时平均观测、stock 速率上限或跨事件误报。

结合 D06，**现在直接换 scattering 并全量训练，证据还不充分**。它可以作为以后唯一一项明确的快慢能量分配对照，不能一次混入新目标、新地理尺度、新 readout 和新恢复上限，否则无法解释谁产生了变化。当前实现只做合成探针复现，未导入正式模型或训练。

## 7. 后续研究应怎样收紧可检验问题，而不收窄地理组合空间

这次不取消原创新目标，也不退回预先指定“坡度×植被”的少数配方。改变的是推进顺序：先识别响应链里哪些自由度能跨事件工作，再选择新核。

1. **下一项优先诊断是事件条件下的响应选择性与导数。** 在固定训练事件与独立留出事件中，分别测天气→deposit、联合地理→控制、state→logit→u 的局部 Jacobian/敏感性和时序方向变化，并报告严重病例与假峰两端。只计算范数不足以确认饱和后是否仍保留有效方向。
2. **组合地理的数值条件与信息价值分开。** 全 40 维保持可访问、所有阶数保持可参与；可比较 FIT-only 中心化/尺度平衡与当前单个混合核坐标，禁止根据 OUTER 选地理组合或阶数。任何幅度修正都需和参数/预算匹配的无地理或置换对照区分；本轮没有启动这些对照。
3. **保留即时冲击与累积的可分辨接口，但不盲目增加输出能量。** 当前核效果已经大，应检查短时天气变化是否能改变响应方向、阈值和持续时间，以及这些变化是否在留出事件可靠。scattering 是可选实现之一，并非由 D06 唯一推出的方案。
4. **观测算子单独设计、单独验证。** 小时均值与端点动力学的问题保留；未来若进行季度小时支持审计，需要新的严格 D-only 清单，不从整年原始数据或 C 读取来绕过边界，不删掉难拟合峰值。不能把一个观测接口修复包装成地理信息的收益。
5. **原严重病例目标与假峰约束继续同时保留。** I20 的 S RMSE 下降≥10%目标未达成；后续不能改成只报训练拟合、MAE 或选择有利的县。所有新设计要先写出单一可否证假说与有限预算，再比较无核宿主。

本轮实际完成的是 D06 的全部固定诊断，不是新 kernel 实验。I18/I20 监控保持暂停，没有新训练队列；冻结源、数据和旧训练产物均未修改。
