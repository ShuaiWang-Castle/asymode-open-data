# 冻结核诊断：状态存在，结构收益未兑现

2026-09-28。开发集 D、seed 0、五个系统留出折；不训练、不读确认集、不改论文。

**结论：不能把失败归结为编码塌缩或状态撞到单位界。核确实改变隐藏表示，但多数小时最终损伤率很小；第 1 折的大空间份额被小读出口径压低。旧的“平均地理”反事实也需要修正解释：标准化描述量 `g=0` 不是中性编码 `z=0`，不同常量参考甚至得到相反方向。以上是模型依赖和局部敏感性证据，不是地理信息或新结构带来泛化收益的证据。**

## 1. 重建与统计口径

脚本：`experiments/geo_weather_20260924/diagnose_kernel_state_v1.py`。只读取 `features_v1D.npz`、`space_v1D.npz`、`splits_v1D.json` 以及两个已训练 arm 的 seed-0 权重和输出。固定模型的标准化、地理中心、校准尺度和阈值，完整系统分批，CPU 单线程、nice 15。

10 个模型的重建预测和 `outer.npz` 最大绝对差不超过 **2.98×10⁻⁸**；关闭核读出也逐折复现原 `P_closed`。每批检查没有已存图边因分批丢失，重建的下游计算与模型原 forward 一致，状态范数满足单位界。所有县事件在所属留出折处理一次。

下文反事实指标使用全部 **144 个预测小时 72–215**，设计加权 MSE；`compare_kernels_v1.py` 的 `+1` 会略去第 72 小时，二者口径应区分。区间为类别内 family-cluster bootstrap，2,000 次，seed 20260924。所有干预相对同一个模型的原始预测，不是相对重新训练的宿主。状态分布为未加权描述；编码混杂同时给出设计加权版本。结果均属开发诊断，没有多重比较修正，也没有多 seed 检验。

## 2. 有效维度没有塌缩，类别混杂不是全部解释

| 1 | 3.83 / 3.24 | 3.87 / 3.08 | 6.3% / 5.8% | 9.1% / 8.1% |
| 2 | 3.18 / 3.28 | 2.98 / 3.41 | 12.8% / 11.3% | 2.3% / 2.3% |
| 3 | 3.88 / 2.95 | 3.75 / 2.22 | 12.5% / 19.8% | 12.5% / 17.9% |
| 4 | 3.32 / 2.74 | 3.40 / 2.85 | 26.5% / 22.4% | 5.6% / 4.1% |
| 5 | 3.15 / 2.73 | 3.07 / 2.68 | 19.8% / 20.2% | 27.8% / 28.4% |

类别间方差是各类均值相对总体均值的平方差，类内余差单独保留有效维度。至少 71.6% 的设计加权编码方差在类别内，因而“编码只是天气类别指示器”过强。这个分解没有控制区域、系统或客户暴露，不能证明类内变化包含停电相关信息。

`λ,a,Ω` 的影响并非全都为零，但折间差异很大：

- 第 1 折 GCRK / ST 的坐标平均县际 `SD(λ)` 只有 0.00056 / 0.00049，第 3 折为 0.00042 / 0.00135。第 2、4、5 折约为 0.013–0.033。
- 以离散衰减的等效记忆 `1/log(1+λ)` 计，各折中位数 12.9–16.6 h，坐标与县合并后的 10–90 分位大致为 7.9–21.0 h；不是均匀利用允许的 2–96 h 范围。
- `Ω` 的县际坐标平均标准差只有 0.0037–0.024；第 2、4、5 折中位增益约 1.94–1.96，靠近上界 2。大量读出放大来自共享增益，地理对增益的额外调制较小。
- `a` 的平均范数约 0.28–0.46，完整坐标范围、相对中性/零描述量的变化和类别间方差均写入 JSON。`z` 在大多数折没有 `|z|>0.95`，第 5 折约 3%，没有普遍 tanh 饱和。

## 3. “平均地理”的三种定义给出相反方向

实现先做 `v=tanh(g/3)-geo_center`，再将 `v` 按 `sqrt(0.1²+||v||²)` 归一化，最后得到 `z=tanh(Uv)`。因此 `g=0` 经中心化和归一化后一般不为零。实测 `||z(g=0)||=0.22–0.70`；训练县事件的经验平均编码 `||zbar_fit||=0.010–0.091`。

下表固定全部权重，只替换核读入的地理描述量或编码。对 ST，常量编码同时移除静态邻居相似度的县际差异；方向权重不变。

| 冻结替换，相对自身地理 | GCRK MSE 变化，95% 区间 | ST-GCRK MSE 变化，95% 区间 | 平均绝对峰值变化 GCRK / ST，百分点 |
|---|---|---|---|
| 标准化描述量 `g=0`（旧反事实） | −2.47% [−7.28, +0.49] | −1.68% [−5.84, +0.98] | 0.264 / 0.222 |
| 精确中性编码 `z=0` | +7.34% [+0.92, +20.02] | +10.23% [+1.70, +24.80] | 0.419 / 0.481 |
| 训练折经验平均编码 `z=zbar_fit` | +10.67% [+1.98, +27.12] | +13.31% [+2.17, +30.94] | 0.488 / 0.552 |
| 关闭整个核读出，宿主权重仍固定 | −1.59% [−3.60, −0.09] | −0.67% [−2.52, +0.79] | 0.352 / 0.313 |

这三种常量参考不是同一个模型干预。`g=0` 仍然激活一个特定方向的条件参数，不能叫“移除地理”。另一方面，中性编码或平均编码变差也**不能证明真实县地理的信息价值**：训练后的损伤网络和核共同适应了原始输入分布，常量替换会改变分布；即使编码位于训练编码的凸包内部，隐藏状态和读出也未必处于训练时常见的位置。信息价值仍需结构一致、重新训练的配对 NULL；本诊断不越过单 seed 筛选规则。

## 5. 第 1 折：强耦合、小开口，实际出口仍很弱

第 1 折 ST 的 `κ_s=0.255, κ_a=0.457`，预测窗实际平均混合份额 0.405，`β=0.136`；同折 GCRK 的 `β=0.382`。ST 的平均 `||W₂ effect||` 仅 0.061，对应基础第二层范数的约 0.85%；GCRK 分别为 0.320 和 4.35%。因此 `κ` 的大小不等于预测贡献的大小。

在**同一个 ST 模型**内关闭耦合，平均状态范数 0.1505→0.1619，平均 `||W₂ effect||` 0.0611→0.0661；耦合确实平滑状态，但幅度缩小不足以单独解释跨模型读出的五倍差异。`β`、`Ω`、损伤权重和局部投影都发生了共同调整。

| 第 1 折冻结干预 | MSE 变化，95% 区间 |
|---|---|
| 关闭空间耦合 | −0.00237% [−0.00944, +0.00497] |
| 保留 ST 其余参数，只把 β 设为同折 GCRK 的 β | +0.126% [+0.026, +0.325] |
| γ 从 0.000733 改为 1 | +0.000415% [−0.000014, +0.001064] |
| γ 改为 10 | +0.001256% [−0.000237, +0.003524] |

当前权重下，直接放大开口不会改善误差。不能反推“训练时因为空间平滑所以主动关小 β”这一因果历史；也不能把冻结去耦合的近零影响当作重新训练 ST 与 GCRK 的差异。

γ 的影响经过静态份额与读出，所以在其余参数固定时，输出对 γ 的导数包含 `κ_s β` 因子。初始化二者都为零，γ 初始不可见；以后可出现梯度，并非结构上永久零梯度。第 1 折邻边 `||z_i-z_j||²` 中位数 0.0534，当前 γ 对邻居相似度的影响极小。将 γ 置零后的预测变化仅约 10⁻⁸ 个百分点；0 到当前 γ 的单边 MSE 有限差分约为每单位 γ 的 4×10⁻⁶ 相对变化，数值太小，float32 下不宜解释成可靠梯度方向。较大的 γ=1/10 干预仍显示当前模型对这一通道不敏感，不能由此排除重新训练或不同邻接设计的价值。

图的限制仍在：每折平均 7.02–7.31 个邻居，孤立县事件 0.68–1.50%，预测小时没有上风邻居份额的比例 4.9–6.6%，上风 row-sum 均值 0.297–0.388。它们只是**已抽样县图**的描述，不能证明真实地理邻域或电网完整。这里没有观测或检验风暴平移方向，所以不能量化 10 m 风向作为风暴移动代理的误差。
