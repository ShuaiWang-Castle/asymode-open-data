## 1. 要解决的具体问题

证据见[D07复核](D07_INDEPENDENT_REVIEW_RESPONSE_20260929_ZH.md)及
[D08真实数据](D08_FIXED_INPUT_PANEL_RESULTS_20260929_ZH.md)。
现有两条预测整轨迹二选一的真值oracle仅改善S约1.96%；达到原10%目标需要新的有效响应，
不能只关闭已有坏响应。FIT的正收益集中、近满幅缓变写入，与留出假峰高敏感区同时存在。
参数改0.1%却可使逐小时预测变12.47个百分点，参数变化并不等于小函数变化。

原写入是[tanh(raw)-tanh(anchor)]/(2sqrt8)。饱和地理anchor同时决定某一侧可用幅度，
地理偏置与天气反应方向发生耦合；它不是已证明的全部错误原因，却是可单独否证的结构问题。
新设计将地理偏置改为天气响应的条件调制，保留非线性联合fusion和直接天气通路。
单独改deposit，保留原宿主、单damage MLP、geo40/全阶地理核、rho/Q、模式数、读出、
开口、校准、drop-path、目标及Adam配置。不增加状态、第二天气网络、辅助损失或地理配方。

## 2. 明确的写入公式

u是旧核的64维标定隐藏level/departure输入，e是旧72维联合地理特征；
f=F_g e+b_f，a_0=H_g e+b_h+C tanh(f)的前32写入坐标。
SN(M)=M/max(1,||M||op)，使用精确奇异值计算，不用欠估计的有限power iteration。

令B=SN(H_weather[:32])、C_w=SN(H_fusion[:32])、F_w=SN(F_weather)，并定义

```
v(u) = u / sqrt(1 + ||u||²/64)
f_w = f / max(1, ||F_g||op)
L_g = max(1, ||H_g[:32]||op + ||H_fusion[:32]||op ||F_g||op)
a(e) = 1 + 0.5 tanh(a_0/L_g)                       # 每坐标[0.5,1.5]
r(e,u) = {a(e) * Bv + C_w[tanh(f_w+F_w v)-tanh(f_w)]}/(2sqrt8)
d_m(e,u) = r_m / sqrt(1 + ||r_m||²)               # 四个8维模式
```

同一参数值下的tau/rho/eta/omega与原核逐值相同，其他时间演化完全继承：
x_t=rho_t Q_t x_(t-1)+(1-rho_t)d_t。全部旧参数仍被使用，新增可学习参数为0。
这不是等函数重参数化；它是明确不同的写入候选。虽然分母沿用2sqrt8，
初始fusion天气矩阵的谱约束可能已生效，不能宣称初始Jacobian完全匹配旧核。

## 3. 这为何可能形成更好的冲击响应

- 零标定隐藏输入严格写入0；不能误称原始气象全部为0必然无冲击，因为宿主有偏置和context。
- 地理不直接凭空沉积，它调制天气方向和非线性天气增量；全40维及任意阶子集仍可参与。
- 正gain下限0.5不会因饱和anchor关闭某一侧天气响应；直接B通路绕过fusion饱和区域。
- 末端按8维向量径向限幅，接近零时保留方向，远处平滑收缩；不按每坐标锚点切掉单侧幅度。
- 原因果多时标状态和旋转继续表达累积、释放与次序作用，不为每种误差添加独立模块。

这里的状态仍为潜在冲击表示，不是已观测物理损伤。这是能与数据对比的设计动机，
不是预测提升、地理净信息、全组合统计覆盖或新理论首创的保证。

## 4. 能证明什么，以及不能证明什么

v的范数≤8且Lipschitz常数1。径向映射R(z)=z/sqrt(1+||z||²)范数<1、Lipschitz常数1。
固定e时，aB项算子范数≤1.5、fusion项≤1，因此

```
||d(e,u)-d(e,u')|| ≤ [2.5/(2sqrt8)] ||u-u'|| ≈ 0.44194 ||u-u'||.
```

固定u时，anchor/L_g对e的Lipschitz常数≤1，gain导数≤0.5且||Bv||∞≤8；
tanh(f+z)-tanh(f)对f的导数是两个sech²之差，绝对值≤1。因此

```
||d(e,u)-d(e',u)|| ≤ [5/(2sqrt8)] ||e-e'|| ≈ 0.88388 ||e-e'||.
```

这是32维拼接deposit的界；继承四模式各状态≤1，不将拼接状态误写成≤1（其范数≤2）。
新写入还有较紧联合容量界：||r||≤5/sqrt2，各模式径向限幅后||d||≤10/sqrt33≈1.741，
小于旧共同上界2；单模式最多约0.962。这是幅度容量改变，不能称仅改变敏感度。
输入球||u||≤8内，v的最小径向导数≥2^(-3/2)，避免在这一区域指数型切平。
但最终B可学成低秩、fusion偏置仍可能饱和、末端R仍会收缩，64→32不可能处处可逆。
rho/Q/omega没有在本对照中得到新的跨输入界；宿主和标定尺度也不受这里的证明控制。
所以不能宣称完整原始天气→停电敏感度已被约束，不能把更小Jacobian当作成功。

实际检验须观察新增修正与残差的幅度/时间对齐、响应覆盖、短与长过程、全类风险及假峰。
若约束抹掉有效变化而只让范数变小，应报告失败，不用数值稳定包装成提升。

## 5. 与文献的关系

[FiLM](https://arxiv.org/abs/1709.07871)提供条件乘性/仿射调制的通用思想；
[Spectral Normalization](https://arxiv.org/abs/1802.05957)提供按矩阵谱尺度控制映射的思路；
[Sorting Out Lipschitz Function Approximation](https://proceedings.mlr.press/v97/anil19a.html)
提醒敏感度约束可能牺牲表达和梯度。这些文献不提供停电预测的性能证据。
上面两个具体界是本候选的推导，不是引用论文直接证明了本核。
创新候选仍是联合地理参与整条天气历史的受控冲击过程；这一轮先验证其中一个必要组件，
不为一个结构修复夸大独立理论贡献。独立数学审查另存D09写入审查笔记。
