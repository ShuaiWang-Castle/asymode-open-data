# AsymODE：以完整轨迹预测为中心的正文重置

日期：2026-09-09。地位：研究设计与数学职责修正；不是新论文最终稿，也不是新的真实性能结论。
当前用户指令优先于原 handoff 中的 SR-first、PROJ-first 表述。

## 1. 一句话问题

**在相同历史、可得驱动和轨迹监督下，显式保留 damage/recovery 的源池动力学结构，是否比直接学习完整轨迹或一般净动力学带来可靠的预测收益？这种结构何时有帮助，何时只是限制？**

“普通单流”在核心比较中由真正的直接轨迹模型代表，不再由删掉 damage 的恢复模型代表。全文尽量使用 DIRECT / NET / ASYM，而不是把头数当成函数类名称。
所有核心模型均直接最小化完整轨迹误差。DIRECT 与 ASYM 的区别是预测映射的构造，不是一个学 trajectory、另一个学 rate labels。

## 2. 只保留三种核心模型

令 I_t 是预测时可得信息，Y_t 是当前库存，H=24。

- DIRECT：G_theta(I_t) -> (Yhat_{t+1},...,Yhat_{t+24})，一次前向输出整段。保留线性残差通道与非线性通道，不能以 24 个弱单步模型替代。
- NET：Yhat_{k+1}=Yhat_k+f_theta(C_t,X_k,Yhat_k)，自由净动力学，24 步递归但用完整 path loss 训练。
- ASYM：Yhat_{k+1}=Yhat_k+U_theta(C_t,X_k)(1-Yhat_k)-R_theta(C_t,X_k)Yhat_k；U,R>=0,U+R<=1，完整 path loss。

C_t 包含过去 24 个库存（不含当前 Y_t）、set 和整段已知未来 clock。当前 Y_t 对全部方法可得；ASYM 只通过源池因子使用它。递归过程中固定 C_t，不偷偷注入未来真实状态，也不滚动更新真实历史。
这是新的匹配历史版本，不能把旧无历史 checkpoint 的数字混入同一方法主表。

PERSISTENCE 只作无训练参考。SR 是单向源池结构消融。AFF 是等价重参数化说明，不是第四个科学模型。

## 3. 投影到底是什么，以及如何安置

在固定上下文 x 下，冻结 DN 的净增量函数 fhat(x,y)，用 source 参考状态把它拟合到源池仿射族：

    (Uproj,Rproj)=argmin_{u,r>=0,u+r<=1} E_{Y~P_source(.|x)} [fhat(x,Y)-u(1-Y)+rY]^2.

这不是把真实观测投影到某个标签空间，也不是免费得到物理率。它把一个一般函数近似成受限的状态仿射函数。
DN_READ 只报告系数，原预测不动；DN_PROJ 把原函数换成投影函数，已是另一个结构化预测算法。

**裁决：不纳入本轮真实主 campaign，不做 PROJ 调参；保留冻结的历史投影审计于附录。**
理由：当前问题是源池结构与普通轨迹学习的比较，不是结构应该训练前施加还是训练后施加。将 PROJ 变成主线会另开估计器、参考测度、条件化和推理预算等问题；带历史的条件投影还不能直接复用原无历史 cell 投影。

但不能把已有反证删除：受控冻结结果中，source 三角投影的 R RMSE=.004903，原 TR=.007545，且 5/5 种子更好。该结果限制“训练时显式两率独占优势”的表述。原本不同训练目标的旧结果不能加入新的 path-trained 主表。
若以后主张“训练时分离优于所有结构后处理”或“最优结构化实现”，就必须增加匹配的真实投影比较；本轮禁止这些主张。

## 4. 正文理论的新职责

### 4.1 首先承认表达能力边界

对于足够一般的轨迹函数类，ASYM 实现的映射也可被 DIRECT 表达或逼近；不能证明一般 DIRECT 的逼近误差因为“只有一个输出机制”而更大。
有限且等参数的两套具体 MLP 未必严格嵌套，因此也不能凭通用逼近结论给两个具体网络作风险排序。

候选优势是结构归纳偏置、跨步约束和学习效率；优势不是已知事实，要由匹配实验验证。

### 4.2 正文命题：双向结构约束整条轨迹，而不是增加可表示过程数量

固定预测时可得上下文与驱动路径，假设率序列不再依赖递归状态。
令 a_k=1-U_k-R_k。初值 y_0 给出

    y_h = A_h + B_h y_0,
    A_0=0, B_0=1,
    A_{h+1}=U_h+a_h A_h, B_{h+1}=a_h B_h.

在 U_h,R_h>=0,U_h+R_h<=1 下，0<=a_h<=1，映射保持[0,1]，且

    |y_h(y_0)-y_h(y'_0)|=(prod_{j=0}^{h-1}a_j)|y_0-y'_0|.

常驱动、常率且 0<U+R<1 时：

    pi=U/(U+R), a=1-U-R,
    y_h=pi+a^h(y_0-pi).

这里 pi 与 a 分别控制平衡水平与松弛速度。DIRECT 完全可以输出同一个表达式；ASYM 是强制所有时域共享这个生成结构，而非独占其表达能力。

证明：对一步仿射更新归纳；初值差每步乘 a_h。完整证明放附录，正文保留式子与条件。
如果率网络也任意读取递归状态，以上全局仿射与收缩结论一般不成立；因此本轮模型接口明确避免该假设漂移。
历史 C_t 固定时的数学扰动并不自动是可实现的真实历史改变。真实状态分层是描述性评价，不是这种反事实实验。

### 4.3 正文误差传播结果：结构提供条件稳定性，不保证战胜 DIRECT

比较同一确定性参考轨迹 y_h 和估计轨迹 yhat_h。定义

    delta U_h=Uhat_h-U_h, delta R_h=Rhat_h-R_h,
    ahat_h=1-Uhat_h-Rhat_h,
    e_h=yhat_h-y_h,
    eta_h=delta U_h(1-y_h)-delta R_h y_h.

直接代数给出

    e_{h+1}=ahat_h e_h+eta_h,
    e_H=(prod_{j=0}^{H-1}ahat_j)e_0
        +sum_{k=0}^{H-1}(prod_{j=k+1}^{H-1}ahat_j) eta_k.

若 |eta_h|<=epsilon 且 ahat_h<=a_bar<1，则

    |e_H|<=a_bar^H |e_0|+epsilon*(1-a_bar^H)/(1-a_bar).

如果只能保证 ahat_h<=1，则仅有 |e_H|<=|e_0|+H epsilon，不能擅自写统一严格收缩。
该结论不控制 epsilon 的学习误差，不把随机路径观察误差等同于条件均值误差，更不直接推出风险优于 NET/DIRECT。共享仿射单步结构的其他参数化也继承该性质。
这些是结构分析工具，不应包装成新颖性本身。新实证之前没有一般 ASYM-vs-DIRECT 胜出定理。

### 4.4 原补偿结论保留，但降为明确的删减消融

同一 X 下真实净均值 m(y)=U(1-y)-Ry；只允许 recovery 分支 -r y 时，内点人口最优

    r*=R-U*C/B, B=E[Y^2], C=E[Y(1-Y)].

受非负约束时需做对应边界处理；要将它称为完整 SR 最优还须核对分支条件 U sqrt(A)<=R sqrt(B)。
这个结论解释“被迫删除一个方向后如何补偿”，不解释一般 DIRECT 为什么失败。
只放正文一段机制说明或 ablation 引导，完整 cone/ray gap、源分布转移、Gamma 的 OLS 推导放附录。Gamma 不再作为 neural/trajectory 主表的万能横轴。

### 4.5 率语义的边界必须留在正文

只有净轨迹监督不自动识别物理 gross processes。例如共同项 h(y) 可以同时加到两个方向并在净差中抵消。
真实台账的 ending projection 不是物理 hazard。DIRECT/NET 无原生 R 不是缺点，不能让它们在本不适用的 rate 指标上被判输。
正文主结论是 forecasting；任何物理机制真实性另需独立假设或方向信息核验。

## 5. 两项核心实验，不再多任务并列

### E1：真实的匹配 trajectory 比较（主表）
固定 ANEEL cohort，2018 forward folds 调参，锁定后 full2018 refit，复用2019做回顾性评价。三主模型 + persistence，一张表。
L=24，H=24；所有状态从 t-24 到 t+24 都合法，1/6/24 终点共用同一起点。
主任务是公司等权 path MSE；相对收益固定以 DIRECT 为参照并同时报告原始绝对 MSE。三模型全部使用同一 path loss、相同可得输入和 source-only selection。
高初态等预定义切片最多放次图/附录，阈值只从 fit 计算，不重新训练，不宣传为 fresh/OOD 证据。

解释顺序：ASYM 对 DIRECT 回答实际预测收益；ASYM 对 NET 回答收益是否不仅是递归归纳偏置。
仅胜 SR 不能闭合主张；胜 DIRECT 但输 NET 不能把递归收益归于双向结构。

### E2：一个可解的完整轨迹受控实验（主图）
使用 U(x)=.005+.035(x+1)/2, R=.20；未来 x 已知且在 horizon 内固定。
source Y0 in [.25,.45]；同机制高初态 Y0 in [.55,.75]；每个模型都训练完整 H=24 路径，不复用旧单步模型冒充。
固定 n=2048，不开大规模 regime/sweep。source validation 只选配置；高初态不调参。
训练目标带 iid .005 标准差观测噪声，评价提供无噪声真路径，并保存带噪标签。三主模型都用相同 x,Y0、无历史输入；这是独立的机制可解任务，不冒充真实数据的信息环境。
主指标仍是 path prediction，而不是强迫 DIRECT 给原生 R。展示 source 与 shifted 两种评价，保留任何反向结果。

## 6. Ablation / Appendix 的固定角色

- SR：只考察单向结构删减。真实消融用已选 ASYM 的预算/优化超参、两个预先规定的符号初始化，经2018选择；不是经完整独立调参的强预测 baseline。
- ASYM_STEP_ONLY：同一模型、同一训练窗口/标签集合，改成 teacher-forced 一步 loss；评价仍完整递归。它只隔离训练目标的影响。
- Projection：冻结历史正确两列审计，保留胜 TR 的事实，不增加新的真实投影模型。
- AFF：代数等价说明，不另开表。
- 旧受控 U=0、弱 state variation、非线性失配：作为边界材料，严格标旧目标/协议，不拼入新主图。
- 原始记录、方向日志、Gamma、精确 cell 优化：保留于对应附录，不组成第三、第四条主线。
- 暂停新方向监督、校正、低状态重训、多天气核、干预识别、证书与报告压缩。
