## 问题

外部条件和起点都相同时，停电事件的轨迹仍然服从一个条件分布。两流递推是 `y' = y + u(c,x)(1−y) − r(c,x)y`：速率由外部输入决定，非负，且 `u + r ≤ 1`。本文问：这个条件分布的哪些特征，决定两流约束会降低还是提高多步预测风险？

这仍是原稿的主题，即数据分布决定结构。这里做两处推进：

1. 把“结构”从仿射包络换成两流实际能生成的路径集合 𝒜。
2. 把“数据特征”从均值信号 S 扩充为以下三项：
   - 仿射之外的均值响应 S = ‖Qm‖²/d；
   - 仿射均值响应的可行性缺口 F = dist(Pm, 𝒜)²/d；
   - 协方差落在被约束去掉的方向上的部分。这些方向包括 Q 方向，以及被激活约束去掉的 P 方向，例如无破坏的恢复期里流入率贴 0。

## 方法论题（待检验）

两流约束的风险相对灵活估计量可以写成两部分：

- **偏差**：S + F。
- **方差节省**：灵活估计量在被约束去掉的方向上要付的协方差代价，即 tr((I − P_face)Σ)/n。约束严格激活时，P_face 投影到被激活约束所在的面；真值恰在边界上时，节省约为该方向方差的一半。

同一个约束同时影响两边：激活时既带来偏差 F，又节省方差。所以在均值和边际方差都固定时，协方差相对被约束方向的朝向本身就能翻转取舍。

## 实验块

### B1：精确解剖（M0，确定性计算）

- 数据：原 neural bridge 设计（`results/neural_bridge/design.npz`）的精确均值与协方差。2 条 forcing × 4 个训练初态 {0,2,4,8}/16 × 24 小时；另有插值初态 {1,3,5,6}/16。
- 计算：
  - P、Q（每条 forcing、每个时距在 {1, z} 上投影）；
  - S，以及 F（在 𝒜 上多起点约束拟合 Pm）；
  - 直接拟合 m，验证恒等式；
  - 活跃约束集；
  - 预测方差项 tr(Σ)、tr(PΣ)、tr(QΣ)、tr(P_face Σ)。
- 成功标准：γ = 0 时 F < 1e−12；恒等式误差 < 1e−10（相对）。
- 失败的解释：若 γ = .04 时 F < 0.05·S，则 F 不作主线（放弃条件 K1）。

### B1b：同数据约束估计量对照（M1，CPU 长时）

- 数据：原 30 个数据重复 × 18 个设置 {γ, ρ, n}，训练前缀与神经模型完全相同。
- 比较对象：
  - 饱和估计 Ȳ；
  - 仿射估计 PȲ；
  - 两流约束最小二乘 argmin_{g∈𝒜}‖Ȳ − g‖²；
  - 已保存的神经 NET 与 ASYM 预测。
- 指标：
  - 训练初态与插值初态上的均值路径风险；
  - 两模型的风险差；
  - 按 P/Q 分解的偏差与方差。
- 成功标准（C2）：
  - γ = .04 时，约束估计与饱和估计的风险差符号与神经 NET/ASYM 的符号一致的设置比例高于仿射对照；
  - 约束估计在共同部分的方差节省，能解释神经模型共同部分方差差异的至少 25%（放弃条件 K3）。

### B2：协方差方向干预（M2）

- 在精确均值 m 周围加高斯噪声，边际方差固定为原 Σ 的对角线，旋转相关结构，让噪声主要落在被约束方向或主要落在可行面内。
- 比较约束估计量、饱和估计量和仿射估计量的 Monte Carlo 风险，并与 Λ_c、Λ 的预测对照。
- 成功标准（C3）：出现预测内的翻转，且 Λ_c 的符号预测准确率高于 Λ（放弃条件 K2）。

### B3：物理可解释的干预（M2，按需）

在有限群体过程里构造“恢复期事件级共同冲击”等保均值干预，把 B2 的方向效应落到停电语言上。只有 B2 通过才做。

### B4：神经长时实验（M3，长时间运行）

- 模型：
  - 外生速率两流（原 ASYM）；
  - 速率可读状态的两流；
  - 有界净流（原 NET）。
- 设计：B2 选出的干预设置，重复与原 bridge 相同的训练协议（AdamW、早停、固定 3000 步消融）。
- 只有 B1b 和 B2 至少一项通过才启动。

### B5：真实数据（M4，事后）

- 同一事件、同一起点，各县初态不同。按天气分层后，估计跨初态的 S 和 F，以及恢复期正性约束是否激活。
- 与 CV 风险差对照，标注为事后描述。

## 修订 1（2026-09-26，B1 之后，任何新神经结果之前冻结）

### 触发原因

- K1 被触发：原设计下 F/S = 0.014。
- K3 被触发：约束激活节省的方差只解释神经共同部分方差差异的约 1%。
- 探索性结果 X2：原 bridge 只有 2/18 个设置能分辨 NET − ASYM 的符号。结构信号 S = 0.5e−6，低于两类网络的训练误差地板（约 5–7e−6）。

原 bridge 因此无法检验任何关于神经结构选择的数据特征理论。

### 修订后的主张（仍是“数据分布决定结构”）

像多步决策学习中用假设的预测误差包络抽象学到的预测器那样 [已删除稿件名]，每个架构的实际误差用可测的包络来抽象：

```
e_j^P(x) = α_j^P + β_j^P · x_P，   e_N^Q(x) = α_N^Q + β_N^Q · x_Q
```

- x 是理想估计量在该分量上的方差，即 c(ρ)·tr(·Σ0)/n，属于数据分布特征。
- α 是与数据噪声无关的训练地板。
- β 是隐式正则化后的统计斜率。

判据：`Δ_pred = (e_N^P − e_A^P) + e_N^Q − (S + F)`，Δ > 0 时两流更好。

可检验的推论是**分辨率极限**：灵活模型只能利用超出训练包络差的被排除信号。低噪声时，交叉点 S* ≈ Δα，而不是经典判据给出的 S* ≈ x_Q。

### B4′ 设计（有功效的神经检验）

- **过程**：与原 bridge 相同的有限群体过程（M = 16，L = 32，U = .06，R = .20，两条 forcing）。
- **初态**：训练初态 K = {0,4,8,12}/16，插值初态 K = {2,6,10,14}/16。
- **反馈**：γ ∈ {0, .04, .08, .12, .16, .19}。精确 S 大约从 0 到 4.9e−4，跨过训练地板（X1）。
- **噪声**：ρ ∈ {0, 1}。均值不变，协方差按 c(ρ) 缩放。
- **样本量**：n ∈ {64, 256, 1024}，验证集为 n/4。
- **重复与初始化**：60 个数据重复，5 个固定初始化（rep mod 5）。
- **模型**：完整公开架构 NET（d2）与 ASYM（r1），训练协议与原 bridge 相同（AdamW lr .001、wd 1e−4、batch 512、3000 步、每 250 步验证、patience 1000、第 0 步可选）。
- **规模**：6 × 2 × 3 × 60 × 2 = 4,320 次拟合，约 15 CPU 小时，6 个进程约 2.5–3 小时。
- **第二阶段（B4′-S，第一阶段之后）**：加入速率读状态的两流，区分“两流结构”与“状态访问限制”。

### 预注册分析

1. 只用 γ = 0 的 6 个格点（S = F = 0）标定每个架构、每个分量的 (α, β)。
2. 用精确的 S、F 和标定好的包络，预测 γ > 0 的 30 个格点的 Δ 符号。
3. 在可分辨格点（|Δ| > 配对 Monte Carlo 半宽）上比较两个判据：
   - 包络判据；
   - 理想估计量判据：饱和估计对仿射估计的精确风险差。

### 放弃条件

- **K4**：可分辨的 γ > 0 格点少于 12 个，结论为检验功效不足，不作任何方向性主张。
- **K5**：包络判据的符号准确率 ≤ 70%，或不高于理想估计量判据，则放弃包络框架。
- **K6**：NET 的 Q 分量误差随 S 显著增长，即 NET 无法利用信号，则包络的可加性假设不成立，改为报告描述性结果。

## 修订 2（2026-09-26，B4′ 第一阶段之后、第二阶段运行之前冻结）

### 第一阶段结果（原早停规则）

- **K4 通过**：可分辨的 γ > 0 格点 24/30。
- **K5 通过**：包络判据符号准确率 24/24，理想估计量判据 22/24。两者分歧的两个格点（γ = .08 与 .12，ρ = 1，n = 64）都是 NET 胜，与包络判据一致。
- **K6 字面触发**：NET 的 Q 分量误差随 S 显著增长（6 组全部 p < .003），但斜率只有 0.0055–0.08，即 NET 仍吃下 92–99.5% 的信号。

### 第二阶段问题

两流的共同部分训练地板低于 NET（α_A^P = 6.23e−6，α_N^P = 7.42e−6）。这一差异来自“速率不读状态”，还是来自“两流的有界正速率参数化”？

### 第二阶段设计

- **模型**：ASYM_STATE（`source/models_state.py`），两流形式不变，速率网络额外读取递推状态。参数按同一规则匹配。
- **其余**：全部同第一阶段，包括同样的 36 个格点、60 个重复、初始化种子、批次序列和训练协议。

### 预注册判定

1. 在 γ = 0 的格点上，用同样的方法标定 ASYM_STATE 的 α^P。
   - 若 α_S^P ≤ (α_A^P + α_N^P)/2，结论是地板优势主要来自两流参数化。
   - 否则，结论是地板优势主要来自状态访问限制。
2. 在 γ ≥ .08、ρ = 0 的格点上，看 ASYM_STATE 的 Q 分量误差：若它 ≤ 两流不可避免误差 S 的 25%，说明读状态后两流也能利用被排除的信号。
3. 报告三模型的配对风险差（ASYM 对 ASYM_STATE、ASYM_STATE 对 NET），用按初始化分层的 95% 半宽。

## 修订 3（2026-09-26，第二阶段之后、泛化运行之前冻结）

### 第二阶段结果

- **判定一**：训练地板优势来自两流参数化。ASYM_STATE 的共同部分地板 α = 4.70e−6，低于中点 6.83e−6，也低于 ASYM（6.23e−6）和 NET（7.42e−6）。
- **判定二**：在强信号格点上，ASYM_STATE 的 Q 分量误差只有 S 的 0.4–4.3%，说明读状态后两流也能利用被排除的信号。
- **观察（非预注册判定，只作为本修订的假设来源）**：
  - 低噪声（ρ = 0）时，ASYM_STATE 在所有 γ 上都不差于 NET，多数格点更好。
  - 高噪声（ρ = 1）时，NET 在多个格点更好。

### 泛化检验

1. **规律 A（拥挤：恢复随规模变慢）**：沿用 B4′ 数据的 γ ∈ {0, .04, .08, .12}、前 40 个重复、n ∈ {64, 1024}，目标参数量改为 8,192。
2. **规律 B（动员：恢复概率 R(1 + η·K/M)）**：η ∈ {0, .2, .5, 1}，精确 S 约为 0、1.6e−6、7.7e−6、2.1e−5，F ≡ 0。目标参数量取 32,768 和 8,192；其余与 B4′ 相同（K = {0,4,8,12}/16，ρ ∈ {0, 1}，n ∈ {64, 1024}，40 个重复，5 个初始化）。
3. **模型**：NET、ASYM、ASYM_STATE，训练协议不变。
4. **规模**：3 × 4 × 2 × 2 × 40 × 3 组（规律 × 规模）= 5,760 次拟合。

### 预注册假设（每个规律 × 规模组合分别检验）

- **H1（参数化地板）**：在无反馈格点上标定后，α^P_ASYM_STATE < α^P_NET，且 α^P_ASYM < α^P_NET。
- **H2（斜率）**：β^P_NET < β^P_ASYM_STATE。
- **H3（状态限制无益）**：在 S > 0 且 ρ = 0 的格点上，ASYM_STATE 的风险不高于 ASYM 加半宽。在无反馈格点上，两者之差在 ±半宽内，或者 ASYM_STATE 更好。
- **H4（包络判据迁移）**：在每个组合内，只用无反馈格点标定 NET 对 ASYM 的包络。它对可分辨的有反馈格点的符号准确率不低于 80%，且不低于经典判据。

### 放弃条件

- **K7**：任一新组合中 H1 不成立，“两流参数化降低训练地板”就不能作为一般结论。
- **K8**：任一新组合中 H4 的准确率低于 80%，包络判据就不能迁移。

## 勘误（2026-09-26，独立审查之后追加；以上各修订保持原样）

1. 修订 2 中 K6 一行写“NET 仍吃下 92–99.5% 的信号”，这是误读。0.0055–0.08 是 e_N^Q 对 S 跨 γ 回归的斜率，不是逐格未学信号比例。逐格 e_N^Q/S 在早停下为 0.52%–97.5%。K6 被触发，按本计划第一阶段应降级为描述性结果。
2. 修订 1 与 2 把 NET 称作“有界净流”，不准确。公开 NET 是无界增量更新，没有状态范围约束。
3. 本计划的修订按顺序追加在同一文件中。最终文件的 SHA-256 与本地修改时间只能证明版本对应，不能独立证明各修订早于对应实验；时间顺序依据本地记录。
4. 判定口径：
   - 早停主实验的 24 个可分辨格点全部是 NET 胜，“始终选 NET”同样 24/24，这一准确率不能证明双向选型能力。
   - 事后补做的简单基线 −(S+F) 的风险差 MAE 为 5.81e−6，低于包络的 6.55e−6。
   - 固定 3000 步消融下，包络 MAE（21.0e−6）差于经典式（15.2e−6）。
   详见 `results/posthoc_baselines.json`（事后分析，未预注册）。
5. 修订 3 的 H3 用“不超过半宽”判定。这只表示没有分辨出更差，不是非劣性检验。H4 是在每个新规律、新规模中重新标定后再评估，检验的是校准程序的适用性，而不是包络系数跨环境迁移。
