# NET / ASYM 受灾县分组交叉验证轮（2026-09-14）

## 0. 来由与性质

在 `net_asym_neural_era5_20260912` 一轮和 Helene 种子扩展之后，PI 于 2026-09-14 提出两点：一是数据可能缺乏可分性；二是训练设置和模型搭配不公平。PI 随后对四个设计问题作出了选择，本轮据此重新设计。

- 这是新的一轮实验，不修改前两轮的任何文件、锁或校验值。
- 前两轮的结果已经看过，所以本轮不是对它们的盲检验。本轮检验的是：修正设置以后，NET/ASYM 的比较是否改变。
- 所有设计、锁和分析脚本都在任何 DEV 或 final 训练开始之前提交。

### PI 的四项决定（2026-09-14）

1. **受灾县。** 训练和内层验证只用受灾县-事件，即事件面板内停电峰值 ≥ 1% 的县-事件。测试同时报告全部、受灾、未受灾三个人群；受灾人群的结果标为“条件于实际受灾”。
2. **事件与划分。** 用现有 26 个事件做分组交叉验证：按类型分层，时间重叠的事件放在同一折，每个事件都由没见过它的模型评价。
3. **ASYM 结构。** 损坏和恢复拆成两个独立网络。损坏:恢复参数比在 {1:1, 2:1, 3:1} 中作为超参数选择；NET 给同样数量的结构候选。两模型总参数对齐到同一目标，误差 ≤ 1%。
4. **训练设置。** 两模型使用同样的最大更新数、学习率网格和早停规则；final 按内层验证逐 seed 早停；两模型都从接近持久性的状态起步。

## 1. 数据合同（沿用前一轮，不改）

- **信息合同：** RETROSPECTIVE_KNOWN_REANALYSIS_CONDITIONAL_RESPONSE。两模型都读取未来 24 h 的 ERA5 再分析路径。这是回顾性的条件响应实验，不是部署预测。
- **面板：** `configs/panel_manifest_g3-all-26.json`（digest db286b4960a4），共 26 个事件。
- **状态：** 取 15 分钟库存的精确 UTC 整点快照。observed=False 或非有限值是非法状态，不补零。
- **天气：** 驱动文件里 12 个通道全为 0 的县视为缺天气，两模型都排除，不当作 0 输入。
- **窗口：** L=24、H=24，起点每 6 h 一个；49 个状态和全部输入天气都合法才进入。直接复用前一轮去重后的窗口索引（119,044 个窗口），逐 split 校验哈希。
- **输入**与前一轮相同：
  - 过去 24 h 的状态（不含 y0，按拟合尺度缩放）；
  - y0；
  - 过去 24 h 和给定的未来 24 h 的 12 通道天气；
  - 逐步特征：t+k+1 时刻的天气、UTC 时刻的 sin/cos、是否周末。
- **拟合统计量：** 状态尺度、source mean 和天气标准化，只用每个外层折的训练窗口计算。

## 2. 人群

- **定义：** 受灾县-事件指 169 h 事件面板内合法快照的最大值 ≥ 0.01。
- **用法：**
  - 训练和内层验证只用受灾县-事件。
  - 测试覆盖全部合法窗口，分别报告全部、受灾、未受灾三个人群。
- **限定：** 受灾标签用到了实际停电，所以受灾人群的测试结果只对“事后确认受灾”的县成立。同时报告未受灾人群，用来发现靠高估停电取胜的模型。

## 4. 模型（`code/models_v2.py`）

**两模型的共同约束**
- 参数目标 32,768；每个结构候选的总参数都在 ±1% 以内。
- 输入信息完全相同，都做完整路径递推。
- 不做 teacher forcing，不使用方向标签或事故结束信息。

**NET**
- y[k+1] = y[k] + scale·f(c, x[k], y[k]/scale)，f 是带线性 skip 的残差 MLP。
- 结构候选按隐藏层数分：
  - d2：宽 48，32,633 参数；
  - d3：宽 45，32,567 参数；
  - d4：宽 43，32,867 参数。

**ASYM（拆分版）**
- 损坏网络 D(c, x[k]) 和恢复网络 R(c, x[k]) 相互独立；(u, r, stay) = softmax(D, R, 0)，y[k+1] = y[k] + u(1−y[k]) − r·y[k]。
- 率不读取递推状态。
- 结构候选按损坏:恢复的参数比分：
  - r1：宽 25 / 24，参数 16,691 + 16,024 = 32,715；
  - r2：宽 33 / 16，参数 22,099 + 10,760 = 32,859，比例 2.05；
  - r3：宽 37 / 12，参数 24,851 + 8,176 = 33,027，比例 3.04。

**同一起点**
- NET：输出层接近 0，即近似持久性。
- ASYM：u = 0.002π，r = 0.002(1−π)，stay = 0.998，其中 π 是折内训练 source mean。24 h 内向 π 回归不到 5%。前一轮审计核心用的是 0.05，未训练时就带有明显的均值回归先验。

## 5. 训练、选择与 final（`code/cv_train.py`）

- **共同设置**
  - 损失：完整路径 MSE，按折内拟合尺度标准化。
  - 采样：训练窗口内事件等概率、县等概率、起点等概率。
  - 优化：batch 512，AdamW（weight decay 1e-4），梯度裁剪 1。
  - 学习率网格：{3e-4, 1e-3, 3e-3}。
  - 预算与验证：最多 3000 更新；每 250 更新在内层验证上评估一次，指标是受灾县-事件的事件等权 path MSE。
  - 早停：连续 1000 更新没有改进就停止，保留最佳 checkpoint（update 0 也是候选）。
  - 配对：同一折、同一 seed 下，两模型抽到的 batch 样本 ID 相同；torch 种子为 seed + 1000·fold。
- **DEV：** 每个外层折、每个模型跑 3 个结构 × 3 个学习率 × DEV seeds {9101, 9102}，共 5 × 2 × 9 × 2 = 180 次。
- **选择：**
  - 每个外层折、每个模型，取两个 DEV seed 最佳验证损失均值最低的配置。
  - 并列时取较小学习率，再按结构顺序。
  - 结果写入 `locks/SELECTION_LOCK.json`，在任何 final 之前提交。
- **FINAL：**
  - 每个外层折、每个模型，用选中的配置跑 seeds 9201–9205，共 50 次，逐 seed 早停。
  - 预测该折全部合法测试窗口，保存预测分片和 checkpoint。

## 6. 评价与判定规则（在任何 DEV 或 final 结果之前固定）

**评分口径**
- 先逐 seed 计算平方损失，再对 seed 聚合。
- 事件内部：县等权，县内起点等权，时距等权。
- Δ = MSE_NET − MSE_ASYM，正数支持 ASYM。

**报告范围**
- 人群：全部、受灾、未受灾。
- 分组：全部 26 个事件、三个类型组、五个目录类型。
- 汇总量：
  - 事件等权的 seed 均值 Δ；
  - 1/6/24 h 端点与逐时距曲线；
  - mean-event-relative gain 与 ratio-of-event-means gain，两者分开报告，不互相替代。
  - 次要指标（PI 2026-09-14 决定）：逐事件 RMSE，即逐 seed 的事件 path MSE 的平方根；报告事件等权 RMSE、两模型之差和分量符号翻转 p。不参与训练、选参和判定。

**推断**
- 推断单位是重叠分量，分量的 Δ 取其所含事件 Δ 的均值。分组内只使用属于该组的事件。
- 符号翻转检验：分量数 ≤ 16 时精确枚举，否则用 20 万次蒙特卡洛。
- 95% 区间：按分量重采样 4,000 次。

**判定**
- **支持 ASYM：** p < 0.05，且事件等权 Δ 与分量均值 Δ 都为正。
- **支持 NET：** p < 0.05，且两者都为负。
- **未决：** 其余情况。分量太少、最小可达 p ≥ 0.05 时只能判为未决。

**附报的稳健性**
- 每个事件中 Δ 为正的 seed 数。
- 每个分组中，事件等权 Δ 为正的 seed 数。
- 未受灾人群上的方向。

## 7. 诊断参考（不是模型，不参与选择）

- **持久性：** 整条路径保持 y0。
- **未训练模型：** 每个折、每个 seed 按训练时的顺序重建 update 0 模型，并核对其内层验证损失与日志一致。
- **平均符号误差：** 预测减观测。
- **可分性描述：** 观测路径在 24 h 内既出现 ≥ 0.001 的上升、又出现 ≥ 0.001 的下降的窗口比例，按类型组和人群报告。
