## 0. 设定：面板设计

- **输入与故障。** 一条固定输入路径 x，对应一个天气情境。故障概率 p_k = U·x_k。
- **设计。**
  - K 个不同的初态 z_1, …, z_K，例如同一场风暴中处在不同停电水平的县。
  - 设计的经验矩按 1/K 加权：均值 z̄，标准差 s（称为**覆盖**），偏度 sk，峰度 κ。记 κ₂ = κ − 1 − sk²；它等于 z² 对 (1, z) 回归残差的标准化方差，恒 ≥ 0。
- **事件。**
  - 共 n 个独立事件，第 i 个事件有一个未观测的环境 ω_i，例如抢修力量或天气强度的偏差。同一事件内所有设计点共享 ω_i，这就是共同冲击。
  - 每个设计点是由 M 个组构成的独立子总体，M 越小，人口统计噪声越大。
  - 未停电的组以 p_k(ω) 故障，停电的组以 R(ω) − γ·Y 恢复，Y 是该子总体当前的停电比例。
  - γ > 0 是**拥挤型**反馈：停电越多，恢复越慢，例如抢修力量饱和。γ < 0 是**动员型**反馈：停电越多，恢复越快，例如互助抢修队到场。
- **三个理想学习者。**
  - 𝒩：饱和最小二乘，即每个设计点取样本均值。
  - 𝒜_aff：路径对初态仿射的最小二乘。
  - 𝒜：两流可行集（外生速率，u, r ≥ 0，u + r ≤ 1）上的约束最小二乘。
- **风险。** 设计点上的平方误差，按 d = K·H 平均。
- **经典精确恒等式（工具，不算贡献）。**
  - R(𝒩) − R(𝒜_aff) = x_Q − S，其中 x_Q = tr(QΣ)/(n·d)，S = ‖Qm‖²/d。
  - Q 是按初态去掉仿射部分的投影，即 I_H ⊗ Q_z；Σ 是单个事件在 K 个设计点上的堆叠协方差。
  - 判据量 Λ = S/x_Q（Toro-Vizcarrondo & Wallace 1968；Mallows 1973）。

**递推量**（γ = 0，给定 ω）：

- λ_k = 1 − p_k − R
- A_{k+1} = p_k + λ_k·A_k，B_{k+1} = λ_k·B_k，其中 A_0 = 0，B_0 = 1
- c_{k+1} = λ_k·c_k + B_k²，其中 c_0 = 0

含义：

- A_h 是从“未停电”出发、h 步后的停电概率；A_h + B_h 是从“停电”出发的停电概率。
- B_h 是初态记忆。
- c_h 是反馈在第 h 步造成的初态曲率的累积权重。

## 1. 引理 1：无反馈时的结构

γ = 0 时，给定 ω：

(a) 均值路径对初态仿射：m_h(z | ω) = A_h + B_h·z。人口统计方差也对初态仿射：v_h(z | ω) = [A_h(1 − A_h) + z·B_h(1 − 2A_h − B_h)]/M。

(b) 因此 S = 0，环境冲击对被排除方向的噪声贡献**恰为零**：Q 作用在 Cov_ω(m(· | ω)) 上后，迹为 0。

(c) **更正（2026-09-27）：F 不一定为 0。**
- 条件均值是可行的两流路径，但无条件均值 m = E_ω[m(· | ω)] 是它们的混合。两流可行集 𝒜 不是凸集，所以混合不一定可行。
- 对均值路径的逐时距仿射系数，隐含一步故障率有精确式：

  u_k^P = E[p_k] + E[B_k]·Cov_π(λ_k, A_k/B_k)，其中 π(ω) ∝ B_k(ω)

- 在无强迫时刻（p_k ≡ 0），若 Cov_π(λ_k, A_k/B_k) < 0，就有 u_k^P < 0，于是 F > 0。条件是：累计损坏（相对初态记忆）越大的事件，恢复越快。
- 反之，Cov_π ≥ 0 且其余约束不紧时，F = 0。
- 精确核对（`logs/random_env_F.log`；γ = 0；两个等概率环境）：

  | 环境组合 | 隐含 u（最小值） | F |
  |---|---|---|
  | (p .06, R .12) 对 (p .06, R .28) | −8.4·10⁻³，与闭式相差 3·10⁻¹⁵ | 9.0·10⁻⁷（B4′ 布局）、1.4·10⁻⁷（窄设计） |
  | (p .10, R .12) 对 (p .03, R .28) | ≥ 0 | 0 |

  前一组的 F 与 γ = .04 时的曲率信号同量级。

**证明。**
- 无反馈时，各组是独立的两状态时变马尔可夫链。z·M 个初始停电组各自以 A_h + B_h 的概率在 h 步时停电，其余组以 A_h 的概率停电。
- 均值是两者按 z 加权。M 个独立伯努利均值的方差为 [z(A+B)(1−A−B) + (1−z)A(1−A)]/M，整理即得 (a)。
- 环境协方差矩阵为 [(1, z_j) C (1, z_l)ᵀ]_{jl} = X C Xᵀ，其中 X = [1, z]。由 Q_z X = 0 得 (b)。∎

**含义（按 (c) 修正）。**
- 通过外生速率起作用的共同冲击，只移动仿射方向，所以**不增加**无约束模型在被排除方向上的方差。进入被排除方向方差的，只有单元层面的独立噪声。
- 但事件间速率的异质性会通过 F 进入**偏差**：恢复速度与损坏规模相关时，两流约束有偏。
- 所以“共同冲击不进入”只对方差一侧成立，不能无条件地写。

## 2. 定理 T3：一阶闭式判据

取 γ → 0，所有 O(·) 都在 M、H、K、设计固定时成立。

(i) **曲率信号。** Qm_h = γ·E_ω[c_h]·Q[z²] + O(γ²)，因此

  S = γ²·s⁴·κ₂·C_H + O(γ³)，其中 C_H = (1/H)·Σ_h (E_ω c_h)²。

(ii) **被排除方向的噪声。**

  n·x_Q = (1/(KH))·Σ_h [(K − 2)·E v_h(z̄) − s·sk·E β_h]·(1 + O(γ)) + γ²·s⁴·κ₂·Ṽ_H + O(γ³)

  - β_h = B_h(1 − 2A_h − B_h)/M 是 v_h 对 z 的斜率。
  - Ṽ_H = (1/H)·Σ_h Var_ω(c_h) 是曲率权重在事件间的方差。

(iii) **对称设计（sk = 0）。**

  1/Λ = (K − 2)·V̄_H / (K·n·M·γ²·s⁴·κ₂·C_H)  +  Ṽ_H / (n·C_H)  + 高阶项

  其中 V̄_H = (1/H)·Σ_h E_ω[A_h(1 − A_h) + z̄·B_h(1 − 2A_h − B_h)]。

**证明。**
- 均值闭包 m_{k+1} = p_k + λ_k·m_k + γ·(m_k² + v_k) 精确成立（当前稿定理 3 的式子，这里对任意初态）。
- 在 γ = 0 处对 γ 求导：ṁ_{k+1} = λ_k·ṁ_k + m_k² + v_k。
- 由引理 1，v_k 对 z 仿射，m_k² = (A_k + B_k z)² 的非仿射部分为 B_k²·Q[z²]。递推即得 Qṁ_h = c_h·Q[z²]。
- 对 ω 取期望得 (i)。‖Q_z z²‖²/K = s⁴κ₂ 是回归残差方差。
- (ii) 的人口统计部分：设计点之间相互独立，所以迹等于 Σ_j (1 − lev_j)·v_h(z_j)，杠杆 lev_j = 1/K + (z_j − z̄)²/(K s²)。v_h 对 z 仿射，求和得 (K − 2)·v_h(z̄) − s·sk·β_h。
- (ii) 的环境部分：给定 ω 的均值，其 Q 分量是 γ·c_h(ω)·Q[z²]，它的方差给出 γ²·s⁴·κ₂·Var_ω(c_h)。∎

**一阶的真实均值对 z 恰为二次**：ṁ_h 是 z 的二次式。所以在一阶上，“两流 vs 净流”的理想比较就是“对初态仿射 vs 对初态二次”。任何更灵活的状态响应只增加不带信号的噪声方向。

## 3. 推论：数据层特征各自的作用

| 特征 | 在 Λ 中的位置 | 结论 |
|---|---|---|
| 覆盖 s | S ∝ s⁴ | 覆盖是四次方效应。临界覆盖见下式 |
| 人口统计噪声 1/M | 第一项 ∝ 1/M | 单元越少（M 小），越偏 𝒜 |
| 共同冲击（ω） | 无反馈时为 0；有反馈时只经 Ṽ_H 进入 | 给出上界 Λ < n·C_H/Ṽ_H，与覆盖和 M 无关 |
| 设计形状 | κ₂·K/(K − 2) | 两簇设计 κ₂ = 0，看不到曲率；把部分设计点放在中心（中心加两端）会增大 κ₂，曲率更容易看到 |
| 反馈 γ | S ∝ γ² | 反馈的方向见第 4 节 |
| 时距 H | C_H 与 V̄_H 之比 | 见第 5 节 |

**临界覆盖。** 对称设计下，Λ = 1 当且仅当 s = s*，其中

  s*⁴ = (K − 2)·V̄_H / (K·M·γ²·κ₂·(n·C_H − Ṽ_H))

- 前提是 n·C_H > Ṽ_H。若 n ≤ Ṽ_H/C_H，即事件间反馈强度的异质性超过事件数，则**任何覆盖下理想比较都偏 𝒜**。
- 例：反馈只在 10% 的事件中出现且强度为 10 倍时，Ṽ/C 约为 9。事件很少的数据（例如 26 场风暴）会受到这个上界的约束。

**水平显式形式（低停电水平）。** 把设计写成 z_j = ℓ·ζ_j：
- ℓ 是停电水平；ζ 的均值为 ζ̄，相对离散度为 σ_ζ，所以 s = ℓ·σ_ζ。
- 强迫也按水平缩放：p_k = O(ℓ)，因此 A_h = O(ℓ)，而 B_h、c_h = O(1)。

于是 S = γ²·ℓ⁴·σ_ζ⁴·κ₂·C_H，V̄_H = ℓ·V̄₁ + O(ℓ²)，并得到

  Λ ≈ n·M·γ²·ℓ³ · σ_ζ⁴·κ₂·K·C_H / ((K − 2)·V̄₁)

- **水平阈值。** ℓ* = [(K − 2)·V̄₁ / (K·n·M·γ²·σ_ζ⁴·κ₂·C_H)]^{1/3}。水平低于 ℓ* 时理想比较偏 𝒜，高于 ℓ* 时偏 𝒩。
- **数据量的影响。** ℓ* 随独立事件数 n 和有效独立单元数 M 的增大而下降。
- **与零初态版本一致。** 当前稿定理 3（零初态、单一路径）在低水平下给出同样的 ℓ³ 标度：t = O(ℓ²)，所以 I_H = O(ℓ⁴)；单组协方差为 O(ℓ)，所以 ν₁² = O(ℓ)。独立评估报告先写出了这个草图，这里在跨初态设定下重新得到。
- **可行性缺口不随水平改变比例。** 在固定相对离散度下，拥挤型 F 也按 ℓ⁴ 缩放，所以低水平时 F/S 与 ℓ 无关，只由 ζ̄/σ_ζ 决定。
- **与真实数据的关系。** 真实风暴里“起点水平低的事件 ASYM 更好”是事后观察。这里它成了事前可检验的预测：阈值 ℓ* 的位置由 n、M、γ 和相对覆盖共同决定。

**成立条件（2026-09-27 按审查意见明确）。** Λ ∝ n·M·γ²·ℓ³ 是局部近似，要同时满足：
1. 小反馈 γ（一阶展开）；
2. 低水平极限；
3. 明确的缩放：跨初态版本中初态与强迫同时按 ℓ 缩放；零初态版本（现稿定理 3，热带风暴起点 y0 ≈ 0 对应这一版）中强迫按 ℓ 缩放；
4. M、H、设计形状固定。

还要注意：
- 真实数据里的“路径平均水平”是一次实现的事后量，不等于理论中的条件均值水平 ℓ，只能作为代理。
- 由 (c)，事件间速率异质性带来的 F 也随水平增长（u^P ∝ ℓ，F ∝ ℓ²）。它与反馈项（信号 ∝ ℓ⁴）同方向，都让 Λ 随水平上升，但不在 ℓ³ 公式之内。

**“水平是主要决定量”的理论依据（限定在反馈强度可比的事件之间）。**
- 在热带开发数据中，县-事件的路径水平从第 1 到第 99 百分位跨 4.9 个数量级（0.0004% 到 30.3%），所以 ℓ³ 约跨 15 个数量级。
- 县客户数（M 的上界代理）只跨 2.6 个数量级。
- γ 有界。但若某些事件几乎没有反馈（γ ≈ 0），Λ 与水平无关，所以这一论断只在反馈可比时成立。
- 这是关于理论判据中变化来源的陈述，不是关于训练网络选型准确率的经验结论。

## 4. 定理 T2：可行性缺口与反馈符号的不对称

(a) **精确刻画。** 记 Pm 的逐时距仿射系数为 (a_h, b_h)，其中 a_0 = 0、b_0 = 1。F = 0 当且仅当对每个 k 都有：

  λ_k^P = b_{k+1}/b_k ∈ [0, 1]，且 u_k^P = a_{k+1} − λ_k^P·a_k ∈ [0, 1 − λ_k^P]

也就是说，投影后的状态响应能由逐步的单调仿射自映射 [0,1] → [0,1] 复合生成。在离散时间下，这只是逐步的线性不等式（逐步转移矩阵非负、行列式非负），不需要嵌入理论。连续时间的嵌入问题（Frydman & Singer 1979）只作类比。

(b) **一阶展开。** u_k^P = p_k + γ·δu_k + O(γ²)，λ_k^P = λ_k + γ·δλ_k + O(γ²)，其中

  δu_k = s_k² − sk·s_k·μ_k − μ_k² + A_k(A_k + B_k)/M
  δλ_k = 2μ_k + sk·s_k + (1 − 2A_k − B_k)/M

这里 μ_k = A_k + B_k·z̄ 是设计平均水平，s_k = B_k·s 是设计点之间均值路径的离散度。

**推导。**
- 由 (i) 的一阶式，δa_{k+1} = λ_k·δa_k + e_k，δb_{k+1} = λ_k·δb_k + f_k。
- e_k、f_k 是 m_k² + v_k 的仿射拟合系数，其中 z² 的仿射拟合为 s² − z̄² − s·sk·z̄ + (2z̄ + s·sk)·z。
- 再代入 δu_k = e_k − A_k·f_k/B_k 和 δλ_k = f_k/B_k。

(c) **符号规则。**
- 无强迫时刻（p_k = 0）约束 u_k ≥ 0 是紧的；有强迫时刻各约束都不紧。
- 若对所有无强迫时刻都有 γ·δu_k ≥ 0，则 F = o(γ²)。
- 若某个无强迫时刻有 γ·δu_k < 0，则 F = γ²·dist_G(δθ, 𝒯)² + o(γ²) > 0。其中 𝒯 是切锥 {t : t_{u_k} ≥ 0，k 无强迫}，dist_G 是设计度量下经路径雅可比映射的距离。

(d) **物理含义**（对称设计，忽略 1/M 项）：δu_k < 0 当且仅当 μ_k > s_k，即水平高于设计离散度。
- 拥挤型反馈（γ > 0）：在水平高于离散度的恢复期产生可行性缺口。它需要一个负的故障率去拟合曲率，两流结构做不到。
- 动员型反馈（γ < 0）：只在离散度高于水平时产生缺口。
- 恢复期内 A_k 与 B_k 同速衰减，所以 μ_k/s_k 不变，符号在整个恢复期保持不变。
- 这说明两流约束的偏差对反馈方向是**不对称的**。

(e) **覆盖依赖（单步示例）。**
- 拥挤型、μ > s 时，单步可行性缺口为 F = γ²·(μ² − s²)²·s²/(μ² + s²)。
- s → 0 时，F ≈ γ²·μ²·s²，比 S ∝ s⁴ 衰减得慢。所以窄覆盖、高水平时，F 是两流约束的主要偏差。
- 多步情形由 (c) 的锥投影给出。

(f) **边界红利（待推）。**
- γ = 0 时真值在边界上（无强迫时 u = 0），约束估计 𝒜 的方差低于 𝒜_aff，也就是 R(𝒜_aff) − R(𝒜) = x_B > 0。
- 这是 χ̄² 型量（Shapiro 1985；Self & Liang 1987；Andrews 1999）；在局部备择 γ = O(n^{−1/2}) 下，它依赖漂移方向。
- 数值（`source/t2_boundary.py`，高斯极限、线性化锥、3,000 次抽样）：

  | 设计 | x_B/x_Q |
  |---|---|
  | B4′ 布局 | 0.049 |
  | 窄覆盖设计 | 0.034 |

  所以边界红利只是一个小项。
- 沿 γ = c/√n 看 n·[R(𝒜) − R(𝒜_aff)]：
  - B4′ 布局，动员型：c = −6 时仍为负（−0.80e−4），红利只是逐渐减弱。
  - B4′ 布局，拥挤型：c = +6 时变为正（+1.39e−4），可行性缺口 F 超过了红利。这是 (c)(d) 所说不对称的数值体现。
  - 窄覆盖设计里两个方向都几乎不变。F 按 s² 缩小。

**完整的理想判据：**

  Δ = R(𝒩) − R(𝒜) = x_Q + x_B − S − F

- 偏向 𝒜 的项：x_Q 和 x_B。
- 偏向 𝒩 的项：S 和 F。

## 5. 定理 T5：时距

- **一般式。** Λ_H 是两个累积和之比：Σ_h c_h² 对 Σ_h v_h(z̄)。所以把时距从 H 延长到 H + 1，当且仅当边际比 c_{H+1}²/v_{H+1}(z̄) 大于当前的 Λ_H 比值时，偏好朝 𝒩 移动。
- **纯恢复期、常速率 λ**（p = 0，因此 A = 0）：

    c_h = λ^{h−1}·(1 − λ^h)/(1 − λ)，v_h(z̄) = z̄·λ^h·(1 − λ^h)/M

    c_h²/v_h(z̄) = M·λ^{h−2}·(1 − λ^h) / (z̄·(1 − λ)²) ∝ t(1 − t)，其中 t = λ^h

- **结论。** 单个时距上的判据在初态记忆的半衰期 h* = ln 2/ln(1/λ) 处最大（R = 0.2 时 h* ≈ 3.1 小时）。净流的相对优势集中在中间时距；很短的时距曲率还没累积起来，很长的时距初态已被遗忘，这两端都偏 𝒜。累积判据 Λ_H 在 h* 之后的某处达到峰值。
- **定位。** 时距 H 是任务选择，不是数据特征；数据特征是恢复速率决定的记忆半衰期。所以 T5 更适合写成 T3 的形状因子，而不是单独的定理。

## 6. 定理 T4：目标分布与覆盖

- **单一被排除方向。** 设 𝒩 是对初态二次的学习者，一阶上这已经足够。在任意目标初态 t（设计内插或外推）上：
  - 𝒜_aff 的偏差平方为 γ²·c_h²·Q̃(t)²；
  - 𝒩 多出的方差为 (σ²/n)·Q̃(t)²/(K·s⁴·κ₂)；
  - 其中 Q̃(t) = t² 减去 z² 的设计仿射拟合在 t 处的值。

  两者按同一个杠杆因子 Q̃(t)² 缩放，所以 **Λ(t) 与目标点无关**。训练与目标之间的覆盖偏移不能翻转理想选择，起作用的只有训练覆盖 s。
- **这一点本身是经典结果。** Toro-Vizcarrondo & Wallace（1968）的 MSE 矩阵判据在只有一个约束（J = 1）时，对所有线性泛函给出同一个结论，每个预测点都包括在内。
- **本稿补上的只是适用条件。** 一阶上，存量—流量过程的均值对初态恰为二次，只有一个带信号的被排除方向，所以 J = 1 的结论正好适用。
- **多于一个被排除方向。** 当 𝒩 更灵活（对 z 的 q 次多项式，q > 2，或饱和）时，多出的方向在一阶上只带噪声，不带信号。设计内 Λ 约按 1/(q − 1) 下降（噪声随 z 异方差时是近似）；外推时高次方向的杠杆增长更快，所以向外推方向的目标偏移偏 𝒜。
- **覆盖趋于 0。** S = O(s⁴)，拥挤型 F = O(s²)，x_Q 不变，所以 Λ → 0，理想比较偏 𝒜。观测性风暴数据中，给定天气后初态的条件离散度很小，这正是这种情形。它是否成立是经验问题，需要在真实数据上估计覆盖。

## 7. 与已有结果的关系与新意所在

- **经典部分（引用，不算贡献）：**
  - 受限对非受限的精确判据：Toro-Vizcarrondo & Wallace 1968；Wallace 1972；Mallows 1973；McElroy 1977。
  - 边界上的 χ̄² 理论：Shapiro 1985；Self & Liang 1987；Andrews 1999。
  - 两状态链的嵌入问题：Frydman & Singer 1979 及其后续。
- **本稿给出的（待核实文献后确认新意）：**
  1. 引理 1（已按随机环境反例修正）：共同冲击不进入被排除方向的方差；但事件间速率异质性可以通过非凸可行集产生 F > 0，并有精确的协方差条件。
  2. 一阶闭式：反馈 × 覆盖⁴ × M × n × 时距权重，外加事件异质性上界 n·C_H/Ṽ_H。
  3. 可行性缺口的符号规则：拥挤对动员，水平对离散度，在恢复期内符号不变。
  4. 低水平下 Λ ∝ n·M·γ²·ℓ³，以及由此得出的水平阈值 ℓ*（与零初态版本一致）。
  5. 一阶上只有一个带信号的被排除方向，因此 J = 1 的经典目标不变性适用。
  6. 单时距判据在初态记忆半衰期处最大（作为 T3 的形状因子）。
- **与 PI 范例论文的结构相同：** 设计维度（约束）→ 精确分解（经典）→ 可解模型中的闭式（本稿）→ 由闭式给出选择规则和可证伪预测。
