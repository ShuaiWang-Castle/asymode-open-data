# 热带气旋子集上的 NET / ASYM / ASYM_STATE（计划与事先预测，2026-09-26，运行前冻结）

## 数据（只读）

- **来源。** geo-weather 线开发集 D 的热带气旋子集：`data/interim/panel_v1/features_v1D.npz` 中 regime = tropical 的单元，共 15 个大西洋热带气旋系统（2018–2024），1,633 个县-事件。
- **时间结构。**
  - 每个单元有 72 小时前缀和 144 小时预报窗。y0 是起点小时（第 71 小时）的停电比例。
  - 输入分三组：损坏特征 xu（42 维，逐小时）、恢复特征 xr（33 维，含前缀停电历史和静态量）、发生特征 xo（7 维），另有 40 维地理静态量。
  - 设计权重 w 来自 geo-weather 线的抽样设计。
- **不碰封存集 C。**
- **不是独立确认。** 1,367 个单元属于“used”系统，即它们的窗口与本仓库以前读过结果的窗口重叠（DATASET_DESIGN §4.2）。所以本次只是开发层面的观察，不是独立确认。

## 协议

- **折。** 用 `splits_v1D.json` 已登记的事件折，只保留热带系统：
  - 折 1：S00008, S00011, S00034, S00040
  - 折 2：S00001, S00006, S00052
  - 折 3：S00009, S00023, S00054
  - 折 4：S00037, S00046, S00053
  - 折 5：S00042, S00047
- **训练与测试。**
  - 只在热带系统上训练。
  - 每个训练系统随机留出 20% 的县做早停验证（按折固定，所有模型和种子共用）。
  - 在留出的系统上测试。
- **模型。** 三个模型的参数量对齐在约 3 万，初值都接近持久性预报（NET 末层置零；ASYM 的故障率约 3×10⁻⁵、恢复率约 0.05，不动点约 0.06%）。另外保存未训练模型的测试预测作参照。
  - NET：y' = y + f(x, y)，无界增量，输入为全部特征加当前状态。
  - ASYM：y' = y + u(1 − y) − r·y。(u, r, 1 − u − r) 由 softmax 给出；u 读损坏与发生特征，r 读恢复特征，都不读状态。
  - ASYM_STATE：与 ASYM 相同，但 u、r 也读当前状态。
- **训练设置。**
  - 设计加权的全路径 MSE，只计观测到的小时。
  - AdamW（lr 1e−3，wd 1e−4），批大小 64，最多 3,000 步。每 100 步验证一次，800 步不改善即停。
  - 种子 0、1、2。
- **对照。** 持久性预报（y0 保持不变）、全零预报。
- **评估。**
  - 单元层面的观测小时 MSE，先对种子平均。
  - 报告设计加权和不加权两种汇总。
  - Δ = MSE_NET − MSE_ASYM，负值表示 NET 更好。
  - 区间用按系统的整群 bootstrap（2,000 次）。

## 理论的事先预测（来自 THEORY_T3.md，在看到任何结果之前写下）

- **P1（水平）。**
  - 热带起点多在风暴之前，y0 ≈ 0，所以跨初态的约束在这里几乎不可见。相关的是零初态版本：Λ ∝ n·M·γ²·ℓ³，ℓ 是路径水平。
  - 预测：路径水平越高，越偏 NET。
  - 检验量：相对差 rd = (MSE_NET − MSE_ASYM)/(MSE_NET + MSE_ASYM) 与水平 ℓ 的 Spearman 相关应当为负。
  - 水平用两种量：观测窗内平均停电比例（事后量）；两模型预测路径的平均水平（预测时可得）。
- **P2（汇总）。**
  - 热带系统停电量大，按 P1 与 B5 的算法层结果，预测设计加权汇总 MSE 是 NET 更低。
  - 同时按 B5 的截距结果预测：在低水平的边缘县上，ASYM 不差于 NET。
- **P3（反馈方向，描述性，只有 15 个系统，功效低）。**
  - 估计：每个系统在峰值之后、风速较低的小时里，把恢复速率对当前停电水平回归，斜率 < 0 为拥挤型，> 0 为动员型。
  - 预测：拥挤型系统中 ASYM 有额外的可行性偏差，所以 rd 更负。
