# 热带气旋 v2：嵌套风暴级验证与约束分解（运行前冻结，2026-09-27）

## 为什么需要 v2

v1 的训练协议有五处粗糙：
1. 学习率固定为 1e−3，没有调参。
2. 早停用的是同一风暴内留出的县，不代表新风暴。
3. 每种模型只有 3 个种子。
4. 缺少有界净流的对照，无法区分“有界”与“门控结构”的作用。
5. 目标里有上报伪迹（孤立单小时尖峰）。

v1 结果保留并照常报告。v2 是后续开发分析，不追认为预注册。

## 数据

- 与 v1 相同：D 中 15 个热带系统，1,633 个县-事件，只读，C 不动。
- **尖峰清洗（事先规定，所有模型相同）。**
  - 规则：预报窗内某小时比前后两小时的较大值高出 1 个百分点以上，且超过它的 5 倍，就用前后两小时的均值替换。第 1 个预报小时以 y0 作左邻。
  - 训练和主评估都用清洗后的目标；用原始目标的评估作为敏感性分析报告。

## 模型

四个模型参数量对齐，约 3 万；输入与 v1 相同。四者对应理论中的两类约束：R1 是速率不读状态（状态仿射），R2 是门控结构（有界、收缩）。

| 模型 | 形式 | R1 | R2 |
|---|---|---|---|
| NET | y' = y + f(x, y)，无界增量 | 无 | 无 |
| NET_B | y' = c(y + f(x, y))，c 为泄漏截断（[0,1] 内斜率 1，外部斜率 0.01）；评估时截断到 [0,1] | 无 | 只有有界性 |
| ASYM_STATE | 门控两流，速率读状态 | 无 | 有 |
| ASYM | 门控两流，速率不读状态 | 有 | 有 |

四组对照各自隔离一个因素：
- ASYM − ASYM_STATE：只差 R1。
- ASYM_STATE − NET_B：只差门控结构。
- NET_B − NET：只差有界性。

## 训练协议（嵌套交叉验证）

- **外层。** 已登记的 5 个事件折，只保留热带系统，与 v1 相同。
- **内层。**
  - 把外层训练集里的风暴按设计权重从大到小排序，按蛇形分成 3 个内层折（1, 2, 3, 3, 2, 1, …）。
  - 每个配置轮流用两折训练、留出一整折风暴验证。每 200 步验证一次，最多 6,000 步；2,000 步不改善就停。
- **调参网格。** lr ∈ {3e−4, 1e−3, 3e−3}；wd = 1e−4；批大小 64；AdamW；梯度裁剪 1.0。
- **选择。**
  - 配置 c*：三次轮换中各自最佳验证 MSE 的均值最小者。
  - 步数 T*：c* 在三次轮换中最佳步数的中位数。
- **最终拟合。** 用全部外层训练风暴、c* 和固定的 T* 步训练，种子 0–4（共 5 个），再预测外层测试风暴。
- **初值。** 与 v1 相同。

## 评估

- 单元层面观测小时的 MSE；主评估用清洗后的目标。
- 同时报告逐种子平均和种子集成（平均曲线）两种口径。
- 汇总：设计加权与不加权。
- 推断以系统为单位：15 个系统的配对效果、系统级 bootstrap、逐系统剔除。
- 水平关联（系统层面 Spearman）。
- 预测时的水平阈值规则，按留一系统方式评估。
- 对照：持久性预报、全零预报。

## 与理论对应的检验（事先写下）

- **Q1（R1 的作用）。** ASYM − ASYM_STATE 随水平增加而上升。理论依据：水平越高，交互带来的曲率越大，速率不读状态的代价越大。
- **Q2（有界性的作用）。** NET_B 在低水平系统上的误差明显低于 NET。
- **Q3（水平关联）。** NET 相对 ASYM 的优势随水平上升；逐系统剔除后方向不变。
- **失败的情形。** 如果 Q1 的方向相反，或者 v2 下的水平关联消失，照实报告。
