## 1. 核心目标

把地理核做成论文中有实际预测价值、结果稳定、解释充分的主要贡献。

目标不局限于回答“为什么不直接把地理信息输入 MLP”。这只是可能被问到的一个例子。真正需要完成的是：找到现有地理核收益有限的原因，针对瓶颈改进设计，再用实验说明提升来自哪里、适用于什么条件、有哪些局限。

争取足够大的、可重复的提升，但不预先承诺实验一定显著。不能用集成收益、挑选出的县或事件、事后排除不利 seed 替代地理核本身的证据。

研究主线保持：

> 天气过程 → 地理的复杂调制 → 潜在冲击形成、相互作用与积累 → 停电轨迹。

地理核仍置于唯一损伤 MLP 内部；恢复与停电动力学保留。潜在冲击是学习到的隐状态，不等于实测物理损伤。

## 2. 最新分支已经告诉我们的事情

| 工作 | 已有结果 | 对后续任务的含义 |
|---|---|---|
| I18：地理归一化调整 | 单 seed、五个事件折；热带 MSE 相对 HOST 降低 3.4179%；热带/冬季均衡 MSE 降低 2.3581%；pooled +1h RMSE 降低 0.4840% | 简单归一化调整尚未带来足够强的整体收益；主指标相对 HOST 的置信区间跨零 |
| I18：既定筛选 | 大尺度风 MSE 相对 HOST 增加 2.0745%，超过预设 2% 上限 | 原筛选结论保持失败，不事后移动门槛，不直接扩展 I18 的 seed |
| D03：输入结构 | geo40 的线性描述方差达到 90% 需 11 个方向；天气均值保留约 69% 的标准化24小时路径变异，前8个固定时间系数保留约97.7% | 值得保留完整地理信息与天气过程形状；这些数字不能证明预测所需维数，也不能证明原4维非线性地理码必然不足 |
| D04：条件净变化探针 | 地理调制未改善事件外总体误差；116次拟合均未达到登记的梯度标准，同时存在漏峰和假峰 | 不能把响应曲面当作稳定机制，也不能据此否定复杂地理作用；需先处理数值限制 |
| D05：漏峰取证 | 726个真实峰值至少10%的县事件中，Georms全窗预测峰值/真实峰值的中位数仅8.936%（未加权），设计加权为1.225% | 幅度缺口严重，即使放宽峰时也没有解决；不能只调整预测时间 |
| D05：天气与地理线索 | 大跳升附近有天气信号，短时冲击和前期积累都值得保留；高峰样本在匹配已有状态后支持明显减少 | 优先定位天气信号在哪里变弱；条件关联尚不等于跨事件可推广的地理机制 |
| 最新设计说明 | 完整geo40通路、联合非线性条件表示、天气与前隐状态条件化 | 是待检验方向，尚无新核训练结果；原GCRK已经具备地理交互与动态记忆 |

注意：I18 与 D04 的任务和 balanced 指标定义不同，不能把它们的百分比当成同一指标直接比较。D05峰值比是描述性分位数，不是误差改善比例。

## 4. T1：补齐会影响结论的数据与数值核验

### 4.1 时间语义

- 核对停电标签的小时均值区间、瞬时天气时间戳与累计天气覆盖区间。
- 区分严格预测时可用的信息与回顾分析可用的信息。
- 不为了改善分数直接平移天气输入；任何修正均要先确认语义，再单独版本化。
- 如需修正，所有模型使用同一版本，修正带来的收益单独报告。

### 4.2 观测质量

- 在公开开发集D范围内，对大跳升和普通样本核验原始观测覆盖、推断零值、原始计数及裁剪情况。
- 保留原样本与原评分，另报质量敏感性；不把尖峰自动判为错误，不按模型表现删除样本。
- 原始记录缺失或不可获取时，明确剩余不确定性。

### 4.3 D04数值稳定性

- 另行记录有限复核范围，保留旧运行结果与配置。
- 检查求解精度、停止条件、初始化对预测及重构响应算子的影响。
- 如响应曲面仍明显不稳定，停止将曲面符号用于结构设计，不无限扩展拟合。

**交付：** 时间与输入可见性表、观测质量敏感性、数值稳定性报告，以及“可靠现象／待验证假说”清单。

## 5. T2：定位天气信号为何没有变成足够的停电响应

沿现有模型追踪：

> 天气输入 → 损伤隐藏表示 → 核的读入与状态 → 核的输出 → 损伤率 → 停电轨迹。

在大跳升、持续高停电、普通时段与平静期分别记录：

- 隐藏天气信号与输入天气变化是否一致。
- 门控开度、归一化前后幅度、状态更新和衰减。
- 核的读出相对宿主隐藏表示的贡献。
- 梯度大小、有效参数更新及下游损伤网络的利用程度。
- 损伤与恢复的模型输出量级，以及对最终轨迹的影响。
- 训练与留出误差、稀有冲击样本的损失和梯度贡献。

据此区分几种可能：输入表达不足、核读入受抑制、状态或读出幅度受限、下游未利用核输出、训练或损失诱导保守预测。它们都是待检验假说。

冻结模型内的开关或替换只能提供灵敏度诊断，不能替代重新训练的对照。真实未来峰值定义的子组只用于诊断，不用于预测时选择模型或设置窗口。

**交付：** 有证据排序的瓶颈列表，每个瓶颈对应一项最小改动和可证伪预期。避免仅凭漏峰就整体放大输出。

## 6. T3：沿最新分支分阶段实现新核

### 6.1 默认候选路线

| 阶段 | 新增内容 | 检验对象 |
|---|---|---|
| K1 | 保留旧地理码，并加入完整geo40与非线性联合表示的通路 | 固定压缩或条件表达能力是否限制收益 |
| K2 | 在K1上让核参数随当前可用天气变化 | 同一地理条件是否需要对不同天气阶段产生不同响应 |
| K3 | 在K2上加入先前隐状态条件化 | 前期积累是否需要改变后续冲击的读入、衰减与状态转换 |

这是一条候选路线，不要求未经诊断就全部执行。T2如果指向读入门槛，优先测试读入；如果主要问题来自宿主或训练，先公平修复所有模型。

### 6.2 设计约束

- 全部地理变量均可参与学习，不手工限定变量对、符号或交互阶数。
- 地理组合由数据学习，物理例子只用于解释动机。
- 保留单一损伤MLP，不另建直接预测停电的第二损伤网络。
- 保留稳定性约束，检查梯度与递归数值行为；有界状态不自动意味着梯度稳定。
- 新增连接置零时验证能恢复旧模型；保留原预处理、校准和时间语义。
- 状态条件化只能使用先前模型隐状态及允许的信息，不输入未来真实停电。
- 修改递归条件后重新验证梯度，不能直接沿用不再适用的旧自定义反向传播。

**交付：** 候选代码、配置、参数量、初始化一致性、梯度正确性和长序列稳定性检查。

## 7. T4：有限筛选，再做完整验证

### 7.1 第一轮筛选

- 采用现有五个事件折、固定训练预算和配对初始化。
- 单seed只能用于筛除失败候选或识别不稳定，不能宣布最终提升。
- 运行前冻结候选数、超参数范围、评分口径与继续条件。
- 复用合规且严格匹配的已有对照；数据或训练设计改变时，同步更新相关基线。

### 7.2 值得保留的候选

- 在相同事件折上扩展多seed验证，按现有协议先做三seed验证；最终确认的五seed及预算在运行前核定。
- 比较无核HOST、原核、新核、认真优化的简单地理接入基线，以及同结构但移除有效地理信息并重新训练的对照。
- 地理置换需要说明破坏了什么、保留了什么，以及是否造成明显分布外输入；不能用单一置换结果宣称因果机制。
- 根据实际改动做消融，分清表达容量、天气条件化、状态条件化的收益。
- 参数匹配的横向对照与逐级嵌套的消融分开报告，不能同时宣称嵌套扩容和参数量完全相同。
- 如改损失、采样或训练预算，作为独立因素，并给基线同样机会。

### 7.3 统一报告内容

| 维度 | 报告内容 |
|---|---|
| 主要预测效果 | 既有主指标、pooled RMSE与MAE、+1/+6/+24/+48四个时效 |
| 尾部表现 | 峰值幅度、真实峰时误差、漏峰、假峰、上升与回落误差 |
| 稳定性 | 逐seed、逐折、逐事件及天气类型结果 |
| 收益集中度 | 各事件贡献、去除单个事件后的敏感性；不据此删除不利事件 |
| 不确定性 | 事件或family聚类区间及seed差异；披露重复县依赖 |
| 信息归因 | 与无有效地理信息对照、简单地理接入和容量对照的比较 |

总体评分按既有权重和有效cell汇总，不平均fold RMSE。不同报告中的balanced定义必须分别注明。

保留既有筛选门槛，不根据新结果临时改规则。预测候选需要通过预测评价；探索性局部现象不能仅因总体MSE弱就被删除。

**交付：** 全部候选结果、明确的继续／停止决定及失败记录。

## 8. T5：形成论文与poster能使用的证据

最终需要回答：

1. 地理核提高了多少，跨seed和跨事件是否稳定？
2. 哪些设计必要，哪些复杂度没有贡献？
3. 哪些天气与地理条件下有效，哪些条件下失败？
4. 提升是否由少数事件、容量增加、训练变化或输入修正解释？
5. 哪些结论只是预测关联或模型行为，哪些有额外机制证据？

准备总体结果表、贡献分解、收益分布，以及使用共同尺度的成功和失败案例。模型内将本县地理替换为均值地理的图，只说明模型敏感性，不直接证明真实地理因果效应。

开发集D已经反复分析，后续结果仍属开发证据。候选、输入与选择规则冻结后，再按既有封存协议进行独立确认；不得将封存集用于反复改模型。

**交付：** 可追溯到结果文件的论文证据包，而不是先写地理机制结论再寻找支持案例。

## 9. 执行优先级与停止规则

近期顺序：T1关键核验 → T2瓶颈定位 → 一个有依据的新核候选 → 五折有限筛选 → 多seed及贡献验证。

- 暂不扩展I18的seed，也不重复生成庞大的相关性图谱。
- 时间或观测问题成立时，先修正并更新所有对照，再评价核。
- 数值问题未解决时，不用不稳定曲面决定物理规则。
- 新核只改善训练、不改善留出时，优先处理过拟合和泛化，不继续无条件扩容。
- 峰值增大同时显著增加假峰时，不认定为冲击预测改进。
- 收益仅来自改变训练或宿主时，如实归因，不能全部计入地理核。
- 多个有限候选仍无稳定收益时，重新评估数据分辨率与可识别信息；若扩展县内空间信息，另立数据版本、成本与实验范围。
