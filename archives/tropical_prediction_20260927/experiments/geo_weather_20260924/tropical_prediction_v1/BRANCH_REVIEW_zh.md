## 分支现状

检查基点：`493aa54fb9233f27c4b6a10b5bacf3c1592f33ba`。
`data_v1` 的开发集包括 81 个天气系统、8,457 个县—事件；其中热带部分为 15 个系统、1,633 个县—事件。
已有林冠、地形、排水、距海岸、历史电力背景、ERA5 和 HRRR 危险度特征。
此前三事件试验使用旧分支的静态表；“缺少上述地理字段”的判断不适用于这里。

现有 HOST 结果来自多天气类型联合训练，再分组统计热带表现，不是纯热带训练。
`../tropical_evidence/stage0_host_s0.json` 中，热带 HOST / 全零的加权 MSE 分别为
0.0029832503 / 0.0033691709。MSE 降低约 11.45%，换成 RMSE 是降低约 5.90%。
它只有 seed 0，不能当作三种子稳定性结论；也没有证明地理核带来的增量收益。

## 为什么旧结果不能直接拼接

| 项目 | 旧三事件试验 | 本分支后续 |
|---|---|---|
| 事件 | Michael / Isaias / Zeta | 全部 15 个热带开发系统，含弱事件 |
| 起报 | 每 6 小时滚动 | 每个系统固定起报 |
| 历史 / 预测 | 24 h / 48 h | 72 h / 144 h |
| 划分 | 一场训练、一场验证、一场测试 | 继承既有五个事件外层折；内层按完整事件组 |
| 主要指标 | 无权重、四个点时效 | 抽样权重下的完整路径 MSE / RMSE，另报 MAE 和点时效 |
| 观测门控 | 来源代码使用前后 ±7 天窗口 | data_v1 的事前观测覆盖规则 |
| 地理特征 | 旧县级静态表 | 当前物理地理及电力背景 |

旧面板的中心窗口可能依赖未来是否出现停电记录。旧试验未重建这些观测掩码，因此只保留为开发记录。
三个旧窗口与封存 C 的县—时间窗口没有交集，核对只读取了窗口和县集合元数据，见 `legacy_exposure_audit.json`。
